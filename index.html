Current status

Release channels

PikaPDF 0.5.0 is available now. It is the release formerly named FastPDF, published on GitHub Releases as an unsigned build, so Windows may show a security warning when you run it. The source code stays private. See the Downloads page for the files and their SHA-256 checksums.

PikaView 0.1.1 is available now. Formerly named OZ Image Viewer, its official Windows x64 installer and portable packages are published alongside corresponding source for its LGPL components. First-party source code is public at github.com/underoatz-netizen/oz-image-viewer. See the Downloads page for packages and SHA-256 checksums.

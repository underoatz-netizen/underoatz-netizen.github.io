  • PikaPDF (formerly FastPDF)

    v0.5.1 · Windows x64

    A Windows desktop app for opening and working with PDF documents: reading, searching, presentation, capture, image export, image-to-PDF conversion and printing, with a system-aware Light/Dark theme.

    Version 0.5.1 is available to download for Windows x64.

  • PikaView (formerly OZ Image Viewer)

    v0.1.2 · Windows x64

    A Windows desktop image viewer for common still image formats, with fast first-image display, smooth zoom and pan, folder navigation, non-destructive editing and printing.

    Version 0.1.2 is available for Windows x64.

    Download Overview

  • PikaSnip

    v0.1.0 · Windows x64

    Version 0.1.0 is available for Windows 10 & 11 (x64).

Current status

Release channels

PikaPDF 0.5.1 is available now. Formerly named FastPDF, it adds a system-aware theme that follows Windows Light, Dark, and High Contrast settings and is published on GitHub Releases as an unsigned build, so Windows may show a security warning when you run it. The source code stays private. See the Downloads page for the files and their SHA-256 checksums.

PikaView 0.1.2 is available now. Formerly named OZ Image Viewer, its official Windows x64 installer and portable packages are published alongside corresponding source for its LGPL components. First-party source code is public at github.com/underoatz-netizen/oz-image-viewer. See the Downloads page for packages and SHA-256 checksums.

PikaSnip 0.1.0 is available now. Published on GitHub Releases (github.com/underoatz-netizen/pikasnip) as a recommended Portable x64 ZIP and a self-signed MSIX sideload test build. Submitted to Microsoft Store — pending certification; the Store listing will be linked here once it is published. See the Downloads page for packages and SHA-256 checksums.

OZ Lab

OZ Lab builds software for Windows. Our products are FastPDF, a desktop app for working with PDF documents, and OZ Image Viewer, a fast desktop image viewer that is in development.

Our products

  • FastPDF

    A Windows desktop app for opening and working with PDF documents: reading, searching, presentation, capture, image export, image-to-PDF conversion and printing.

    Version 0.3.2 is available for Windows x64.

  • OZ Image Viewer

    A Windows desktop image viewer for common still image formats, with fast first-image display, smooth zoom and pan, folder navigation and non-destructive editing.

    In development — no public release yet.

Current status

FastPDF 0.3.2 is available now. It is published on GitHub Releases as an unsigned build, so Windows may show a security warning when you run it. The source code stays private. See the Downloads page for the files and their SHA-256 checksums.

OZ Image Viewer is in development. It is at version 0.1.0 and has no public release yet; its source code is private. See the product page for the current status.

# OZ Lab website

This repository is the public source of the OZ Lab website served at
<https://underoatz-netizen.github.io/>. The site is plain HTML and CSS with no
build step and no JavaScript; GitHub Pages publishes the files here directly.

- English: <https://underoatz-netizen.github.io/>
- Thai (ไทย): <https://underoatz-netizen.github.io/th/>

## Product pages on the site

- **FastPDF** — a Windows desktop app for opening, reading, searching,
  presenting, printing and converting PDF documents.
  <https://underoatz-netizen.github.io/software/fastpdf/>
- **OZ Image Viewer** — a Windows desktop image viewer for common still image
  formats, with fast first-image display, zoom and pan, folder navigation and
  non-destructive editing. It is in development at version 0.1.0, with no
  public release yet.
  <https://underoatz-netizen.github.io/software/oz-image-viewer/>

The site also has a Support page (<https://underoatz-netizen.github.io/support/>)
and a Privacy page (<https://underoatz-netizen.github.io/privacy/>).

## What this repository is, and is not

This is the static site repository. It holds the published pages' HTML, CSS,
images and text, and nothing else. It is not a product repository: it contains
no application source code, no installers and no release files.

Product source and release files are kept in their own repositories:

- FastPDF — <https://github.com/underoatz-netizen/FastPDF-Downloads>
- OZ Image Viewer — <https://github.com/underoatz-netizen/oz-image-viewer>

For what can currently be downloaded, see the product pages on the site.

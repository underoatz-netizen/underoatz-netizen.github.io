# underoatz-netizen.github.io

Static website for **OZ Lab** and its product **FastPDF**.

- Plain HTML and CSS. **No build step and no JavaScript.**
- English pages are at the site root; Thai pages are under `/th/`.
- Hosted with GitHub Pages (free `*.github.io` URL).
- This repository contains **no application source code**, no internal
  documentation, and no credentials.

This repository is currently **private** and the site is **not published**.
Public visibility and GitHub Pages are enabled only after the project's review
gates are passed.

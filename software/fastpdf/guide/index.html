User guide & FAQ

This guide walks through how PikaPDF (formerly FastPDF) is used. It covers the features in version 0.5.0 for Windows x64, available on the Downloads page.

Basics Keyboard shortcuts Known limitations Frequently asked questions

Basics

  • Command bar & More commands. Commands live in a single-row responsive command bar with Lucide icons. Commands that do not fit, along with document actions, appear under More commands (Open..., Recent Files, Save a Copy..., Save Rotated Copy..., Print..., PDF to PNG..., Image to PDF..., Check for Updates).
  • Open a document. Use Open... (Ctrl+O), Recent Files, drag a single PDF file onto the window, or open one directly from the command line.
  • Sidebar (Ctrl+B). Toggle the sidebar to switch between Thumbnails and Bookmarks. Unsupported external or remote bookmark actions are labelled cleanly and never executed.
  • Read & Navigate. Documents are shown in a continuous single-column layout. Scroll with the mouse wheel or keyboard, or jump directly to any valid page number using the Go to Page dialog (Ctrl+G).
  • Zoom. Use the zoom commands or the mouse wheel with the Control key held. A page anchor keeps your position when you zoom or resize.
  • Search. Open the find panel (Ctrl+F) and type. Search runs as you type and highlights matches in the document.
  • Draw & Highlight. Draw freehand ink in multiple colours and three stroke widths, or highlight embedded selectable text. Undo and redo changes with Ctrl+Z and Ctrl+Y.
  • Save a Copy. Save annotations using Save a Copy..., which always writes a new file and never overwrites existing files or the source document. Unsaved-change protection prompts you before closing, opening another file, printing, or exporting to PNG.
  • Present. Presentation mode (F11) fills the screen and shows one page at a time; use the arrow keys, space or paging keys to move between pages.
  • Screenshot (Ctrl+S). Drag a region on the page to copy it to the clipboard and optionally save it as an image. Note that Ctrl+S triggers Screenshot capture, not document saving.
  • Convert. Export PDF pages to PNG images, or combine PNG, JPEG and BMP images into a single PDF.
  • Print (Ctrl+P). Use the Print dialog with 1–6 pages per sheet, a first-sheet preview thumbnail, colour or monochrome output, duplex printing, Fast/Medium/Detailed quality, By set or By page copy order, and spool progress with cancel.

Known limitations

These are the current limits, so you know what to expect:

  • Password-protected PDFs cannot be opened.
  • Search and text highlighting cover the document's embedded text layer only. There is no OCR, so scanned pages cannot be searched or text-highlighted.
  • There is no Add Text tool.
  • Annotation editing is disabled on signed, protected, or encrypted PDFs and on pages that already contain annotations.
  • Save a Copy never overwrites existing files or the source document.
  • Page rotation applies to the open session only. To keep a rotation, use Save Rotated Copy; the original file is not modified.
  • The builds are unsigned, so Windows SmartScreen or your browser may show a warning before you run them.

Frequently asked questions

Where can I download PikaPDF?

Version 0.5.0 is available for Windows 10 and Windows 11 (x64) on the Downloads page. The builds are unsigned, so Windows may show a warning when you run them.

How do I upgrade from FastPDF 0.4.1?

PikaPDF 0.5.0 upgrades over FastPDF 0.4.1 in place, reusing your existing install folder and preserving your settings and recent files in %LOCALAPPDATA%\FastPDF. Fresh installs default to Program Files\PikaPDF. Inside both packages, the executable filename remains FastPDF.exe (with pdfium.dll and licenses/) so existing shortcuts keep working.

Do I need an account to use PikaPDF?

No. PikaPDF is a desktop application and does not use accounts or sign-in.

Where is the source code?

The source code is kept private. It is not published, and PikaPDF is not an open-source project.

What kind of computer does PikaPDF run on?

PikaPDF runs on 64-bit (x64) Windows 10 and Windows 11.

Does PikaPDF send my documents anywhere?

For data handling, see the Privacy page. The application privacy policy is still a draft and is not yet in effect.

How do I report a problem?

See the Support page for how to reach us.

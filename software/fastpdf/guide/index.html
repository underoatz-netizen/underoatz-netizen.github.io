User guide & FAQ

This guide walks through how FastPDF is used. It covers the features in the current release. Version 0.4.0 for Windows x64 is available on the Downloads page.

Basics

  • Open a document. Use the Open command, drag a single PDF file onto the window, or open one directly from the command line.
  • Read. Documents are shown in a continuous single-column layout. Scroll with the mouse wheel or the keyboard.
  • Go to Page. Jump directly to any valid page number using the Go to Page dialog (Ctrl+G).
  • Zoom. Use the zoom commands or the mouse wheel with the Control key held. A page anchor keeps your position when you zoom or resize.
  • Search. Open the find panel and type. Search runs as you type and highlights matches in the document.
  • Present. Presentation mode fills the screen and shows one page at a time; use the arrow keys, space or paging keys to move between pages.
  • Capture. Drag a region on the page to copy it to the clipboard, and save it as an image if you want.
  • Convert. Export pages to PNG images, or combine PNG, JPEG and BMP images into a single PDF.
  • Print. Print the current document through the standard Windows printing system.

Known limitations

These are the current limits, so you know what to expect:

  • Password-protected PDFs cannot be opened yet.
  • Search covers the document's text layer only. There is no OCR, so scanned pages return no results.
  • Page rotation applies to the open session only. To keep a rotation, save a rotated copy; the original file is not modified.

Frequently asked questions

Where can I download FastPDF?

Version 0.4.0 is available for Windows x64 on the Downloads page. The builds are unsigned, so Windows may show a warning when you run them.

Do I need an account to use FastPDF?

No. FastPDF is a desktop application and does not use accounts or sign-in.

Where is the source code?

The source code is kept private. It is not published, and FastPDF is not an open-source project.

What kind of computer does FastPDF run on?

FastPDF runs on Windows. The 0.4.0 release is a 64-bit (x64) build.

Does FastPDF send my documents anywhere?

For data handling, see the Privacy page. The application privacy policy is still a draft and is not yet in effect.

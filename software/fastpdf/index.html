FastPDF

FastPDF is a Windows desktop app for working with PDF documents, made by OZ Lab. The source code is private, and version 0.4.0 is available to download.

Available now: FastPDF 0.4.0 for Windows x64. The builds are unsigned, so Windows may show a warning when you run them. You can find the files and their SHA-256 checksums on the Downloads page.

What FastPDF does

FastPDF is a viewer and a small set of document tools in one desktop app. These are the features it includes:

  • Open and read PDF documents, with continuous single-column scrolling.
  • Jump directly to any page with the Go to Page dialog.
  • Zoom controls: fit width, fit page, 100% and free zoom, with a page anchor that keeps your place.
  • Presentation mode for full-screen page-by-page viewing.
  • Search inside a document with an incremental find panel.
  • Capture a region of a page to the clipboard and save it as an image.
  • Export PDF pages to PNG images.
  • Combine PNG, JPEG and BMP images into a single PDF.
  • Print through the standard Windows printing system.
  • Rotate pages and save a rotated copy without changing the original file.
  • Keep a list of recently opened documents.
  • Open a document directly from the command line or by dragging one file onto the window.
  • A manual "Check for Updates" option and an About dialog.
  • An optional diagnostics overlay for troubleshooting.

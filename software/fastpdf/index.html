PikaPDF

PikaPDF (formerly FastPDF) is a Windows desktop app for working with PDF documents, made by OZ Lab. The source code is private, and version 0.5.0 is available to download.

PikaPDF 0.5.0 for Windows x64 is available now. Upgrading over FastPDF 0.4.1 is seamless: the build upgrades in place, reuses the existing install directory, and preserves your settings and recent files. The builds are unsigned, so Windows may show a warning when you run them. You can find the files and their SHA-256 checksums on the Downloads page.

What PikaPDF does

PikaPDF is a viewer and a set of document tools in one desktop app. These are the features it includes:

  • Open and read PDF documents, with continuous single-column scrolling.
  • Reach commands from a single-row responsive command bar with Lucide icons; commands that do not fit appear in the More commands overflow menu.
  • Show or hide the Thumbnails and Bookmarks sidebar with Ctrl+B. Unsupported external or remote bookmark actions are safely labelled and never executed.
  • Draw freehand ink in multiple colours and three stroke widths, or highlight selectable text in multiple colours, then undo and redo with Ctrl+Z and Ctrl+Y.
  • Save a Copy of the current document. Unsaved-change protection prompts on close, open, print and PNG export, and never overwrites existing files or the source document.
  • Jump directly to any page with the Go to Page dialog (Ctrl+G).
  • Zoom controls: fit width, fit page, 100% and free zoom, with a page anchor that keeps your place.
  • Presentation mode (F11) for full-screen page-by-page viewing.
  • Search inside a document with an incremental find panel (Ctrl+F).
  • Capture a region of a page to the clipboard with Screenshot (Ctrl+S) and save it as an image.
  • Export PDF pages to PNG images, and combine PNG, JPEG and BMP images into a single PDF.
  • Print through an enhanced Print dialog: 1–6 pages per sheet, a preview thumbnail, colour or monochrome output, duplex printing, Fast/Medium/Detailed quality, By set or By page selection, and progress with cancel.
  • Rotate pages and save a rotated copy without changing the original file.
  • Keep a list of recently opened documents.
  • Open a document directly from the command line or by dragging one file onto the window.
  • A manual "Check for Updates" option and an About dialog, plus Diagnostics (Ctrl+D) for troubleshooting.

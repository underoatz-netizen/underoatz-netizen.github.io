Download PikaPDF

Version 0.5.0, for Windows x64. Take the installer if you would like PikaPDF set up for you, or the portable ZIP if you would rather keep it self-contained.

PikaPDF 0.5.0 is available now. Both files come from the official GitHub Release. The executable inside the packages is still named FastPDF.exe, so existing shortcuts keep working. If you already have FastPDF 0.4.1, the build upgrades in place, reuses the existing install directory and preserves your settings and recent files. The builds are unsigned, so Windows may warn you before you run them.

Release files

  • PikaPDF-0.5.0-win-x64-Setup.exe — the Windows installer (about 5.4 MB).
  • PikaPDF-0.5.0-win-x64.zip — a portable ZIP package (about 4.1 MB).
  • SHA256SUMS — the checksum file for both downloads.

All three files are listed together on the v0.5.0 release page on GitHub.

Checksums and unsigned builds

Each file has a SHA-256 checksum. After you download one, run your own checksum tool and compare the result with the value below. If they do not match, please do not run the file.

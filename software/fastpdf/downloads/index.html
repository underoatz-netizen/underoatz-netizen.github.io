Download PikaPDF

Version 0.5.1, for Windows x64. Take the installer if you would like PikaPDF set up for you, or the portable ZIP if you would rather keep it self-contained.

PikaPDF 0.5.1 is available now. Both files come from the official GitHub Release. The executable inside the packages is still named FastPDF.exe, so existing shortcuts keep working. The builds are unsigned, so Windows may warn you before you run them.

Quick start

3 steps
  1. Step 01

    Download & verify SHA-256

    Download either the installer or portable ZIP from GitHub Releases and verify its SHA-256 checksum against the values below before opening.

  2. Step 02

    Install or extract

    Run the installer (or extract the full ZIP folder). Because builds are unsigned, Windows SmartScreen may show a notice — confirm your SHA-256 hash matches first, then choose More info > Run anyway.

  3. Step 03

    Open & keep shortcuts

    Launch PikaPDF (FastPDF.exe). Upgrades from FastPDF 0.4.x or PikaPDF 0.5.0 reuse your install folder and keep settings and recent files in %LOCALAPPDATA%\FastPDF.

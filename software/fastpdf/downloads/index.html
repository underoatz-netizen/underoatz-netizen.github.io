Version 0.3.2, for Windows x64. Take the installer if you would like FastPDF set up for you, or the portable ZIP if you would rather keep it self-contained.

FastPDF 0.3.2 is ready to download. Both files come from the official GitHub Release. They are unsigned, so Windows may warn you before you run them.

Release files

  • FastPDF-0.3.2-win-x64-Setup.exe — the Windows installer (about 4.8 MB).
  • FastPDF-0.3.2-win-x64.zip — a portable ZIP package (about 3.7 MB).
  • SHA256SUMS — the checksum file for both downloads.

All three files are listed together on the v0.3.2 release page on GitHub.

Checksums and unsigned builds

Each file has a SHA-256 checksum. After you download one, run your own checksum tool and compare the result with the value below. If they do not match, please do not run the file.

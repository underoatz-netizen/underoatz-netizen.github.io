Changelog

The release history of PikaPDF (formerly FastPDF through version 0.4.1), newest first.

PikaPDF 0.5.0 is available now. Published on 18 November 2026, for Windows 10 and Windows 11 (64-bit x64).

0.5.0 — 18 November 2026

  • Rebranded the product from FastPDF to PikaPDF, while keeping the executable filename FastPDF.exe inside packages so existing shortcuts keep working.
  • Fresh installs default to Program Files\PikaPDF; upgrades over FastPDF 0.4.1 upgrade in place, reusing the existing install folder and preserving settings and recent files in %LOCALAPPDATA%\FastPDF.
  • Replaced the separate menu bar (File, View, Convert) with a single-row responsive command bar with Lucide icons and a More commands overflow menu (Open..., Recent Files, Save a Copy..., Save Rotated Copy..., Print..., PDF to PNG..., Image to PDF..., Check for Updates).
  • Added a Thumbnails and Bookmarks sidebar (Ctrl+B); unsupported external or remote bookmark actions are labelled cleanly and never executed.
  • Added freehand ink drawing (multiple colours, three stroke widths) and embedded-text highlighting with undo and redo (Ctrl+Z / Ctrl+Y), saved via Save a Copy without overwriting existing or source files, plus unsaved-change prompts before close, open, print or PNG export.
  • Enhanced Print dialog with 1–6 pages per sheet, first-sheet preview thumbnail, colour or monochrome output, duplex printing, Fast/Medium/Detailed quality, By set/By page copy order, and spool progress with cancel.
  • Two downloads: a Windows installer and a portable ZIP package, both unsigned, with SHA-256 checksums published in SHA256SUMS.

See Downloads for the files and their checksums, or v0.5.0 on GitHub Releases.

0.4.1 — 26 October 2026

  • Added PDF open-duration diagnostics: how long the document-open phase takes is now measured and written to the diagnostic log. This is a logging change only and makes no performance claim.
  • Includes the Go to Page dialog (Ctrl+G) with 1-based target validation.
  • The Windows installer can optionally create a Desktop shortcut (off by default).
  • Two downloads: a Windows installer and a portable ZIP package.
  • Both builds are unsigned, and SHA-256 checksums are published in SHA256SUMS.

See Downloads for the files and their checksums, or v0.4.1 on GitHub Releases.

0.4.0 — 24 October 2026

  • Added Go to Page dialog (Ctrl+G) with 1-based target validation.
  • Improved cancellation safety and render stability during rapid navigation.
  • Two downloads: a Windows installer and a portable ZIP package.
  • Both builds are unsigned, and SHA-256 checksums are published in SHA256SUMS.

See Downloads for the files and their checksums.

0.3.2 — 14 October 2026

  • First public release of FastPDF, for Windows x64.
  • Two downloads: a Windows installer and a portable ZIP package.
  • Both builds are unsigned, and SHA-256 checksums are published in SHA256SUMS.
  • The in-app update check is manual and opens the GitHub Releases page.
  • The release contains no source code.

See v0.3.2 on GitHub Releases.

0.1.0 — 26 November 2026

Latest release
  • Initial public release of PikaSnip for Windows 10 and 11 (x64), built in native C++20 on Win32 and Direct2D with zero Electron, WebView2, Qt, or .NET dependencies.
  • Compact PikaSnip.exe binary (754,688 bytes) compiled with static CRT (/MT) and zero dynamic CRT imports, plus 4 bundled app-local MSVC x64 CRT DLLs for ONNX Runtime so clean Windows machines require no VC++ Redistributable.
  • Screen capture (PrintScreen / Alt+A), annotation with undo/redo (Ctrl+Z / Ctrl+Y), color picker HEX copy (C), clipboard copy (Ctrl+C / Enter), and PNG save (Ctrl+S) to %USERPROFILE%\Pictures\PikaSnip.
  • Always-on-top floating pin windows from capture selection (Ctrl+P) or clipboard (Alt+P) with zoom (25%–400%), opacity control (20%–100%), reset (0), and inline edit toolbar (E / Space).
  • 100% offline Thai & English OCR (Alt+T Quick OCR and Ctrl+T selection OCR) powered by bundled OpenThai 2.1 models (Apache 2.0) and Microsoft ONNX Runtime v1.32.0 (MIT).
  • Lazy OCR engine loading via LoadLibraryExW keeps idle standby RAM under 15 MB (observed 10.79–11.33 MB on a clean Windows 11 build 26100 system).
  • 100% offline with zero telemetry, zero network requests, and Windows Startup disabled by default (Enabled="false").
  • Published on GitHub Releases as a recommended Portable x64 ZIP (13.30 MiB) and a self-signed MSIX sideload package (13.65 MiB) with PikaSnip_0.1.0.0_x64.cer, SHA256SUMS.txt, and ThirdPartyNotices.txt. Submitted to Microsoft Store — pending certification.

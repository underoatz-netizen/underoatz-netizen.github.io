What PikaSnip does

Capture · Pin · Annotate · Offline OCR

PikaSnip stays quietly in the Windows system tray until you press a shortcut. It combines screen capture, floating reference pins, quick annotations, color picking, and offline Thai/English OCR in a single native utility:

  • Capture screen regions across monitors with PrintScreen or Alt+A, then copy to the clipboard (Ctrl+C / Enter) or save as PNG (Ctrl+S) to Pictures\PikaSnip.
  • Pin any selection (Ctrl+P) or clipboard image (Alt+P) as a floating always-on-top reference window.
  • Inspect pinned windows smoothly with mouse-wheel zoom (25%–400%), Ctrl+Wheel opacity adjustment (20%–100%), reset (0), and an inline pin edit toolbar (E / Space).
  • Annotate captures before copying, pinning, or saving, with undo and redo (Ctrl+Z / Ctrl+Y).
  • Pick exact pixel colors while capturing and copy the HEX code directly with C.
  • Extract Thai and English text 100% offline with Quick OCR (Alt+T) or from the active capture selection (Ctrl+T), powered by bundled OpenThai 2.1 models (Apache 2.0) and Microsoft ONNX Runtime (MIT).
  • Keep standby memory low: onnxruntime.dll (v1.32.0) is loaded lazily via LoadLibraryExW only when you actually invoke OCR.
  • Work completely offline with zero telemetry, zero network requests, no accounts, and Windows Startup disabled by default (Enabled="false").

Architecture & footprint

Zero-bloat native Windows

PikaSnip is written in pure native C++20 against Win32 and Direct2D — with no Electron, WebView2, Qt, or .NET runtime:

  • Compact main binary: PikaSnip.exe is 754,688 bytes, compiled with static CRT (/MT) and zero dynamic CRT imports.
  • Low standby RAM: Idle standby memory stays under 15 MB (observed 10.79–11.33 MB on a clean Windows 11 build 26100 system) because the OCR runtime stays unloaded until needed.
  • No VC++ Redistributable required: Four app-local MSVC x64 CRT DLLs are bundled alongside onnxruntime.dll so clean Windows installations run out of the box.
  • Transparent local storage: Portable mode keeps settings.json beside PikaSnip.exe; MSIX stores settings at %LOCALAPPDATA%\OZLab\PikaSnip\settings.json; saved PNGs go to %USERPROFILE%\Pictures\PikaSnip.

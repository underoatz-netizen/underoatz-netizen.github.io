v0.1.0 · Windows 10 & 11 (x64) · Portable ZIP & Self-Signed MSIX

Download PikaSnip

Version 0.1.0 for 64-bit Windows 10 and Windows 11. Choose the Portable ZIP for immediate extract-and-run use, or the self-signed MSIX package if you want to test MSIX sideloading.

Portable ZIP is recommended right now. Both builds come from the official GitHub Release and bundle OpenThai 2.1 OCR models, Microsoft ONNX Runtime v1.32.0, and 4 app-local MSVC x64 CRT DLLs so no VC++ Redistributable is needed. The MSIX package is a self-signed test/sideload build requiring administrator certificate trust while the Microsoft Store release is in preparation.

Quick start

3 steps
  1. Step 01

    Download & verify SHA-256

    Download PikaSnip_0.1.0_Portable_x64.zip from GitHub Releases and verify its SHA-256 hash against the table below before extracting.

  2. Step 02

    Extract & launch

    Extract the entire ZIP folder (keeping the OCR models and DLLs together) and run PikaSnip.exe. If Windows SmartScreen warns on an unsigned binary, confirm the SHA-256 hash matches first, then choose More info > Run anyway.

  3. Step 03

    Capture, pin & OCR

    PikaSnip runs quietly in the system tray under 15 MB RAM. Press PrintScreen or Alt+A to capture, Ctrl+P to pin, or Alt+T for offline Thai & English OCR.

Self-signed MSIX sideload note

The MSIX package is signed with a self-signed test certificate for local sideload testing while the Microsoft Store release is in preparation:

  • Certificate file: PikaSnip_0.1.0.0_x64.cer (772 bytes)
  • Subject: CN=OZ Lab
  • SHA-1 Thumbprint: 9F536B494A2FC9724B848064E0E40873A0984408
  • Trust requirement: To sideload PikaSnip_0.1.0.0_x64.msix, an administrator must import PikaSnip_0.1.0.0_x64.cer into both LocalMachine\Root (Trusted Root Certification Authorities) and LocalMachine\TrustedPeople (Trusted People). If you prefer not to install a local test certificate, use the Portable ZIP instead.

User guide & FAQ

How to capture, pin, annotate, pick colors, and run offline Thai & English OCR with PikaSnip 0.1.0 for Windows x64, available on the Downloads page.

Basics Keyboard shortcuts Data & storage paths Frequently asked questions

Basics

  • System tray standby. Launch PikaSnip.exe and it stays ready in the Windows notification area (system tray) using under 15 MB of RAM while idle. Right-click the tray icon to open settings, trigger actions, or toggle Run at Startup (disabled by default).
  • Capture & annotate. Press PrintScreen or Alt+A to select a region. Draw annotations directly over the selection, undo or redo with Ctrl+Z / Ctrl+Y, copy with Ctrl+C or Enter, or save as PNG with Ctrl+S.
  • Color picker. While capturing, press C to copy the HEX color value of the pixel under the cursor straight to your clipboard.
  • Pin floating windows. Press Ctrl+P during capture to pin the selected region on top of all windows, or press Alt+P to pin whatever image is currently in your clipboard.
  • Inspect & edit pins. Hover a pinned window and scroll the Mouse Wheel to zoom (25%–400%), hold Ctrl+Wheel to change opacity (20%–100%), press 0 to reset, press E or Space to toggle the pin edit toolbar, or press Esc to close it.
  • Offline Thai & English OCR. Press Alt+T for Quick OCR or Ctrl+T on an active capture selection to extract Thai and English text completely offline using bundled OpenThai 2.1 models and lazily loaded Microsoft ONNX Runtime (v1.32.0).

Frequently asked questions

Should I download the Portable ZIP or the MSIX package?

For most users right now, download the Portable x64 ZIP from the Downloads page: extract it and run PikaSnip.exe without installing any certificate. The MSIX file is a self-signed sideload test build that requires importing PikaSnip_0.1.0.0_x64.cer as Administrator into LocalMachine\Root and LocalMachine\TrustedPeople while the Microsoft Store release is in preparation.

Do I need to install Microsoft Visual C++ Redistributable?

No. PikaSnip.exe is linked statically (/MT) with zero dynamic CRT imports, and the package includes the 4 app-local MSVC x64 CRT DLLs required by onnxruntime.dll so clean Windows 10 and 11 systems work out of the box.

How does PikaSnip stay under 15 MB RAM when idle?

The core app uses pure native C++20 Win32/Direct2D with no browser engine, and onnxruntime.dll (v1.32.0) is loaded lazily via LoadLibraryExW only when you actually invoke OCR. On a clean Windows 11 build 26100 system, idle standby memory was observed at 10.79–11.33 MB.

Does PikaSnip send screenshots or OCR text over the internet?

Never. PikaSnip runs 100% offline with zero telemetry and zero network access. All screen captures, pins, annotations, and OpenThai 2.1 OCR recognition happen locally on your PC. Read the full PikaSnip Privacy Policy or the site-wide Privacy page for details.

Does PikaSnip start automatically with Windows?

Not by default. The startup task is disabled by default (Enabled="false") and only runs at login if you explicitly enable Run at Startup.

Where can I view source and open-source notices?

Visit the repository at github.com/underoatz-netizen/pikasnip and see ThirdPartyNotices.txt on the Downloads page for Apache 2.0 (OpenThai 2.1) and MIT (Microsoft ONNX Runtime) license notices.

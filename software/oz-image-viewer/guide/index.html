User guide & FAQ

This guide walks through how OZ Image Viewer is used. It describes the behaviour implemented so far. The app is still in development and has no public release yet.

Basics

  • Open an image. Launch with no arguments to get a window with an Open button, use Ctrl+O, or open an image directly from the command line. You can also drag a single image file onto the window.
  • View. The image is shown fit to the window without enlarging images that are smaller than the window. The first image appears before the rest of the folder is scanned.
  • Navigate. Other images in the same folder become available for browsing with the keyboard, and each one is decoded as you select it.
  • Zoom and pan. Scroll to zoom in and out at the cursor, or use the keyboard. Drag with the left mouse button to pan, and double-click to switch between fit and 100%.
  • Fullscreen. Switch the window to borderless fullscreen on the current monitor and back again.
  • Edit. Rotate, flip, crop and resize are non-destructive: they change the on-screen document only, and the original file stays untouched until you save.
  • Save. Save writes the current document back to its original file where the format allows it; Save As writes a new copy and never changes the original.

Supported formats

These are the common still image formats it opens. Support works by reading the file's own signature, not by trusting the file extension.

  • JPEG (.jpg, .jpeg)
  • PNG (.png)
  • Static WebP (.webp, still images only)
  • BMP (.bmp) and static GIF (.gif)
  • TIFF (.tif, .tiff, first page only)
  • ICO (.ico) and CUR (.cur)
  • TGA (.tga)
  • AVIF (.avif) and HEIC/HEIF still images when the optional decoder is available

For saving, the output formats are PNG, JPEG, WebP (lossless), TIFF and BMP. TIFF is Save As only.

Known limitations

These are the current limits, so you know what to expect:

  • There is no RAW support. RAW and camera-raw containers are deliberately rejected.
  • There is no animation support. Animated WebP and multi-frame GIF files are rejected rather than played, and animated PNG (APNG) shows only its first frame.
  • Vector graphics, PDF and general document formats are not supported.
  • Multi-page or multi-frame files such as TIFF and ICO show a single page or frame only.
  • WebP export is lossless single-frame only; lossy and animated WebP export are not supported.
  • There are no plugins or third-party shell codecs, and the set of supported extensions is a fixed list.
  • The app is still in development. There is no public release, no download, and the source code is public.

Frequently asked questions

Can I download OZ Image Viewer?

Not yet. OZ Image Viewer is still in development and there is no public release to download at this time.

Where is the source code?

The source code is public. The project lives on GitHub at underoatz-netizen/oz-image-viewer.

Do I need an account to use it?

No. OZ Image Viewer is a desktop application and does not use accounts or sign-in.

What kind of computer does it run on?

OZ Image Viewer is a Windows desktop application for 64-bit (x64) Windows 10 and Windows 11.

Does editing change my original file?

No. Rotate, flip, crop and resize are non-destructive and affect the on-screen document only. Your file changes only when you choose Save or Save As.

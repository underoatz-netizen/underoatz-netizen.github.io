Quick start

3 steps
  1. Step 01

    Download & verify SHA-256

    Download the v0.1.1 installer or portable ZIP from GitHub Releases and verify its SHA-256 checksum against SHA256SUMS before executing.

  2. Step 02

    Install, upgrade, or extract

    Run the per-user installer (upgrades OZ Image Viewer 0.1.0 in place) or extract the entire ZIP folder (including heif.dll and libde265.dll). If SmartScreen shows an "Unknown Publisher" notice for this unsigned build, verify the SHA-256 hash first rather than bypassing blindly.

  3. Step 03

    View, edit & print safely

    Open any still image directly or drag it onto ozviewer.exe. Edits stay non-destructive until you choose Save or Save As, and Ctrl+P prints one fit-to-page copy without modifying the file.

Security, trust, and platform scope

Unsigned release builds: Release binaries in version 0.1.1 (pikaview-0.1.1-win-x64-installer.exe, ozviewer.exe, heif.dll, and libde265.dll) are unsigned (NotSigned), while the bundled Microsoft VC143 CRT DLLs carry valid Microsoft Authenticode signatures. Windows SmartScreen or web browsers may show an "Unknown Publisher" protection notice when opening the installer or executable. Please check that the file was downloaded from the official repository and that its SHA-256 hash matches SHA256SUMS and the table above rather than blindly bypassing security warnings.

Target platform and verification scope: Built for 64-bit Windows (x64). Automated disposable standard-user installation, FirstPresent benchmark smoke, opt-in association and desktop shortcut handling, in-place v0.1.0 -> v0.1.1 upgrade with UserChoice preservation, runtime closure verification, and clean uninstallation have been verified in clean-room standard-user CI on Windows Server 2022 (x64). 32-bit x86 and native ARM64 architectures are not supported in this build.

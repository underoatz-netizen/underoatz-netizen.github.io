PikaView downloads

Official Windows x64 packages for PikaView (formerly OZ Image Viewer) version 0.1.1.

Version 0.1.1 release: Packages are published as 64-bit Windows binaries (x64). First-party source code is licensed under the MIT License. In compliance with LGPLv3 §4 and GPLv3 §6(d), complete corresponding source code, build scripts, and build instructions for the dynamically loaded LGPL components (libheif and libde265) are provided alongside binary distributions. Installing over OZ Image Viewer 0.1.0 upgrades in place while keeping ozviewer.exe and %LOCALAPPDATA%\Programs\OZ Image Viewer.

Release files (version 0.1.1)

  • pikaview-0.1.1-win-x64-installer.exe — guided Windows setup installer for 64-bit Windows (about 4.1 MB / 4,260,442 bytes).
  • pikaview-0.1.1-win-x64-portable.zip — portable ZIP package (about 2.6 MB / 2,714,302 bytes).
  • pikaview-0.1.1-lgpl-corresponding-source.zip — complete corresponding source package, patches, and build scripts for LGPL components libheif and libde265 (about 2.3 MB / 2,420,966 bytes).
  • SHA256SUMS — official cryptographic checksum file for all three distribution archives.

All release files and git tags are recorded together on the v0.1.1 release page on GitHub.

Package types and installation

  • Windows Setup Installer: Installs PikaView to your local per-user application directory (%LOCALAPPDATA%\Programs\OZ Image Viewer) using the retained executable filename ozviewer.exe. It requires no administrative privileges to install or run. If you already have OZ Image Viewer 0.1.0 installed, version 0.1.1 upgrades in place at the original install directory, updates labels to PikaView, and preserves your existing Windows default file associations (UserChoice). File associations are strictly opt-in during setup and do not hijack system defaults. You can cleanly remove the program at any time through Windows Settings > Installed Apps.
  • Portable ZIP Archive: Extract the entire ZIP archive to a folder of your choice before running ozviewer.exe. Do not run the executable directly from inside the compressed folder view, as required companion DLLs (including heif.dll and libde265.dll) must reside alongside the executable to load properly. The portable version writes no uninstaller registry keys.

PikaView does not include background services, telemetry, or silent background auto-updaters.

Security, trust, and platform scope

Unsigned release builds: Release binaries in version 0.1.1 (pikaview-0.1.1-win-x64-installer.exe, ozviewer.exe, heif.dll, and libde265.dll) are unsigned (NotSigned), while the bundled Microsoft VC143 CRT DLLs carry valid Microsoft Authenticode signatures. Windows SmartScreen or web browsers may show an "Unknown Publisher" protection notice when opening the installer or executable. Please check that the file was downloaded from the official repository and that its SHA-256 hash matches SHA256SUMS and the table above rather than blindly bypassing security warnings.

Target platform and verification scope: Built for 64-bit Windows (x64). Automated disposable standard-user installation, FirstPresent benchmark smoke, opt-in association and desktop shortcut handling, in-place v0.1.0 -> v0.1.1 upgrade with UserChoice preservation, runtime closure verification, and clean uninstallation have been verified in clean-room standard-user CI on Windows Server 2022 (x64). 32-bit x86 and native ARM64 architectures are not supported in this build.

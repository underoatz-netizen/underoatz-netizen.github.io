Changelog

Release notes and version milestones for OZ Image Viewer.

Version 0.1.0

Initial release candidate for 64-bit Windows

Version 0.1.0 is the initial public release of OZ Image Viewer, a fast, lightweight native image viewer built with modern C++23, Direct3D 11, DXGI, and Direct2D for 64-bit Windows systems.

Image viewing & navigation

  • Multi-format image decoding: Native signature-based detection and decoding for JPEG, PNG, static WebP, BMP, static GIF, TIFF (first page), ICO, CUR, TGA, and AVIF.
  • Optional dynamic HEIC/HEIF decoding: Dynamically loads standalone codec DLLs (heif.dll and libde265.dll) under LGPLv3 for still HEIC/HEIF image display without static linkage.
  • Fast startup: Presents the requested image immediately fit-to-window while asynchronously enumerating sibling folder images and preloading neighbours.
  • Smooth navigation: Arrow-key and spacebar navigation across images in the same directory.
  • Interactive zoom & pan: Cursor-centred mouse wheel zoom, 100% actual size toggle (1 or double click), fit to window (F), drag-to-pan, and borderless fullscreen mode (F11).

Non-destructive image adjustments

  • Canvas transforms: Rotate 90 degrees left or right (Ctrl+L, Ctrl+R) and flip horizontally or vertically (Ctrl+Shift+H, Ctrl+Shift+V).
  • Crop & Resize: Interactive visual crop mode (C) and pixel-dimension resize dialog (Ctrl+Alt+R).
  • Undo/Redo: Document edits modify in-memory render state only; original files remain unaltered until saved.
  • Save & Save As: Export edited images to PNG, JPEG, WebP (lossless), BMP, or TIFF.

Distribution & packaging

  • Per-user Windows Setup installer: Guided per-user installation to %LOCALAPPDATA%\Programs\OZ Image Viewer without requiring Administrator rights. File associations are strictly opt-in during setup.
  • Portable ZIP package: Self-contained directory structure ready to run without installation or registry modification.
  • LGPL corresponding source package: Shipped alongside binaries with exact build instructions and patches to satisfy LGPLv3 §4 and GPLv3 §6(d).
  • Cryptographic verification: Official SHA-256 checksums provided for all packages.

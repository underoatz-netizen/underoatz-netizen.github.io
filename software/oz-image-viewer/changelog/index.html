Version 0.1.2 — 19 November 2026

Current release · Windows x64

New PikaView icon, single-row Lucide 1.71.0 command bar, save cache/preload reliability & storage error guidance, in-place upgrade continuity, and deterministic reproducible PE binary builds

Version 0.1.2 updates PikaView's application icon and chrome with a single-row Lucide 1.71.0 command bar, fixes stale save cache/preload state across navigation, adds localized storage error guidance, preserves in-place upgrades from both 0.1.0 and 0.1.1, and produces bit-for-bit reproducible PE binaries built cleanly from source.

Visual identity & command bar

  • New PikaView application icon: Applied consistently across ozviewer.exe executable resources, main window, dialogs, empty/welcome view, and Windows setup installer (pikaview.png / ozviewer.ico).
  • Single-row Lucide 1.71.0 command bar & clean chrome: Replaced the legacy menu bar with a 40-DIP single-row command bar (32 DIP buttons, subtle separators, deterministic right-side More overflow menu, crisp crop strip controls, F10/Alt keyboard menu activation, preserved keyboard shortcuts, and automatic canvas focus restore) styled cleanly in a dark charcoal UI. Included Lucide (ISC) and Feather (MIT) notices in THIRD-PARTY-NOTICES.md.

Save reliability, upgrade continuity & deterministic builds

  • Save cache/preload reliability & storage error guidance: Fixed stale app.cache and preloaded completion state on Save so navigating Save -> Next -> Previous -> Save reloads/re-saves cleanly without false "source file modified" errors; coordinated save-completion steps with active document checkpoints and pending navigation rescheduling; added localized EN/TH guidance for read-only media (win32 19 write-protected storage) and permission denials (win32 5).
  • In-place upgrade continuity: Installer recognizes 0.1.0, 0.1.1, and 0.1.2 owned registrations, upgrading in place at %LOCALAPPDATA%\Programs\OZ Image Viewer while retaining ozviewer.exe, the stable AppId, OZImageViewer.Image ProgID, and HKCU\Software\OZImageViewer without altering existing Windows default file associations (UserChoice).
  • Deterministic MSVC /Brepro / /experimental:deterministic builds: Built from clean commit 4541ffedc4fde9d4095d92f3f7a0c5397bbb501b (tree 0c464561de3d418b8d2a8b3689ca163a1cbad7bd) using MSVC /experimental:deterministic /Brepro /PDBALTPATH:%_PDB%, pinned v143 triplet oz-x64-windows-static-md (with libheif/libde265 /Brepro /PDBALTPATH:heif.pdb & libde265.pdb), and file-local named namespace oz_viewer_main_internal in src/viewer/main.cpp, with clean from-source dependency rebuilds (VCPKG_BINARY_SOURCES=clear).

Version 0.1.1 — 18 November 2026

Previous release · Windows x64

PikaView rebrand, PrintDlgExW single-image print path, and provenance release for 64-bit Windows

Version 0.1.1 continues OZ Image Viewer under the PikaView name while preserving internal upgrade identity so existing 0.1.0 per-user installations upgrade seamlessly in place.

Identity & in-place upgrade

  • PikaView rebrand: User-facing product naming, installer branding, shortcuts, and release packages now use PikaView (formerly OZ Image Viewer).
  • Upgrade continuity over 0.1.0: Retains the ozviewer.exe executable filename, default per-user directory (%LOCALAPPDATA%\Programs\OZ Image Viewer), stable AppId, OZImageViewer.Image ProgID, and HKCU\Software\OZImageViewer registry layout. Upgrading from 0.1.0 updates owned labels in place without modifying existing Windows default file associations (UserChoice).

Interactive printing & evidence limits

  • PrintDlgExW single-image print path: Interactive printing (File -> Print... or Ctrl+P) uses a dedicated PrintDlgExW helper with a scoped apartment-threaded COM lifecycle, explicit cancel/apply/failure handling, full DevMode/DevNames/HDC cleanup, and a reentrancy guard to prepare one fit-to-page output of the committed image without modifying the file.
  • Truthful verification scope: Reported physical page print and second-Cancel observations come from historical runs on an earlier candidate and environment rather than re-run physical printer tests for this v0.1.1 build. The failed-network-first printer case was not tested, and no claim is made that all print-dialog hangs are fixed.
  • Diagnostics off in Release: Built with OZVIEWER_PRINT_DIAGNOSTICS=OFF.

Provenance, verification & packages

  • Dependency provenance checks: BUILD-PROVENANCE.json binds the staged heif.dll and libde265.dll bytes to effective vcpkg oz-x64-windows-static-md build inputs, pinned recipes/patches, and pikaview-0.1.1-lgpl-corresponding-source.zip.
  • Clean-room CI lifecycle verification: GitHub Actions CI run 44229309225 on Windows Server 2022 (x64) passed fetch-candidate and validate-candidate (disposable lifecycle harness: 48 checks with 47 pass and 1 expected non_admin_integrity_check warning; plus standard-user-lifecycle gate: 12/12 parent + 48/48 non-elevated standard-user child checks pass), covering fresh install, FirstPresent benchmark smoke, opt-in file associations and desktop shortcut handling, v0.1.0 -> v0.1.1 in-place upgrade, runtime closure hashes, UserChoice preservation across all 14 extensions, and clean uninstall.
  • Four v0.1.1 release packages: pikaview-0.1.1-win-x64-installer.exe, pikaview-0.1.1-win-x64-portable.zip, pikaview-0.1.1-lgpl-corresponding-source.zip, and SHA256SUMS (project binaries unsigned / NotSigned; bundled Microsoft VC143 CRT DLLs Microsoft-signed).

Version 0.1.0

Initial release candidate · Windows x64

Version 0.1.0 is the initial public release of OZ Image Viewer, a fast, lightweight native image viewer built with modern C++23, Direct3D 11, DXGI, and Direct2D for 64-bit Windows systems.

Image viewing & navigation

  • Multi-format image decoding: Native signature-based detection and decoding for JPEG, PNG, static WebP, BMP, static GIF, TIFF (first page), ICO, CUR, TGA, and AVIF.
  • Optional dynamic HEIC/HEIF decoding: Dynamically loads standalone codec DLLs (heif.dll and libde265.dll) under LGPLv3 for still HEIC/HEIF image display without static linkage.
  • Fast startup: Presents the requested image immediately fit-to-window while asynchronously enumerating sibling folder images and preloading neighbours.
  • Smooth navigation: Arrow-key and spacebar navigation across images in the same directory.
  • Interactive zoom & pan: Cursor-centred mouse wheel zoom, 100% actual size toggle (1 or double click), fit to window (F), drag-to-pan, and borderless fullscreen mode (F11).

Non-destructive image adjustments

  • Canvas transforms: Rotate 90 degrees left or right (Ctrl+L, Ctrl+R) and flip horizontally or vertically (Ctrl+Shift+H, Ctrl+Shift+V).
  • Crop & Resize: Interactive visual crop mode (C) and pixel-dimension resize dialog (Ctrl+Alt+R).
  • Undo/Redo: Document edits modify in-memory render state only; original files remain unaltered until saved.
  • Save & Save As: Export edited images to PNG, JPEG, WebP (lossless), BMP, or TIFF.

Distribution & packaging

  • Per-user Windows Setup installer: Guided per-user installation to %LOCALAPPDATA%\Programs\OZ Image Viewer without requiring Administrator rights. File associations are strictly opt-in during setup.
  • Portable ZIP package: Self-contained directory structure ready to run without installation or registry modification.
  • LGPL corresponding source package: Shipped alongside binaries with exact build instructions and patches to satisfy LGPLv3 §4 and GPLv3 §6(d).
  • Cryptographic verification: Official SHA-256 checksums provided for all packages.

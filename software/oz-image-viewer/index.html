PikaView

PikaView (formerly OZ Image Viewer) is a fast, lightweight image viewer for Windows desktop, made by OZ Lab. It opens common still image formats quickly and lets you zoom, pan, print and make simple non-destructive edits.

Download v0.1.2 User guide & FAQ

Version 0.1.2 release: Introduces the new PikaView application icon, a single-row 40-DIP Lucide command bar with a dark-charcoal UI and More overflow menu, save cache/preload invalidation fixes, and localized storage error guidance. Version 0.1.2 is available for 64-bit Windows systems and upgrades existing 0.1.0 or 0.1.1 per-user installations seamlessly in place, keeping ozviewer.exe and %LOCALAPPDATA%\Programs\OZ Image Viewer. Download the installer or portable ZIP from the Downloads page. Source code is public on GitHub at underoatz-netizen/oz-image-viewer.

What PikaView does

10 core capabilities

PikaView opens one image at a time and focuses on showing it quickly, then staying responsive while you look around. Common still image formats open directly, zoom and pan follow the pointer, other images in the same folder are one keypress away, and simple edits stay non-destructive until you save. These are the capabilities implemented so far.

Features

10 capabilities in 4 groups

Theme & interface

  • Borderless-windowed fullscreen on the current monitor.

Reading & navigation

  • Open and display common still image formats: JPEG, PNG, static WebP, BMP, static GIF, TIFF (first page), ICO, CUR, TGA, AVIF and HEIC/HEIF.
  • Fast-first display: the requested image is shown first, while scanning the folder and preloading neighbours happen in the background.
  • Navigate between other images in the same folder with the keyboard, with each image decoded as you select it.
  • Zoom with the mouse wheel centred on the cursor, or with the keyboard, and pan by dragging the image.
  • Fit-to-window and 100% views, and a double-click toggle between them.
  • Open an image from the command line, or drag a single file onto the window.

Editing & saving

  • Non-destructive editing: rotate, flip, crop and resize, with undo and redo. The original file is never changed until you save.
  • Save and Save As to PNG, JPEG, WebP (lossless), TIFF (Save As only) and BMP.

Print

  • Interactive single-image printing (More -> Print... or Ctrl+P): prepares one fit-to-page output of the committed image without modifying the file.

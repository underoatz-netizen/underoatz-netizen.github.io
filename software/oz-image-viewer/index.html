OZ Image Viewer

OZ Image Viewer is a fast, lightweight image viewer for Windows desktop, made by OZ Lab. It opens common still image formats quickly and lets you zoom, pan and make simple non-destructive edits.

In development: OZ Image Viewer is at version 0.1.0 and is still being built. There is no public release to download yet, and the source code is public. The project lives on GitHub at underoatz-netizen/oz-image-viewer.

What OZ Image Viewer does

OZ Image Viewer opens one image at a time and focuses on showing it quickly, then staying responsive while you look around. These are the capabilities implemented so far:

  • Open and display common still image formats: JPEG, PNG, static WebP, BMP, static GIF, TIFF (first page), ICO, CUR, TGA, AVIF and HEIC/HEIF.
  • Fast-first display: the requested image is shown first, while scanning the folder and preloading neighbours happen in the background.
  • Navigate between other images in the same folder with the keyboard, with each image decoded as you select it.
  • Zoom with the mouse wheel centred on the cursor, or with the keyboard, and pan by dragging the image.
  • Fit-to-window and 100% views, and a double-click toggle between them.
  • Borderless-windowed fullscreen on the current monitor.
  • Non-destructive editing: rotate, flip, crop and resize, with undo and redo. The original file is never changed until you save.
  • Save and Save As to PNG, JPEG, WebP (lossless), TIFF (Save As only) and BMP.
  • Open an image from the command line, or drag a single file onto the window.

Privacy

This page covers two things: this website, and the PikaPDF (formerly FastPDF) app.

This website

Zero tracking
  • This site is a set of static pages. It does not use tracking, analytics or advertising.
  • It does not set cookies of its own.
  • It has no forms, no sign-in and no user accounts.
  • It does not load analytics or tracking scripts from other companies.

The official OZ Lab website is hosted on Cloudflare Pages, with GitHub Pages serving as the backup mirror. As the hosting providers, Cloudflare and GitHub may process standard technical data (such as an IP address and request details) when serving a page, under each provider's own privacy policy. That is the host's processing, not something this site collects.

Privacy policy

This Privacy Policy explains how data is handled by the OZ Lab website, PikaPDF (formerly FastPDF), PikaView (formerly OZ Image Viewer), and PikaSnip.

This website

Zero tracking
  • This site consists of plain static HTML and CSS pages. It does not use tracking, analytics, or advertising.
  • It does not set cookies of its own, load third-party fonts, or include third-party tracking scripts.
  • It has no forms, no sign-in, and no user accounts.

The official site is hosted on Cloudflare Pages (ozlab.pages.dev), with GitHub Pages (underoatz-netizen.github.io) serving as the backup mirror. When serving a page, Cloudflare or GitHub may process standard technical connection data (such as your IP address and request headers) under that provider's own privacy policy. OZ Lab does not collect or retain this connection data.

PikaPDF (formerly FastPDF)

Effective 19 November 2026 · PikaPDF v0.5.0+

Published policy · Effective 19 November 2026 · PikaPDF v0.5.0+

PikaPDF is an offline-first local Windows desktop application with no user accounts, no login, no telemetry, no analytics, no advertising, no crash-report uploads, and no background network services.

Offline-first and local processing

All PDF opening, reading, searching, freehand drawing, text highlighting, screenshot capture, PNG export, image-to-PDF conversion, and printing happen locally on your device. Your PDF files and document contents are never uploaded or transmitted by PikaPDF.

Local files stored on your device

PikaPDF stores small local state files under %LOCALAPPDATA%\FastPDF\ (kept in the legacy FastPDF folder so upgrades from FastPDF 0.4.1 preserve your settings and recent files):

  • recent.dat — file paths and per-document viewing position/zoom state of recently opened PDF documents so the Recent Files list and resume view work across sessions.
  • fastpdf.log / fastpdf.log.1 — a local diagnostic log written automatically during normal use (rotated at approximately 1 MB) containing local timestamps, status/diagnostic events, and the file paths of opened or saved PDF documents. (Note: Ctrl+D only toggles the on-screen diagnostics overlay.)

These files never leave your device, are not deleted automatically when you uninstall the app, and can be deleted manually at any time.

Optional manual update check

PikaPDF's only network operation runs solely when you explicitly choose More commands > Check for Updates. It never checks for updates at startup, on a timer, or in the background.

  • When triggered, PikaPDF sends a single HTTPS GET request with User-Agent: PikaPDF/<version> to the fixed endpoint https://api.github.com/repos/underoatz-netizen/FastPDF-Downloads/releases/latest using Windows system certificate validation, finite timeouts, and a 64 KB response limit.
  • It reads only the tag_name field to check whether a newer release exists.
  • PikaPDF never auto-downloads or auto-installs files. Only if you explicitly confirm opening the releases page does it launch https://github.com/underoatz-netizen/FastPDF-Downloads/releases in your default web browser.
  • Standard connection metadata (such as your IP address and request details) for that request is processed by GitHub under GitHub's privacy policy.

PikaView (formerly OZ Image Viewer)

Effective 19 November 2026 · PikaView v0.1.1+

PikaView is a completely offline Windows desktop image viewer. It makes no network requests and has no telemetry, no background services, and no auto-updater.

  • Local viewer preferences are stored on your device at %LOCALAPPDATA%\OZViewer\settings.json.
  • If installed with the per-user Windows Setup installer, standard local installation entries may also exist under %LOCALAPPDATA%\Programs\OZ Image Viewer and HKCU\Software\OZImageViewer.
  • Uninstalling PikaView via Windows Settings removes its installed program files and owned installer registry entries, while manually deleting %LOCALAPPDATA%\OZViewer\ removes your local preferences (settings.json).

PikaSnip

Effective 25 November 2026 · PikaSnip v0.1.0+

PikaSnip runs 100% offline on your Windows device. It collects no personal data, uses no telemetry or analytics, shows no ads, and makes zero network connections. All screen captures, annotations, floating pins, and Thai/English OCR (powered by bundled OpenThai 2.1 models and Microsoft ONNX Runtime) are processed strictly locally.

  • Preferences are stored locally in settings.json beside PikaSnip.exe (Portable) or at %LOCALAPPDATA%\OZLab\PikaSnip\settings.json (MSIX).
  • Saved screenshots are written to %USERPROFILE%\Pictures\PikaSnip only when you explicitly choose Save (Ctrl+S).
  • Windows Startup is disabled by default (Enabled="false") and only runs if you explicitly enable it.
  • Read the standalone English and Thai policy at /privacy-pikasnip.html.

Support, donations & user control

  • Support & public issue trackers: Reports and questions submitted via GitHub issue trackers (see the Support page) are public and governed by GitHub's privacy policy. Please do not post personal data, credentials, or confidential documents.
  • Voluntary donations: Contributions through Ko-fi or PromptPay happen directly on Ko-fi or in your banking app. OZ Lab's website and desktop apps do not collect, process, or store payment details.
  • User control: Because OZ Lab operates no backend servers and collects no personal data, uninstalling through Windows Settings removes the installed program files (and PikaView's owned installer registry entries), while manually deleting %LOCALAPPDATA%\FastPDF\, %LOCALAPPDATA%\OZViewer\, and %LOCALAPPDATA%\OZLab\PikaSnip\ removes all retained local state, recent-file history, preferences, and diagnostic logs from your device.

นโยบายความเป็นส่วนตัว

หน้านี้คือนโยบายความเป็นส่วนตัวฉบับเผยแพร่สำหรับเว็บไซต์ OZ Lab แอป PikaPDF (เดิมชื่อ FastPDF) แอป PikaView (เดิมชื่อ OZ Image Viewer) และแอป PikaSnip

เว็บนี้ PikaPDF PikaView PikaSnip การช่วยเหลือ บริจาค และการควบคุมข้อมูล การปรับปรุงนโยบาย

เว็บนี้

ไม่มีการติดตาม
  • เว็บนี้เป็นหน้า HTML และ CSS แบบสถิต ไม่มีการติดตาม การวิเคราะห์ หรือโฆษณา
  • ไม่ตั้งคุกกี้ของตัวเอง ไม่โหลดฟอนต์จากภายนอก และไม่มีสคริปต์ติดตามจากบุคคลที่สาม
  • ไม่มีแบบฟอร์ม ไม่มีการลงชื่อเข้าใช้ และไม่มีบัญชีผู้ใช้

เว็บไซต์ทางการโฮสต์อยู่บน Cloudflare Pages (ozlab.pages.dev) โดยมี GitHub Pages (underoatz-netizen.github.io) เป็นเว็บสำรอง เมื่อให้บริการหน้าเว็บ Cloudflare หรือ GitHub อาจประมวลผลข้อมูลการเชื่อมต่อทางเทคนิคมาตรฐาน (เช่น ที่อยู่ IP และส่วนหัวของคำขอ) ภายใต้นโยบายความเป็นส่วนตัวของผู้ให้บริการแต่ละราย โดย OZ Lab ไม่ได้เก็บรวบรวมข้อมูลดังกล่าว

PikaPDF (เดิมชื่อ FastPDF)

มีผลบังคับใช้ 19 พฤศจิกายน 2026 · PikaPDF v0.5.0+

นโยบายฉบับเผยแพร่ · มีผลบังคับใช้ 19 พฤศจิกายน 2026 · PikaPDF v0.5.0+

PikaPDF เป็นโปรแกรมบนเดสก์ท็อปสำหรับ Windows ที่ทำงานแบบออฟไลน์เป็นหลัก ไม่มีบัญชีผู้ใช้ ไม่มีการเข้าสู่ระบบ ไม่มี telemetry ไม่มีการวิเคราะห์ ไม่มีโฆษณา ไม่ส่งรายงานข้อผิดพลาด และไม่มีบริการเครือข่ายเบื้องหลัง

การทำงานแบบออฟไลน์และประมวลผลในเครื่อง

การเปิดอ่านเอกสาร PDF การค้นหา การวาดและไฮไลต์ การจับภาพหน้าจอ การส่งออกเป็น PNG การรวมรูปภาพเป็น PDF และการพิมพ์ทั้งหมดประมวลผลภายในเครื่องของคุณ เนื้อหาในเอกสารไม่เคยถูกอัปโหลดหรือส่งออกไปภายนอกโดย PikaPDF

ไฟล์ที่เก็บไว้ในเครื่องของคุณ

PikaPDF เก็บไฟล์สถานะขนาดเล็กไว้ในเครื่องที่โฟลเดอร์ %LOCALAPPDATA%\FastPDF\ (ยังคงใช้โฟลเดอร์ชื่อเดิม FastPDF เพื่อให้การอัปเกรดจาก FastPDF 0.4.1 รักษารายการไฟล์ล่าสุดและการตั้งค่าเดิมไว้ได้):

  • recent.dat — เส้นทางไฟล์ รวมถึงตำแหน่งการอ่านและระดับการซูมของเอกสาร PDF ที่เปิดล่าสุด เพื่อให้เมนู Recent Files และการเปิดอ่านต่อจากเดิมใช้งานข้ามเซสชันได้
  • fastpdf.log / fastpdf.log.1 — บันทึกการวินิจฉัยในเครื่องที่เขียนขึ้นโดยอัตโนมัติระหว่างการใช้งานปกติ (หมุนไฟล์เมื่อขนาดประมาณ 1 MB) ซึ่งบันทึกเวลาท้องถิ่น เหตุการณ์สถานะ/การวินิจฉัย และเส้นทางไฟล์ของเอกสาร PDF ที่เปิดหรือบันทึก (หมายเหตุ: ปุ่ม Ctrl+D ใช้สลับแสดงแถบข้อมูลวินิจฉัยบนหน้าจอเท่านั้น)

ไฟล์เหล่านี้ไม่ออกจากเครื่องของคุณ ไม่ถูกลบอัตโนมัติเมื่อถอนการติดตั้ง และคุณสามารถลบเองได้ทุกเมื่อ

การตรวจสอบอัปเดตเมื่อผู้ใช้สั่งเอง (ตัวเลือกเสริม)

การเชื่อมต่อเครือข่ายเพียงอย่างเดียวของ PikaPDF จะทำงานเฉพาะเมื่อคุณกดคำสั่ง More commands > Check for Updates ด้วยตัวเองเท่านั้น ไม่เคยทำงานอัตโนมัติตอนเปิดโปรแกรม ตามเวลา หรือในเบื้องหลัง

  • เมื่อกดใช้งาน PikaPDF จะส่งคำขอ HTTPS GET เพียงครั้งเดียวพร้อมส่วนหัว User-Agent: PikaPDF/<version> ไปยังปลายทางคงที่ https://api.github.com/repos/underoatz-netizen/FastPDF-Downloads/releases/latest โดยตรวจสอบใบรับรองผ่านระบบของ Windows มีตัวกำหนดหมดเวลา และจำกัดขนาดข้อมูลตอบกลับไว้ที่ 64 KB
  • อ่านเฉพาะฟิลด์ tag_name เพื่อตรวจว่ามีรุ่นใหม่กว่าหรือไม่
  • ไม่มีการดาวน์โหลดหรือติดตั้งไฟล์อัตโนมัติ เฉพาะเมื่อคุณกดยืนยันเปิดหน้ารีลีสเท่านั้น PikaPDF จึงจะเปิด https://github.com/underoatz-netizen/FastPDF-Downloads/releases ในเบราว์เซอร์เริ่มต้นของคุณ
  • ข้อมูลเมตาการเชื่อมต่อมาตรฐาน (เช่น ที่อยู่ IP และรายละเอียดคำขอ) สำหรับคำขอดังกล่าวจะถูกประมวลผลโดย GitHub ภายใต้นโยบายความเป็นส่วนตัวของ GitHub

PikaView (เดิมชื่อ OZ Image Viewer)

มีผลบังคับใช้ 19 พฤศจิกายน 2026 · PikaView v0.1.1+

PikaView เป็นโปรแกรมดูรูปภาพบนเดสก์ท็อปสำหรับ Windows ที่ทำงานแบบออฟไลน์ทั้งหมด ไม่มีการเชื่อมต่อเครือข่าย ไม่มี telemetry ไม่มีบริการเบื้องหลัง และไม่มีระบบอัปเดตอัตโนมัติ

  • ค่ากำหนดการใช้งานในเครื่องจะบันทึกไว้ที่ %LOCALAPPDATA%\OZViewer\settings.json
  • หากติดตั้งด้วยตัวติดตั้งสำหรับผู้ใช้รายเดียว (per-user installer) อาจมีรายการติดตั้งในเครื่องอยู่ที่ %LOCALAPPDATA%\Programs\OZ Image Viewer และ HKCU\Software\OZImageViewer
  • การถอนการติดตั้ง PikaView ผ่าน Windows Settings จะลบไฟล์โปรแกรมที่ติดตั้งไว้และรายการรีจิสทรีของตัวติดตั้ง ส่วนการลบโฟลเดอร์ %LOCALAPPDATA%\OZViewer\ ออกด้วยตัวเองจะลบค่ากำหนดในเครื่อง (settings.json)

PikaSnip

มีผลบังคับใช้ 25 พฤศจิกายน 2026 · PikaSnip v0.1.0+

PikaSnip ทำงานแบบออฟไลน์ 100% บนเครื่อง Windows ของคุณ ไม่เก็บข้อมูลส่วนบุคคล ไม่ส่ง telemetry หรือสถิติการใช้งาน ไม่มีโฆษณา และไม่เชื่อมต่อเครือข่ายใด ๆ การจับภาพหน้าจอ การวาดแก้ไข การปักหมุดภาพลอย และ OCR ภาษาไทย/อังกฤษ (ขับเคลื่อนด้วยโมเดล OpenThai 2.1 และ Microsoft ONNX Runtime ที่รวมมาในเครื่อง) ประมวลผลในเครื่องทั้งหมด

  • การตั้งค่าถูกเก็บในเครื่องที่ settings.json ข้างไฟล์ PikaSnip.exe (รุ่น Portable) หรือที่ %LOCALAPPDATA%\OZLab\PikaSnip\settings.json (รุ่น MSIX)
  • ภาพหน้าจอจะถูกบันทึกเป็นไฟล์ PNG ลงใน %USERPROFILE%\Pictures\PikaSnip เฉพาะเมื่อคุณสั่งบันทึก (Ctrl+S) เท่านั้น
  • การเปิดพร้อม Windows ถูกปิดไว้เป็นค่าเริ่มต้น (Enabled="false") และจะทำงานเฉพาะเมื่อคุณเปิดใช้งานด้วยตนเอง
  • อ่านนโยบายฉบับเต็ม (ภาษาอังกฤษและภาษาไทย) ได้ที่ /privacy-pikasnip.html

การช่วยเหลือ การบริจาค และการควบคุมข้อมูล

  • การช่วยเหลือและตัวติดตามปัญหาสาธารณะ: รายงานปัญหาและคำถามที่ส่งผ่าน GitHub issue trackers (ดูหน้า ช่วยเหลือ) เป็นข้อมูลสาธารณะและอยู่ภายใต้นโยบายความเป็นส่วนตัวของ GitHub โปรดอย่าโพสต์ข้อมูลส่วนบุคคล ข้อมูลรับรอง หรือเอกสารลับ
  • การบริจาคโดยสมัครใจ: การสนับสนุนผ่าน Ko-fi หรือ PromptPay เกิดขึ้นโดยตรงบน Ko-fi หรือในแอปธนาคารของคุณ เว็บไซต์และแอปของ OZ Lab ไม่ได้ประมวลผลหรือจัดเก็บข้อมูลการชำระเงิน
  • การควบคุมโดยผู้ใช้: เนื่องจาก OZ Lab ไม่มีเซิร์ฟเวอร์ฝั่งหลังบ้านและไม่ได้เก็บข้อมูลส่วนบุคคล การถอนการติดตั้งผ่าน Windows Settings จะลบไฟล์โปรแกรมที่ติดตั้งไว้ (และรายการรีจิสทรีของตัวติดตั้ง PikaView) ส่วนการลบโฟลเดอร์ %LOCALAPPDATA%\FastPDF\, %LOCALAPPDATA%\OZViewer\ และ %LOCALAPPDATA%\OZLab\PikaSnip\ ออกด้วยตัวเองจะลบสถานะแอป ประวัติไฟล์ล่าสุด ค่ากำหนด และบันทึกการวินิจฉัยที่เหลืออยู่ทั้งหมดออกจากอุปกรณ์ของคุณ

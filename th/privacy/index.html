English

ความเป็นส่วนตัว

หน้านี้ครอบคลุมสองเรื่องที่แยกจากกัน คือเว็บนี้ และแอปพลิเคชัน FastPDF

เว็บนี้

  • เว็บนี้เป็นชุดหน้าไฟล์สถิต ไม่มีการติดตาม การวิเคราะห์ หรือโฆษณา
  • เว็บนี้ไม่ตั้งคุกกี้ของตัวเอง
  • เว็บนี้ไม่มีแบบฟอร์ม ไม่มีการลงชื่อเข้าใช้ และไม่มีบัญชีผู้ใช้
  • เว็บนี้ไม่โหลดสคริปต์วิเคราะห์หรือติดตามจากบริษัทอื่น

เว็บนี้โฮสต์อยู่บน GitHub Pages ในฐานะผู้ให้บริการโฮสต์ GitHub อาจประมวลผล ข้อมูลทางเทคนิคมาตรฐาน (เช่น ที่อยู่ IP และรายละเอียดคำขอ) ขณะให้บริการหน้าเว็บ ภายใต้นโยบายของ GitHub เอง นั่นเป็นการประมวลผลของผู้ให้บริการโฮสต์ ไม่ใช่สิ่งที่เว็บนี้เก็บรวบรวม

แอปพลิเคชัน FastPDF

ฉบับร่าง — รอการอนุมัติจากเจ้าของ

นโยบายความเป็นส่วนตัวของแอปพลิเคชัน FastPDF ยังเป็นฉบับร่าง ยังไม่ได้รับการอนุมัติ ยังไม่มีผลบังคับใช้ และจงใจไม่เผยแพร่ บนหน้านี้ จนกว่าจะสรุปและได้รับอนุมัติ หน้านี้จะไม่ให้คำมั่นใด ๆ เกี่ยวกับ การจัดการข้อมูลของแอปพลิเคชัน

คำถาม

หากมีคำถามเกี่ยวกับการรายงานปัญหาหรือความเป็นส่วนตัว โปรดดูหน้า ช่วยเหลือ

ช่องทางติดต่อและสนับสนุนผู้พัฒนา

ช่วยเหลือและการบริจาค

ช่องทางขอความช่วยเหลือเกี่ยวกับ PikaPDF (เดิมชื่อ FastPDF) และสถานะการบริจาคในปัจจุบัน

การขอความช่วยเหลือ

ระบบแจ้งปัญหาสาธารณะ

การช่วยเหลือดำเนินการผ่านระบบแจ้งปัญหาสาธารณะของโปรเจกต์ คุณสามารถอ่านรายงานที่มีอยู่เดิม หรือเปิดรายการใหม่ได้ที่นั่น:

ระบบแจ้งปัญหา PikaPDF (เดิมชื่อ FastPDF) บน GitHub

เมื่อรายงานปัญหา โปรดอย่าใส่เอกสารที่เป็นความลับ ข้อมูลส่วนบุคคล รหัสผ่าน คีย์ไลเซนส์ หรือข้อมูลอ่อนไหวอื่น ๆ ให้อธิบายปัญหาเป็นข้อความแทน โดยใส่เฉพาะรายละเอียดที่จำเป็นต่อการเข้าใจปัญหา

เราไม่สัญญาเรื่องเวลาตอบกลับ กำหนดการแก้ไข หรือฟีเจอร์ใหม่ ในตอนนี้ไม่มีอีเมล เบอร์โทรศัพท์ หรือแบบฟอร์มติดต่อสำหรับการช่วยเหลือ

การสนับสนุนและร่วมบริจาคให้ OZ Lab

ตามความสมัครใจ

PikaPDF (เดิมชื่อ FastPDF) เป็นฟรีแวร์ (Freeware) ที่เปิดให้ใช้งานได้โดยไม่มีค่าใช้จ่าย ทุกฟีเจอร์สามารถใช้งานได้เต็มรูปแบบโดยไม่ต้องชำระเงิน ไม่มีการจำกัดฟังก์ชัน และตัวโปรแกรมจะไม่มีหน้าต่างแจ้งเตือนหรือรบกวนเพื่อขอรับบริจาคอย่างแน่นอน

หากคุณพบว่า PikaPDF หรือผลงานของพวกเรามีประโยชน์ และต้องการร่วมสนับสนุนค่าใช้จ่ายในการพัฒนาและดูแลระบบ คุณสามารถร่วมสนับสนุนตามความสมัครใจได้ตามช่องทางด้านล่างนี้:

สำหรับผู้สนับสนุนจากต่างประเทศ (Ko-fi)

สากล

ผู้สนับสนุนจากต่างประเทศหรือผู้ที่ต้องการชำระผ่านช่องทางสากล สามารถร่วมสนับสนุนได้ทาง Ko-fi:

สนับสนุน OZ Lab ผ่าน Ko-fi (ko-fi.com/ozlab)

สำหรับผู้สนับสนุนในประเทศไทย (พร้อมเพย์ / PromptPay)

THB · QR

สำหรับผู้สนับสนุนในประเทศไทย สามารถสแกนคิวอาร์โค้ดพร้อมเพย์ผ่านแอปพลิเคชันธนาคารบนมือถือได้โดยตรง:

หมายเหตุความปลอดภัยและความเป็นส่วนตัว: เว็บไซต์นี้เป็นเว็บสถิต (Static Website) ไม่มีการฝังสคริปต์รับชำระเงินภายนอก ไม่มีโค้ดติดตาม และไม่มีแบบฟอร์มเก็บข้อมูลใด ๆ การทำธุรกรรมทั้งหมดจะดำเนินไปบนแพลตฟอร์มปลายทาง (Ko-fi) หรือภายในแอปธนาคารของท่านเองโดยตรงอย่างปลอดภัย โปรดตรวจสอบชื่อบัญชีผู้รับเงินให้ตรงกับชื่อที่แสดงบนภาพก่อนยืนยันการโอน

หมายเหตุด้านความเป็นส่วนตัว

หากคุณโพสต์รายการปัญหา ข้อมูลที่คุณเลือกเขียนจะถูกจัดการโดย GitHub ภายใต้นโยบายของ GitHub เอง ดูรายละเอียดเพิ่มเติมได้ที่หน้า ความเป็นส่วนตัว

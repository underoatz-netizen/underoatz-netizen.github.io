ช่วยเหลือและการบริจาค

ช่องทางขอความช่วยเหลือเกี่ยวกับ FastPDF และสถานะการบริจาคในปัจจุบัน

การขอความช่วยเหลือ

การช่วยเหลือดำเนินการผ่านระบบแจ้งปัญหาสาธารณะของโปรเจกต์ คุณสามารถอ่าน รายงานที่มีอยู่เดิม หรือเปิดรายการใหม่ได้ที่นั่น:

ระบบแจ้งปัญหา FastPDF บน GitHub

เมื่อรายงานปัญหา โปรดอย่าใส่เอกสารที่เป็นความลับ ข้อมูล ส่วนบุคคล รหัสผ่าน คีย์ไลเซนส์ หรือข้อมูลอ่อนไหวอื่น ๆ ให้อธิบายปัญหาเป็น ข้อความแทน โดยใส่เฉพาะรายละเอียดที่จำเป็นต่อการเข้าใจปัญหา

เราไม่สัญญาเรื่องเวลาตอบกลับ กำหนดการแก้ไข หรือฟีเจอร์ใหม่ ในตอนนี้ไม่มี อีเมล เบอร์โทรศัพท์ หรือแบบฟอร์มติดต่อสำหรับการช่วยเหลือ

การบริจาค

ไม่มีการขอหรือรับบริจาค ไม่มีลิงก์บริจาค บัญชี หรือช่องทาง ชำระเงินใด ๆ และโปรเจกต์ไม่ขอหรือเก็บข้อมูลการชำระเงิน

หากเรื่องนี้เปลี่ยนแปลงในอนาคต รายละเอียดจะประกาศให้ชัดเจนบนหน้านี้ จนถึงตอนนั้น หากมีคำขอชำระเงินหรือบริจาคที่อ้างว่ามาจาก OZ Lab หรือ FastPDF โปรดถือว่าไม่เป็นทางการ

หมายเหตุด้านความเป็นส่วนตัว

หากคุณโพสต์รายการปัญหา ข้อมูลที่คุณเลือกเขียนจะถูกจัดการโดย GitHub ภายใต้ นโยบายของ GitHub เอง ดูรายละเอียดเพิ่มเติมได้ที่หน้า ความเป็นส่วนตัว

ซอฟต์แวร์

หน้านี้รวมผลิตภัณฑ์ที่เราเผยแพร่ข้อมูลบนเว็บนี้ ตอนนี้มีสองอย่าง คือ FastPDF และ OZ Image Viewer

ผลิตภัณฑ์

  • FastPDF

    โปรแกรมบนเดสก์ท็อปสำหรับ Windows ใช้เปิดและทำงานกับเอกสาร PDF: อ่าน ค้นหา นำเสนอ จับภาพ ส่งออกเป็นรูปภาพ รวมรูปภาพเป็น PDF และพิมพ์

    สถานะ: เวอร์ชัน 0.4.0 พร้อมให้ดาวน์โหลดสำหรับ Windows x64

  • OZ Image Viewer

    โปรแกรมดูรูปภาพบนเดสก์ท็อปสำหรับ Windows รองรับไฟล์ภาพนิ่งทั่วไป แสดงภาพแรกอย่างรวดเร็ว ซูมและเลื่อนภาพได้ลื่นไหล เลื่อนดูภาพในโฟลเดอร์ และแก้ไขแบบไม่ทำลายต้นฉบับ

    สถานะ: อยู่ระหว่างการพัฒนา ยังไม่มีรุ่นสาธารณะ

ผลิตภัณฑ์อื่น

ตอนนี้ FastPDF และ OZ Image Viewer เป็นผลิตภัณฑ์ที่เราเผยแพร่ข้อมูลแล้ว เมื่อมีอะไรใหม่พร้อมเผยแพร่ จะแสดงไว้ที่นี่

ซอฟต์แวร์

หน้านี้รวมผลิตภัณฑ์ที่เราเผยแพร่ข้อมูลบนเว็บนี้ ตอนนี้มีสองอย่าง คือ PikaPDF (เดิมชื่อ FastPDF) และ PikaView (เดิมชื่อ OZ Image Viewer)

ผลิตภัณฑ์

เผยแพร่แล้ว 2 รายการ

  • PikaPDF (เดิมชื่อ FastPDF)

    v0.5.0 · Windows x64

    โปรแกรมบนเดสก์ท็อปสำหรับ Windows ใช้เปิดและทำงานกับเอกสาร PDF: อ่าน ค้นหา ใส่คำอธิบายประกอบ นำเสนอ จับภาพ ส่งออกเป็นรูปภาพ รวมรูปภาพเป็น PDF และพิมพ์

    สถานะ: เวอร์ชัน 0.5.0 พร้อมให้ดาวน์โหลดสำหรับ Windows x64

    ดาวน์โหลด ภาพรวม คู่มือ

  • PikaView (เดิมชื่อ OZ Image Viewer)

    v0.1.2 · Windows x64

    โปรแกรมดูรูปภาพบนเดสก์ท็อปสำหรับ Windows รองรับไฟล์ภาพนิ่งทั่วไป แสดงภาพแรกอย่างรวดเร็ว ซูมและเลื่อนภาพได้ลื่นไหล เลื่อนดูภาพในโฟลเดอร์ แก้ไขแบบไม่ทำลายต้นฉบับ และพิมพ์

    สถานะ: เวอร์ชัน 0.1.2 พร้อมให้ดาวน์โหลดสำหรับ Windows x64

    ดาวน์โหลด ภาพรวม คู่มือ

ผลิตภัณฑ์อื่น

แผนงาน

ตอนนี้ PikaPDF (เดิมชื่อ FastPDF) และ PikaView (เดิมชื่อ OZ Image Viewer) เป็นผลิตภัณฑ์ที่เราเผยแพร่ข้อมูลแล้ว เมื่อมีอะไรใหม่พร้อมเผยแพร่ จะแสดงไว้ที่นี่

OZ Lab

โปรแกรมบนเดสก์ท็อปสำหรับ Windows จาก OZ Lab เว็บนี้เป็นไฟล์สถิตและไม่มีการติดตามหรือวิเคราะห์ผู้ใช้

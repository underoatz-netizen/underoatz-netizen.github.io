บันทึกการเปลี่ยนแปลง

ประวัติรุ่นและการพัฒนาของ PikaView (เดิมชื่อ OZ Image Viewer)

เวอร์ชัน 0.1.1 — 18 พฤศจิกายน 2026

เปลี่ยนชื่อเป็น PikaView เส้นทางการพิมพ์ PrintDlgExW และแพ็กเกจพร้อม provenance สำหรับ Windows 64-บิต

เวอร์ชัน 0.1.1 สืบเนื่องจาก OZ Image Viewer ภายใต้ชื่อผลิตภัณฑ์ PikaView โดยยังคงข้อมูลระบุตัวตนภายในสำหรับการอัปเกรด เพื่อให้การติดตั้งแบบต่อผู้ใช้รุ่น 0.1.0 เดิมสามารถอัปเกรดทับในตำแหน่งเดิมได้อย่างราบรื่น

ข้อมูลระบุตัวตนและการอัปเกรดในตำแหน่งเดิม

  • เปลี่ยนชื่อเป็น PikaView: ชื่อผลิตภัณฑ์สำหรับผู้ใช้ ป้ายชื่อในตัวติดตั้ง ชอร์ตคัต และแพ็กเกจรุ่นนี้เปลี่ยนเป็น PikaView (เดิมชื่อ OZ Image Viewer)
  • ความต่อเนื่องของการอัปเกรดจาก 0.1.0: ยังคงชื่อไฟล์โปรแกรม ozviewer.exe โฟลเดอร์ติดตั้งต่อผู้ใช้ (%LOCALAPPDATA%\Programs\OZ Image Viewer) ค่า AppId ที่คงที่ ProgID OZImageViewer.Image และโครงสร้างรีจิสทรี HKCU\Software\OZImageViewer การอัปเกรดจาก 0.1.0 จะปรับป้ายชื่อในตำแหน่งเดิมโดยไม่แก้ไขค่าเริ่มต้นการเปิดไฟล์ของ Windows (UserChoice)

การพิมพ์แบบโต้ตอบและข้อจำกัดของหลักฐาน

  • เส้นทางการพิมพ์ภาพเดี่ยวผ่าน PrintDlgExW: คำสั่งพิมพ์ (File -> Print... หรือ Ctrl+P) ใช้ตัวช่วย PrintDlgExW แยกเฉพาะพร้อมวงจรชีวิต COM แบบ STA ที่จำกัดขอบเขต การจัดการผลลัพธ์ยกเลิก/ใช้งาน/ล้มเหลวอย่างชัดเจน การเก็บคืน DevMode/DevNames/HDC ครบถ้วน และตัวป้องกันการเรียกซ้ำเพื่อเตรียมหนึ่งหน้าพอดีกระดาษจากภาพที่ยืนยันแล้วโดยไม่แก้ไขไฟล์ต้นฉบับ
  • ขอบเขตของหลักฐานตามจริง: ข้อสังเกตเรื่องการพิมพ์ออกหน้ากระดาษจริงและพฤติกรรมการกด Cancel ครั้งที่สองเป็นข้อมูลเชิงประวัติศาสตร์จากแคนดิเดตและสภาพแวดล้อมก่อนหน้า ไม่ใช่ผลการทดสอบกับเครื่องพิมพ์จริงที่รันซ้ำในรุ่น v0.1.1 นี้ กรณีเครื่องพิมพ์เครือข่าย failed-network-first ยังไม่ได้ทดสอบ และไม่มีการอ้างว่าอาการค้างของกล่องโต้ตอบพิมพ์ทั้งหมดได้รับการแก้ไขแล้ว
  • ปิดไดแอกนอสติกในรุ่น Release: คอมไพล์ด้วยค่า OZVIEWER_PRINT_DIAGNOSTICS=OFF

Provenance การตรวจสอบ และแพ็กเกจ

  • การตรวจสอบ provenance ของ dependency: ไฟล์ BUILD-PROVENANCE.json ผูกไบต์ของ heif.dll และ libde265.dll เข้ากับค่าสร้าง vcpkg oz-x64-windows-static-md สูตร/แพตช์ที่ปักหมุด และไฟล์ pikaview-0.1.1-lgpl-corresponding-source.zip
  • การทดสอบวงจรชีวิตในระบบ CI แบบ clean-room: การรัน GitHub Actions CI หมายเลข 44229309225 บน Windows Server 2022 (x64) ผ่าน fetch-candidate และ validate-candidate (ชุดทดสอบ disposable lifecycle: 48 รายการ โดยผ่าน 47 รายการ และมีคำเตือน non_admin_integrity_check ตามคาด 1 รายการ; พร้อมเกต standard-user-lifecycle: ผ่าน 12/12 รายการฝั่ง parent + 48/48 รายการฝั่ง child ในบัญชีผู้ใช้ทั่วไปแบบไม่ยกระดับสิทธิ์) ครอบคลุมการติดตั้งใหม่ การทดสอบ FirstPresent benchmark การเชื่อมโยงนามสกุลไฟล์และชอร์ตคัตแบบเลือกเอง การอัปเกรดในตำแหน่งเดิม v0.1.0 -> v0.1.1 การตรวจแฮชรันไทม์ การคงค่า UserChoice ครบทั้ง 14 นามสกุล และการถอนการติดตั้งอย่างหมดจด
  • แพ็กเกจรุ่น v0.1.1 จำนวน 4 ไฟล์: pikaview-0.1.1-win-x64-installer.exe, pikaview-0.1.1-win-x64-portable.zip, pikaview-0.1.1-lgpl-corresponding-source.zip และ SHA256SUMS (ไฟล์ไบนารีของโปรเจกต์ยังไม่ได้ลงลายเซ็น / NotSigned; ส่วน Microsoft VC143 CRT DLL มีลายเซ็นของ Microsoft)

เวอร์ชัน 0.1.0

รุ่นแรกสำหรับ Windows แบบ 64-บิต

เวอร์ชัน 0.1.0 เป็นรุ่นแรกของ OZ Image Viewer โปรแกรมดูภาพที่เร็วและขนาดกะทัดรัด พัฒนาด้วย C++23, Direct3D 11, DXGI และ Direct2D สำหรับระบบปฏิบัติการ Windows x64

การดูภาพและการเลื่อนดู

  • เปิดไฟล์ภาพหลากหลายรูปแบบ: ตรวจจับประเภทไฟล์จากโครงสร้างข้อมูลไบนารีโดยตรง รองรับ JPEG, PNG, static WebP, BMP, static GIF, TIFF (หน้าแรก), ICO, CUR, TGA และ AVIF
  • รองรับไฟล์ HEIC/HEIF: รองรับการเปิดดูภาพนิ่ง HEIC/HEIF ผ่านการโหลดโมดูลไดนามิก (heif.dll และ libde265.dll) ภายใต้สัญญาอนุญาต LGPLv3
  • เปิดภาพแรกอย่างรวดเร็ว: แสดงภาพที่เลือกให้พอดีกับหน้าต่างทันที พร้อมทั้งอ่านรายชื่อไฟล์อื่นในโฟลเดอร์เดียวกันและโหลดภาพถัดไปไว้ล่วงหน้าในเบื้องหลัง
  • การเลื่อนดูภาพที่สะดวก: ใช้ปุ่มลูกศรซ้าย/ขวา หรือ Spacebar เพื่อดูภาพก่อนหน้าหรือถัดไปในโฟลเดอร์เดียวกัน
  • การซูมและเลื่อนภาพ: ซูมภาพโดยอิงตำแหน่งตัวชี้เมาส์ สลับระหว่างมุมมองพอดีหน้าต่าง (F) และขนาดจริง 100% (1 หรือดับเบิลคลิก) เลื่อนภาพด้วยการลากเมาส์ และดูภาพแบบเต็มหน้าจอ (F11)

การปรับแต่งภาพแบบไม่ทำลายต้นฉบับ

  • การหมุนและพลิกภาพ: หมุนภาพ 90 องศาซ้ายหรือขวา (Ctrl+L, Ctrl+R) และพลิกภาพแนวนอนหรือแนวตั้ง (Ctrl+Shift+H, Ctrl+Shift+V)
  • การครอปและปรับขนาด: โหมดครอปภาพแบบเห็นผลลัพธ์ทันที (C) และหน้าต่างปรับขนาดความละเอียดพิกเซล (Ctrl+Alt+R)
  • เลิกทำและทำซ้ำ (Undo/Redo): การปรับแต่งภาพจะเปลี่ยนเฉพาะการแสดงผลในหน่วยความจำ ไม่แก้ไขไฟล์ต้นฉบับจนกว่าจะสั่งบันทึก
  • การบันทึกไฟล์: บันทึกทับหรือบันทึกเป็นไฟล์ใหม่ในรูปแบบ PNG, JPEG, WebP (lossless), BMP หรือ TIFF

แพ็กเกจและการติดตั้ง

  • ตัวติดตั้งสำหรับ Windows (Setup Installer): ติดตั้งลงในโฟลเดอร์เฉพาะของผู้ใช้ (%LOCALAPPDATA%\Programs\OZ Image Viewer) โดยไม่ต้องใช้สิทธิ์ระดับผู้ดูแลระบบ (Admin) ไม่ผูกนามสกุลไฟล์โดยพลการ
  • ไฟล์ ZIP แบบพกพา (Portable ZIP): แตกไฟล์แล้วเปิดใช้งานได้ทันทีโดยไม่ต้องติดตั้งหรือแก้ไขค่าระบบ
  • ซอร์สโค้ดส่วนประกอบ LGPL: เผยแพร่ซอร์สโค้ดและวิธีคอมไพล์สำหรับ libheif และ libde265 ครบถ้วนตามเงื่อนไข LGPLv3 ข้อ 4 และ GPLv3 ข้อ 6(d)
  • การตรวจสอบความถูกต้อง: ระบุค่าแฮช SHA-256 ทางการสำหรับทุกแพ็กเกจ

เวอร์ชัน 0.1.0

รุ่นแรกสำหรับ Windows แบบ 64-บิต

เวอร์ชัน 0.1.0 เป็นรุ่นแรกของ OZ Image Viewer โปรแกรมดูภาพที่เร็วและขนาดกะทัดรัด พัฒนาด้วย C++23, Direct3D 11, DXGI และ Direct2D สำหรับระบบปฏิบัติการ Windows x64

การดูภาพและการเลื่อนดู

  • เปิดไฟล์ภาพหลากหลายรูปแบบ: ตรวจจับประเภทไฟล์จากโครงสร้างข้อมูลไบนารีโดยตรง รองรับ JPEG, PNG, static WebP, BMP, static GIF, TIFF (หน้าแรก), ICO, CUR, TGA และ AVIF
  • รองรับไฟล์ HEIC/HEIF: รองรับการเปิดดูภาพนิ่ง HEIC/HEIF ผ่านการโหลดโมดูลไดนามิก (heif.dll และ libde265.dll) ภายใต้สัญญาอนุญาต LGPLv3
  • เปิดภาพแรกอย่างรวดเร็ว: แสดงภาพที่เลือกให้พอดีกับหน้าต่างทันที พร้อมทั้งอ่านรายชื่อไฟล์อื่นในโฟลเดอร์เดียวกันและโหลดภาพถัดไปไว้ล่วงหน้าในเบื้องหลัง
  • การเลื่อนดูภาพที่สะดวก: ใช้ปุ่มลูกศรซ้าย/ขวา หรือ Spacebar เพื่อดูภาพก่อนหน้าหรือถัดไปในโฟลเดอร์เดียวกัน
  • การซูมและเลื่อนภาพ: ซูมภาพโดยอิงตำแหน่งตัวชี้เมาส์ สลับระหว่างมุมมองพอดีหน้าต่าง (F) และขนาดจริง 100% (1 หรือดับเบิลคลิก) เลื่อนภาพด้วยการลากเมาส์ และดูภาพแบบเต็มหน้าจอ (F11)

การปรับแต่งภาพแบบไม่ทำลายต้นฉบับ

  • การหมุนและพลิกภาพ: หมุนภาพ 90 องศาซ้ายหรือขวา (Ctrl+L, Ctrl+R) และพลิกภาพแนวนอนหรือแนวตั้ง (Ctrl+Shift+H, Ctrl+Shift+V)
  • การครอปและปรับขนาด: โหมดครอปภาพแบบเห็นผลลัพธ์ทันที (C) และหน้าต่างปรับขนาดความละเอียดพิกเซล (Ctrl+Alt+R)
  • เลิกทำและทำซ้ำ (Undo/Redo): การปรับแต่งภาพจะเปลี่ยนเฉพาะการแสดงผลในหน่วยความจำ ไม่แก้ไขไฟล์ต้นฉบับจนกว่าจะสั่งบันทึก
  • การบันทึกไฟล์: บันทึกทับหรือบันทึกเป็นไฟล์ใหม่ในรูปแบบ PNG, JPEG, WebP (lossless), BMP หรือ TIFF

แพ็กเกจและการติดตั้ง

  • ตัวติดตั้งสำหรับ Windows (Setup Installer): ติดตั้งลงในโฟลเดอร์เฉพาะของผู้ใช้ (%LOCALAPPDATA%\Programs\OZ Image Viewer) โดยไม่ต้องใช้สิทธิ์ระดับผู้ดูแลระบบ (Admin) ไม่ผูกนามสกุลไฟล์โดยพลการ
  • ไฟล์ ZIP แบบพกพา (Portable ZIP): แตกไฟล์แล้วเปิดใช้งานได้ทันทีโดยไม่ต้องติดตั้งหรือแก้ไขค่าระบบ
  • ซอร์สโค้ดส่วนประกอบ LGPL: เผยแพร่ซอร์สโค้ดและวิธีคอมไพล์สำหรับ libheif และ libde265 ครบถ้วนตามเงื่อนไข LGPLv3 ข้อ 4 และ GPLv3 ข้อ 6(d)
  • การตรวจสอบความถูกต้อง: ระบุค่าแฮช SHA-256 ทางการสำหรับทุกแพ็กเกจ

หน้าที่เกี่ยวข้อง

  • ดาวน์โหลด — ไฟล์ดาวน์โหลดทางการสำหรับ Windows และค่าแฮช SHA-256
  • คู่มือและคำถามที่พบบ่อย — ปุ่มลัด วิธีดูภาพ และคำถามทั่วไป
  • ภาพรวม OZ Image Viewer — ข้อมูลความสามารถและไฟล์ภาพที่รองรับ
  • คลังซอร์สโค้ดบน GitHub — ดูซอร์สโค้ด สคริปต์คอมไพล์ และแจ้งปัญหา

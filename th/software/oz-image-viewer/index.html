OZ Image Viewer

OZ Image Viewer เป็นโปรแกรมดูรูปภาพบนเดสก์ท็อปสำหรับ Windows พัฒนาโดย OZ Lab เปิดไฟล์ภาพนิ่งทั่วไปได้อย่างรวดเร็ว และให้คุณซูม เลื่อนดู และแก้ไขแบบง่าย ๆ โดยไม่ทำลายไฟล์ต้นฉบับ

อยู่ระหว่างการพัฒนา: OZ Image Viewer เวอร์ชัน 0.1.0 ยังอยู่ระหว่างการพัฒนา ยังไม่มีรุ่นสาธารณะให้ดาวน์โหลด และซอร์สโค้ดเป็น ส่วนตัว โปรเจกต์อยู่บน GitHub ที่ underoatz-netizen/oz-image-viewer

OZ Image Viewer ทำอะไรได้บ้าง

OZ Image Viewer เปิดรูปทีละภาพ เน้นการแสดงผลที่รวดเร็วและตอบสนองลื่นไหล ระหว่างดูรูป นี่คือความสามารถที่มีในตอนนี้:

  • เปิดและแสดงไฟล์ภาพนิ่งทั่วไป: JPEG, PNG, WebP แบบนิ่ง, BMP, GIF แบบนิ่ง, TIFF (หน้าแรก), ICO, CUR, TGA, AVIF และ HEIC/HEIF
  • แสดงภาพแรกอย่างรวดเร็ว โดยสแกนโฟลเดอร์และโหลดภาพข้างเคียงอยู่เบื้องหลัง
  • เลื่อนดูภาพอื่นในโฟลเดอร์เดียวกันด้วยคีย์บอร์ด และถอดรหัสภาพเมื่อเลือก
  • ซูมด้วยล้อเมาส์โดยยึดตำแหน่งเคอร์เซอร์ หรือใช้คีย์บอร์ด และเลื่อนภาพ ด้วยการลาก
  • มุมมองพอดีหน้าต่าง และ 100% พร้อมดับเบิลคลิกเพื่อสลับ
  • โหมดเต็มจอแบบไม่มีขอบบนจอปัจจุบัน
  • แก้ไขแบบไม่ทำลายต้นฉบับ: หมุน พลิก ครอป และย่อ/ขยาย พร้อมเลิกทำและ ทำซ้ำ ไฟล์ต้นฉบับไม่ถูกแก้จนกว่าคุณจะบันทึก
  • บันทึกและบันทึกเป็นเป็น PNG, JPEG, WebP (แบบไม่สูญเสียข้อมูล), TIFF (บันทึกเป็นเท่านั้น) และ BMP
  • เปิดภาพจากบรรทัดคำสั่ง หรือลากไฟล์หนึ่งไฟล์วางบนหน้าต่าง

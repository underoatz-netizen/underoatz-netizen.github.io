PikaView

PikaView (เดิมชื่อ OZ Image Viewer) เป็นโปรแกรมดูรูปภาพบนเดสก์ท็อปสำหรับ Windows พัฒนาโดย OZ Lab เปิดไฟล์ภาพนิ่งทั่วไปได้อย่างรวดเร็ว และให้คุณซูม เลื่อนดู สั่งพิมพ์ และแก้ไขแบบง่าย ๆ โดยไม่ทำลายไฟล์ต้นฉบับ

ดาวน์โหลด v0.1.2 คู่มือและคำถามที่พบบ่อย

การเผยแพร่รุ่น 0.1.2: มาพร้อมไอคอนแอป PikaView ใหม่ แถบคำสั่ง Lucide แถวเดียวความสูง 40-DIP ในหน้าตาโทนเข้มพร้อมเมนู More การแก้ไขบั๊กล้างแคช/พรีโหลดเมื่อบันทึก และคำแนะนำภาษาไทย/อังกฤษเมื่อพื้นที่จัดเก็บข้อมูลป้องกันการเขียนหรือไม่มีสิทธิ์ เวอร์ชัน 0.1.2 พร้อมให้ดาวน์โหลดสำหรับ Windows แบบ 64-บิต และสามารถอัปเกรดทับการติดตั้งรุ่น 0.1.0 หรือ 0.1.1 แบบต่อผู้ใช้เดิมได้ทันทีโดยยังคงใช้ ozviewer.exe และโฟลเดอร์ %LOCALAPPDATA%\Programs\OZ Image Viewer ดาวน์โหลดตัวติดตั้งหรือไฟล์ ZIP แบบพกพาได้ที่หน้า ดาวน์โหลด ซอร์สโค้ดเปิดเผยสาธารณะบน GitHub ที่ underoatz-netizen/oz-image-viewer

PikaView ทำอะไรได้บ้าง

ความสามารถหลัก 10 รายการ

PikaView เปิดรูปทีละภาพ เน้นการแสดงผลที่รวดเร็วและตอบสนองลื่นไหลระหว่างดูรูป นี่คือความสามารถที่มีในตอนนี้:

  • เปิดและแสดงไฟล์ภาพนิ่งทั่วไป: JPEG, PNG, WebP แบบนิ่ง, BMP, GIF แบบนิ่ง, TIFF (หน้าแรก), ICO, CUR, TGA, AVIF และ HEIC/HEIF
  • แสดงภาพแรกอย่างรวดเร็ว โดยสแกนโฟลเดอร์และโหลดภาพข้างเคียงอยู่เบื้องหลัง
  • เลื่อนดูภาพอื่นในโฟลเดอร์เดียวกันด้วยคีย์บอร์ด และถอดรหัสภาพเมื่อเลือก
  • ซูมด้วยล้อเมาส์โดยยึดตำแหน่งเคอร์เซอร์ หรือใช้คีย์บอร์ด และเลื่อนภาพด้วยการลาก
  • มุมมองพอดีหน้าต่าง และ 100% พร้อมดับเบิลคลิกเพื่อสลับ
  • โหมดเต็มจอแบบไม่มีขอบบนจอปัจจุบัน
  • แก้ไขแบบไม่ทำลายต้นฉบับ: หมุน พลิก ครอป และย่อ/ขยาย พร้อมเลิกทำและทำซ้ำ ไฟล์ต้นฉบับไม่ถูกแก้จนกว่าคุณจะบันทึก
  • พิมพ์ภาพเดี่ยวแบบโต้ตอบ (More -> Print... หรือ Ctrl+P): เตรียมผลลัพธ์หนึ่งหน้าพอดีกระดาษจากภาพที่ยืนยันแล้วโดยไม่แก้ไขไฟล์ต้นฉบับ
  • บันทึกและบันทึกเป็นเป็น PNG, JPEG, WebP (แบบไม่สูญเสียข้อมูล), TIFF (บันทึกเป็นเท่านั้น) และ BMP
  • เปิดภาพจากบรรทัดคำสั่ง หรือลากไฟล์หนึ่งไฟล์วางบนหน้าต่าง

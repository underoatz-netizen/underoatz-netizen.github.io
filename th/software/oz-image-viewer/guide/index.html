คู่มือและคำถามที่พบบ่อย

คู่มือนี้พาคุณดูวิธีใช้ OZ Image Viewer ตามพฤติกรรมที่มีในตอนนี้ แอปยังอยู่ระหว่างการพัฒนาและยังไม่มีรุ่นสาธารณะ

พื้นฐาน

  • เปิดภาพ เปิดโปรแกรมโดยไม่ใส่อาร์กิวเมนต์จะได้หน้าต่างที่มี ปุ่มเปิดไฟล์ ใช้ Ctrl+O หรือเปิดภาพจากบรรทัดคำสั่ง โดยตรง และลากไฟล์ภาพหนึ่งไฟล์วางบนหน้าต่างได้เช่นกัน
  • ดูภาพ ภาพจะแสดงให้พอดีหน้าต่าง โดยไม่ขยายภาพที่เล็กกว่า หน้าต่าง ภาพแรกจะปรากฏก่อนที่โฟลเดอร์จะสแกนเสร็จ
  • เลื่อนดู ภาพอื่นในโฟลเดอร์เดียวกันจะพร้อมให้เลื่อนดูด้วย คีย์บอร์ด และแต่ละภาพจะถูกถอดรหัสเมื่อคุณเลือก
  • ซูมและเลื่อนภาพ เลื่อนล้อเมาส์เพื่อซูมเข้า/ออกที่ตำแหน่ง เคอร์เซอร์ หรือใช้คีย์บอร์ด ลากด้วยปุ่มซ้ายเพื่อเลื่อนภาพ และดับเบิลคลิก เพื่อสลับระหว่างพอดีหน้าต่างกับ 100%
  • เต็มจอ สลับหน้าต่างเป็นเต็มจอแบบไม่มีขอบบนจอปัจจุบัน และกลับมา
  • แก้ไข หมุน พลิก ครอป และย่อ/ขยายเป็นการแก้ไขแบบไม่ทำลาย ต้นฉบับ เปลี่ยนเฉพาะเอกสารบนหน้าจอ ไฟล์ต้นฉบับยังคงเดิมจนกว่าคุณจะบันทึก
  • บันทึก บันทึกจะเขียนเอกสารปัจจุบันกลับไปยังไฟล์ต้นฉบับ เมื่อรูปแบบไฟล์รองรับ ส่วนบันทึกเป็นจะสร้างสำเนาใหม่และไม่แก้ไฟล์ต้นฉบับ

รูปแบบไฟล์ที่รองรับ

รูปแบบไฟล์ภาพนิ่งทั่วไปเหล่านี้เปิดได้ โดยตรวจจากลายเซ็นของไฟล์เอง ไม่ได้ดูจากนามสกุลไฟล์

  • JPEG (.jpg, .jpeg)
  • PNG (.png)
  • WebP แบบนิ่ง (.webp รองรับเฉพาะภาพนิ่ง)
  • BMP (.bmp) และ GIF แบบนิ่ง (.gif)
  • TIFF (.tif, .tiff เฉพาะหน้าแรก)
  • ICO (.ico) และ CUR (.cur)
  • TGA (.tga)
  • AVIF (.avif) และ HEIC/HEIF แบบภาพนิ่งเมื่อมีตัวถอดรหัส เสริมพร้อมใช้งาน

สำหรับการบันทึก รูปแบบผลลัพธ์คือ PNG, JPEG, WebP (แบบไม่สูญเสียข้อมูล), TIFF และ BMP โดย TIFF บันทึกเป็นเท่านั้น

ข้อจำกัดที่ทราบ

นี่คือข้อจำกัดในตอนนี้ เพื่อให้คุณรู้ว่าควรคาดหวังอะไรได้:

  • ไม่รองรับ RAW ไฟล์ RAW และรูปแบบกล้องถูกปฏิเสธโดยเจตนา
  • ไม่รองรับภาพเคลื่อนไหว WebP แบบเคลื่อนไหวและ GIF หลายเฟรมจะถูกปฏิเสธ แทนที่จะเล่น และ APNG จะแสดงเฉพาะเฟรมแรก
  • ไม่รองรับเวกเตอร์ PDF และรูปแบบเอกสารทั่วไป
  • ไฟล์หลายหน้าหรือหลายเฟรม เช่น TIFF และ ICO จะแสดงเพียงหน้าเดียว หรือเฟรมเดียว
  • การส่งออก WebP รองรับเฉพาะแบบไม่สูญเสียข้อมูลเฟรมเดียว ไม่รองรับ WebP แบบสูญเสียข้อมูลหรือแบบเคลื่อนไหว
  • ไม่มีปลั๊กอินหรือตัวถอดรหัสของระบบอื่น และรายการนามสกุลที่รองรับ เป็นชุดที่กำหนดไว้ตายตัว
  • แอปยังอยู่ระหว่างการพัฒนา ยังไม่มีรุ่นสาธารณะ ไม่มีให้ดาวน์โหลด และซอร์สโค้ดเป็นส่วนตัว

คำถามที่พบบ่อย

ดาวน์โหลด OZ Image Viewer ได้ไหม

ยังไม่ได้ ตอนนี้ยังอยู่ระหว่างการพัฒนา และยังไม่มีรุ่นสาธารณะให้ดาวน์โหลด

ซอร์สโค้ดอยู่ที่ไหน

ซอร์สโค้ดเป็นส่วนตัวและไม่ได้เผยแพร่ โปรเจกต์อยู่บน GitHub ที่ underoatz-netizen/oz-image-viewer แต่ที่เก็บโค้ดไม่เปิดให้เข้าถึงสาธารณะ

ต้องมีบัญชีไหม

ไม่ต้อง OZ Image Viewer เป็นโปรแกรมเดสก์ท็อป ไม่ใช้บัญชีหรือการลงชื่อเข้าใช้

ใช้กับคอมพิวเตอร์แบบไหน

OZ Image Viewer เป็นโปรแกรมสำหรับ Windows 64 บิต (x64) บน Windows 10 และ Windows 11

การแก้ไขเปลี่ยนไฟล์ต้นฉบับไหม

ไม่ หมุน พลิก ครอป และย่อ/ขยายเป็นการแก้ไขแบบไม่ทำลายต้นฉบับ มีผลเฉพาะ เอกสารบนหน้าจอ ไฟล์ของคุณจะเปลี่ยนเมื่อคุณเลือกบันทึกหรือบันทึกเป็นเท่านั้น

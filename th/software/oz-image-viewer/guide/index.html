คู่มือและคำถามที่พบบ่อย

คู่มือนี้พาคุณดูวิธีใช้ PikaView (เดิมชื่อ OZ Image Viewer) ตามพฤติกรรมการทำงานในเวอร์ชัน 0.1.2

พื้นฐาน รูปแบบไฟล์ที่รองรับ คีย์บอร์ดและเมาส์ ข้อจำกัดที่ทราบ คำถามที่พบบ่อย

พื้นฐาน

  • เปิดภาพ เปิดโปรแกรมโดยไม่ใส่อาร์กิวเมนต์จะได้หน้าต่างที่มีปุ่มเปิดไฟล์ ใช้ Ctrl+O หรือเปิดภาพจากบรรทัดคำสั่งโดยตรง และลากไฟล์ภาพหนึ่งไฟล์วางบนหน้าต่างได้เช่นกัน
  • ดูภาพ ภาพจะแสดงให้พอดีหน้าต่าง โดยไม่ขยายภาพที่เล็กกว่าหน้าต่าง ภาพแรกจะปรากฏก่อนที่โฟลเดอร์จะสแกนเสร็จ
  • เลื่อนดู ภาพอื่นในโฟลเดอร์เดียวกันจะพร้อมให้เลื่อนดูด้วยคีย์บอร์ด และแต่ละภาพจะถูกถอดรหัสเมื่อคุณเลือก
  • ซูมและเลื่อนภาพ เลื่อนล้อเมาส์เพื่อซูมเข้า/ออกที่ตำแหน่งเคอร์เซอร์ หรือใช้คีย์บอร์ด ลากด้วยปุ่มซ้ายเพื่อเลื่อนภาพ และดับเบิลคลิกเพื่อสลับระหว่างพอดีหน้าต่างกับ 100%
  • เต็มจอ สลับหน้าต่างเป็นเต็มจอแบบไม่มีขอบบนจอปัจจุบันและกลับมา
  • แก้ไข หมุน พลิก ครอป และย่อ/ขยายเป็นการแก้ไขแบบไม่ทำลายต้นฉบับ เปลี่ยนเฉพาะเอกสารบนหน้าจอ ไฟล์ต้นฉบับยังคงเดิมจนกว่าคุณจะบันทึก
  • พิมพ์ เลือก More -> Print... หรือกด Ctrl+P เพื่อเปิดกล่องโต้ตอบการพิมพ์ของ Windows และพิมพ์ภาพที่ยืนยันแล้วหนึ่งชุดพอดีหน้ากระดาษโดยไม่แก้ไขไฟล์ต้นฉบับ
  • บันทึก บันทึกจะเขียนเอกสารปัจจุบันกลับไปยังไฟล์ต้นฉบับเมื่อรูปแบบไฟล์รองรับ ส่วนบันทึกเป็นจะสร้างสำเนาใหม่และไม่แก้ไฟล์ต้นฉบับ

รูปแบบไฟล์ที่รองรับ

ตรวจจับจากลายเซ็นไฟล์

รูปแบบไฟล์ภาพนิ่งทั่วไปเหล่านี้เปิดได้ โดยตรวจจากลายเซ็นของไฟล์เอง ไม่ได้ดูจากนามสกุลไฟล์

  • JPEG (.jpg, .jpeg)
  • PNG (.png)
  • WebP แบบนิ่ง (.webp รองรับเฉพาะภาพนิ่ง)
  • BMP (.bmp) และ GIF แบบนิ่ง (.gif)
  • TIFF (.tif, .tiff เฉพาะหน้าแรก)
  • ICO (.ico) และ CUR (.cur)
  • TGA (.tga)
  • AVIF (.avif) และ HEIC/HEIF แบบภาพนิ่งเมื่อมีตัวถอดรหัสเสริมพร้อมใช้งาน

สำหรับการบันทึก รูปแบบผลลัพธ์คือ PNG, JPEG, WebP (แบบไม่สูญเสียข้อมูล), TIFF และ BMP โดย TIFF บันทึกเป็นเท่านั้น

ข้อจำกัดที่ทราบ

นี่คือข้อจำกัดในตอนนี้ เพื่อให้คุณรู้ว่าควรคาดหวังอะไรได้:

  • ไม่รองรับ RAW ไฟล์ RAW และรูปแบบกล้องถูกปฏิเสธโดยเจตนา
  • ไม่รองรับภาพเคลื่อนไหว WebP แบบเคลื่อนไหวและ GIF หลายเฟรมจะถูกปฏิเสธแทนที่จะเล่น และ APNG จะแสดงเฉพาะเฟรมแรก
  • ไม่รองรับเวกเตอร์ PDF และรูปแบบเอกสารทั่วไป
  • ไฟล์หลายหน้าหรือหลายเฟรม เช่น TIFF และ ICO จะแสดงเพียงหน้าเดียวหรือเฟรมเดียว
  • การส่งออก WebP รองรับเฉพาะแบบไม่สูญเสียข้อมูลเฟรมเดียว ไม่รองรับ WebP แบบสูญเสียข้อมูลหรือแบบเคลื่อนไหว
  • ไม่มีปลั๊กอินหรือตัวถอดรหัสของระบบอื่น และรายการนามสกุลที่รองรับเป็นชุดที่กำหนดไว้ตายตัว
  • การพิมพ์จะส่งออกภาพที่ยืนยันแล้วหนึ่งชุดแบบพอดีหน้ากระดาษผ่านกล่องโต้ตอบของระบบ Windows PrintDlgExW กรณีเครื่องพิมพ์เครือข่าย failed-network-first ยังไม่ได้ทดสอบ และไม่มีการอ้างว่าอาการค้างของกล่องโต้ตอบพิมพ์ทั้งหมดได้รับการแก้ไขแล้ว
  • ไฟล์ไบนารีของโปรเจกต์ (pikaview-0.1.2-win-x64-installer.exe, ozviewer.exe, heif.dll และ libde265.dll) ยังไม่ได้ลงลายเซ็นดิจิทัล Windows SmartScreen หรือเบราว์เซอร์อาจแสดงคำเตือน "Unknown Publisher" โปรดตรวจสอบค่าแฮช SHA-256 ที่หน้า ดาวน์โหลด ก่อนรันไฟล์
  • ซอร์สโค้ดเปิดเผยสาธารณะภายใต้สัญญาอนุญาต MIT บน GitHub

คำถามที่พบบ่อย

ดาวน์โหลด PikaView ได้ไหม

ได้ สามารถดาวน์โหลดแพ็กเกจสำหรับ Windows 64-บิต ได้ที่หน้า ดาวน์โหลด

อัปเกรดจากรุ่น 0.1.0 หรือ 0.1.1 อย่างไร

รันตัวติดตั้ง PikaView 0.1.2 ทับการติดตั้ง OZ Image Viewer 0.1.0 หรือ PikaView 0.1.1 เดิมได้เลย โปรแกรมจะอัปเกรดในตำแหน่งเดิมภายใต้โฟลเดอร์ต่อผู้ใช้ (%LOCALAPPDATA%\Programs\OZ Image Viewer) โดยยังคงชื่อไฟล์โปรแกรม ozviewer.exe ค่า AppId ที่คงที่ ProgID OZImageViewer.Image และรักษาค่าเริ่มต้นการเปิดไฟล์ของ Windows (UserChoice) เดิมไว้ครบถ้วน

ซอร์สโค้ดอยู่ที่ไหน

ซอร์สโค้ดเปิดเผยสาธารณะ โปรเจกต์อยู่บน GitHub ที่ underoatz-netizen/oz-image-viewer

ต้องมีบัญชีไหม

ไม่ต้อง PikaView เป็นโปรแกรมเดสก์ท็อป ไม่ใช้บัญชีหรือการลงชื่อเข้าใช้

ใช้กับคอมพิวเตอร์แบบไหน

PikaView เป็นโปรแกรมสำหรับ Windows 64 บิต (x64) บน Windows 10 และ Windows 11

การแก้ไขเปลี่ยนไฟล์ต้นฉบับไหม

ไม่ หมุน พลิก ครอป และย่อ/ขยายเป็นการแก้ไขแบบไม่ทำลายต้นฉบับ มีผลเฉพาะเอกสารบนหน้าจอ ไฟล์ของคุณจะเปลี่ยนเมื่อคุณเลือกบันทึกหรือบันทึกเป็นเท่านั้น

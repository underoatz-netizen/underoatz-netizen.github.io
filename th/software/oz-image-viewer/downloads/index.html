ดาวน์โหลด PikaView

แพ็กเกจทางการสำหรับระบบปฏิบัติการ Windows x64 ของ PikaView (เดิมชื่อ OZ Image Viewer) เวอร์ชัน 0.1.1

การเผยแพร่รุ่น 0.1.1: แพ็กเกจไบนารีสร้างขึ้นสำหรับระบบปฏิบัติการ Windows แบบ 64-บิต (x64) ซอร์สโค้ดส่วนแรกพัฒนาโดยตรงอยู่ภายใต้สัญญาอนุญาต MIT สำหรับไลบรารีบุคคลที่สามที่โหลดแบบไดนามิกภายใต้สัญญาอนุญาต LGPLv3 (libheif และ libde265) ทางเราได้จัดเตรียมซอร์สโค้ด ส่วนแก้ไข (patches) และสคริปต์คอมไพล์ครบถ้วนควบคู่กับไฟล์โปรแกรมตามข้อกำหนดของ LGPLv3 ข้อ 4 และ GPLv3 ข้อ 6(d) หากคุณมี OZ Image Viewer 0.1.0 อยู่แล้ว ตัวติดตั้งจะอัปเกรดในตำแหน่งเดิมโดยยังคงใช้ ozviewer.exe และโฟลเดอร์ %LOCALAPPDATA%\Programs\OZ Image Viewer

ไฟล์ดาวน์โหลดทางการ (รุ่น 0.1.1)

GitHub Releases

ตัวติดตั้งสำหรับ Windows (.exe) — แนะนำ

~4.1 MB

pikaview-0.1.1-win-x64-installer.exe (4,260,442 ไบต์)

ติดตั้งโปรแกรมลงในโฟลเดอร์ผู้ใช้เฉพาะบุคคล (%LOCALAPPDATA%\Programs\OZ Image Viewer) โดยยังคงชื่อไฟล์โปรแกรม ozviewer.exe และไม่ต้องใช้สิทธิ์ระดับผู้ดูแลระบบ (Admin) หากมี OZ Image Viewer 0.1.0 อยู่ก่อนแล้ว รุ่น 0.1.1 จะอัปเกรดในโฟลเดอร์เดิม อัปเดตป้ายชื่อเป็น PikaView และคงค่าเริ่มต้นการเปิดไฟล์ของ Windows (UserChoice) เดิมไว้ครบถ้วน การเชื่อมโยงนามสกุลไฟล์เป็นแบบให้ผู้ใช้เลือกเปิดเองขณะติดตั้งเท่านั้น และถอนการติดตั้งได้อย่างหมดจดผ่าน Windows Settings > Installed Apps

ดาวน์โหลดตัวติดตั้ง (.exe)

ไฟล์ ZIP แบบพกพา (.zip)

~2.6 MB

pikaview-0.1.1-win-x64-portable.zip (2,714,302 ไบต์)

ให้แตกไฟล์ทั้งหมดออกจากไฟล์ ZIP ไปยังโฟลเดอร์ที่ต้องการก่อนเปิดใช้งาน ozviewer.exe โปรดอย่าเปิดไฟล์จากในหน้าดูไฟล์บีบอัดโดยตรงเนื่องจากจำเป็นต้องโหลดไฟล์ DLL คู่ขนาน (เช่น heif.dll และ libde265.dll) จากโฟลเดอร์เดียวกัน รุ่นพกพาจะไม่มีการเขียนคีย์ถอนการติดตั้งลงในรีจิสทรี

ดาวน์โหลดไฟล์ ZIP แบบพกพา
  • pikaview-0.1.1-lgpl-corresponding-source.zip ซอร์สโค้ดและสคริปต์คอมไพล์สำหรับส่วนประกอบ LGPL (libheif และ libde265) (2,420,966 ไบต์) ~2.3 MB
  • SHA256SUMS ไฟล์บันทึกค่าแฮชตรวจสอบความถูกต้องของไฟล์ดาวน์โหลดทั้ง 3 ไฟล์ ไฟล์ค่าแฮช
  • หน้า Release v0.1.1 บน GitHub ไฟล์ดาวน์โหลดทั้งหมดและแท็ก git บันทึกรวมไว้ที่หน้า Release ทางการ GitHub

PikaView ไม่มีบริการเบื้องหลัง ไม่มีการเก็บข้อมูลการใช้งาน (Telemetry) และไม่มีระบบอัปเดตอัตโนมัติแบบเงียบ

เริ่มต้นใช้งานอย่างรวดเร็ว

3 ขั้นตอน
  1. ขั้นตอน 01

    ดาวน์โหลดและตรวจ SHA-256

    ดาวน์โหลดตัวติดตั้งหรือไฟล์ ZIP แบบพกพาของ v0.1.1 จาก GitHub Releases และตรวจสอบค่าแฮช SHA-256 ให้ตรงกับไฟล์ SHA256SUMS และตารางด้านล่างก่อนเปิดใช้งาน

  2. ขั้นตอน 02

    ติดตั้ง อัปเกรด หรือแตกไฟล์ให้ครบ

    เปิดตัวติดตั้งสำหรับผู้ใช้ทั่วไป (อัปเกรด OZ Image Viewer 0.1.0 ในตำแหน่งเดิมได้ทันที) หรือแตกไฟล์ทั้งหมดใน ZIP (รวม heif.dll และ libde265.dll) หาก Windows SmartScreen แสดงคำเตือน "Unknown Publisher" ให้ตรวจสอบค่าแฮช SHA-256 ก่อนยืนยันเปิดไฟล์

  3. ขั้นตอน 03

    ดูภาพ แก้ไข และพิมพ์อย่างปลอดภัย

    เปิดไฟล์ภาพนิ่งโดยตรงหรือลากไฟล์วางบน ozviewer.exe การปรับแต่งทั้งหมดจะยังไม่แก้ไฟล์ต้นฉบับจนกว่าคุณจะสั่งบันทึก และกด Ctrl+P เพื่อสั่งพิมพ์หนึ่งหน้าพอดีกระดาษได้ทันที

ค่าแฮชตรวจสอบความถูกต้อง (SHA-256) และความปลอดภัย

SHA-256 และข้อมูลแพลตฟอร์ม

สถานะไฟล์ที่ยังไม่ได้ลงลายมือชื่อดิจิทัล: ไฟล์ไบนารีของโปรเจกต์ในรุ่น 0.1.1 (pikaview-0.1.1-win-x64-installer.exe, ozviewer.exe, heif.dll และ libde265.dll) ยังไม่ได้ลงลายมือชื่อดิจิทัล (NotSigned) ส่วน Microsoft VC143 CRT DLL ที่รวมอยู่ในแพ็กเกจมีลายเซ็น Authenticode ของ Microsoft ที่ถูกต้อง Windows SmartScreen หรือเว็บเบราว์เซอร์อาจแสดงข้อความแจ้งเตือน "Unknown Publisher" เมื่อเปิดไฟล์ โปรดตรวจสอบว่าดาวน์โหลดมาจากคลังทางการและมีค่าแฮช SHA-256 ตรงตามไฟล์ SHA256SUMS และตารางด้านบน ไม่แนะนำให้กดยืนยันเปิดไฟล์โดยไม่ได้ตรวจสอบความถูกต้อง

ขอบเขตสถาปัตยกรรมและการทดสอบ: โปรแกรมคอมไพล์สำหรับ Windows แบบ 64-บิต (x64) ผ่านการทดสอบอัตโนมัติในบัญชีผู้ใช้ทั่วไป (Standard User) บน Windows Server 2022 (x64) แบบ clean-room ครอบคลุมการติดตั้งใหม่ การทดสอบ FirstPresent benchmark การเชื่อมโยงนามสกุลไฟล์และชอร์ตคัตบนเดสก์ท็อปแบบเลือกเอง การอัปเกรดในตำแหน่งเดิมจาก v0.1.0 -> v0.1.1 พร้อมคงค่า UserChoice การตรวจแฮชรันไทม์ และการถอนการติดตั้งอย่างหมดจด โดยในรุ่นนี้ยังไม่รองรับ Windows 32-บิต และ ARM64

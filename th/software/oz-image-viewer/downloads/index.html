ดาวน์โหลด OZ Image Viewer

แพ็กเกจทางการสำหรับระบบปฏิบัติการ Windows x64 ของ OZ Image Viewer รุ่น 0.1.0

การเผยแพร่รุ่น 0.1.0: แพ็กเกจไบนารีสร้างขึ้นสำหรับระบบปฏิบัติการ Windows แบบ 64-บิต (x64) ซอร์สโค้ดส่วนแรกพัฒนาโดยตรงอยู่ภายใต้สัญญาอนุญาต MIT สำหรับไลบรารีบุคคลที่สามที่โหลดแบบไดนามิกภายใต้สัญญาอนุญาต LGPLv3 (libheif และ libde265) ทางเราได้จัดเตรียมซอร์สโค้ด ส่วนแก้ไข (patches) และสคริปต์คอมไพล์ครบถ้วนควบคู่กับไฟล์โปรแกรมตามข้อกำหนดของ LGPLv3 ข้อ 4 และ GPLv3 ข้อ 6(d)

ไฟล์ดาวน์โหลดทางการ (รุ่น 0.1.0)

  • ozviewer-0.1.0-win-x64-installer.exe — ตัวติดตั้งสำหรับ Windows 64-บิต (ขนาดประมาณ 4.0 MB)
  • ozviewer-0.1.0-win-x64-portable.zip — แพ็กเกจไฟล์ ZIP แบบพกพา (ขนาดประมาณ 2.6 MB)
  • ozviewer-0.1.0-lgpl-corresponding-source.zip — ซอร์สโค้ดและสคริปต์คอมไพล์สำหรับส่วนประกอบ LGPL (libheif และ libde265) (ขนาดประมาณ 2.4 MB)
  • SHA256SUMS — ไฟล์บันทึกค่าแฮชตรวจสอบความถูกต้องของไฟล์ดาวน์โหลดทั้ง 3 ไฟล์

ไฟล์ดาวน์โหลดทั้งหมดและแท็ก git บันทึกรวมไว้ที่ หน้า Release v0.1.0 บน GitHub

คำแนะนำการเลือกแพ็กเกจและการติดตั้ง

  • ตัวติดตั้งสำหรับ Windows (Setup Installer): ติดตั้งโปรแกรมลงในโฟลเดอร์ผู้ใช้เฉพาะบุคคล (%LOCALAPPDATA%\Programs\OZ Image Viewer) โดยไม่ต้องใช้สิทธิ์ระดับผู้ดูแลระบบ (Admin) ไม่ผูกนามสกุลไฟล์โดยพลการ (ผู้ใช้เลือกเปิดใช้เองได้ขณะติดตั้ง) และสามารถถอนการติดตั้งออกได้อย่างหมดจดผ่าน Windows Settings > Installed Apps
  • ไฟล์ ZIP แบบพกพา (Portable ZIP): ให้แตกไฟล์ทั้งหมดออกจากไฟล์ ZIP ไปยังโฟลเดอร์ที่ต้องการก่อนเปิดใช้งาน ozviewer.exe โปรดอย่าเปิดไฟล์จากในหน้าดูไฟล์บีบอัดโดยตรงเนื่องจากจำเป็นต้องโหลดไฟล์ DLL คู่ขนาน (เช่น heif.dll และ libde265.dll) จากโฟลเดอร์เดียวกัน รุ่นพกพาจะไม่มีการเขียนคีย์ถอนการติดตั้งลงในรีจิสทรี

OZ Image Viewer ไม่มีบริการเบื้องหลัง ไม่มีการเก็บข้อมูลการใช้งาน (Telemetry) และไม่มีระบบอัปเดตอัตโนมัติแบบเงียบ

ค่าแฮชตรวจสอบความถูกต้อง (SHA-256)

โปรดตรวจสอบค่าแฮช SHA-256 ของไฟล์ที่คุณดาวน์โหลดเสมอ โดยเปรียบเทียบกับค่าทางการที่แสดงในตารางด้านล่าง:

ค่าแฮช SHA-256 ทางการสำหรับ OZ Image Viewer 0.1.0
ชื่อไฟล์ค่าแฮช SHA-256
ozviewer-0.1.0-win-x64-installer.exe 25637adf86ab1eeac9a0e5992918bc492c957c7568116f452de8c6a5e2d3b633
ozviewer-0.1.0-win-x64-portable.zip 7c014784fc6a8aa0a9c466d22ae33b838c4f76521c91af2a68e01e445e312792
ozviewer-0.1.0-lgpl-corresponding-source.zip 6d6aadebe2ecf2b4f96183de3860b5f24aabac2429673ab300c86ed1ff4cba3f

คุณสามารถใช้เครื่องมือบรรทัดคำสั่งใน Windows เพื่อตรวจค่าแฮชได้ดังนี้:

คำสั่งตรวจสอบค่าแฮช SHA-256 บน Windows
เครื่องมือตัวอย่างคำสั่ง
PowerShell Get-FileHash -Algorithm SHA256 filename
Command Prompt certutil -hashfile filename SHA256

หากค่าแฮชที่คำนวณได้ไม่ตรงกับค่าทางการที่ระบุไว้ โปรดอย่าเปิดไฟล์ดังกล่าวใช้งาน

ความปลอดภัยและการรองรับระบบปฏิบัติการ

สถานะไฟล์ที่ยังไม่ได้ลงลายมือชื่อดิจิทัล: ไฟล์ไบนารีในรุ่น 0.1.0 ยังไม่ได้ลงลายมือชื่อดิจิทัล (Code Signing) Windows SmartScreen หรือเว็บเบราว์เซอร์อาจแสดงข้อความแจ้งเตือนความปลอดภัยเมื่อเปิดไฟล์ โปรดตรวจสอบว่าดาวน์โหลดมาจากคลังทางการและมีค่าแฮช SHA-256 ตรงตามตาราง ไม่แนะนำให้กดยืนยันเปิดไฟล์โดยไม่ได้ตรวจสอบความถูกต้อง

ขอบเขตสถาปัตยกรรมและการทดสอบ: โปรแกรมคอมไพล์สำหรับ Windows แบบ 64-บิต (x64) ผ่านการทดสอบวงจรการทำงาน ติดตั้ง เปิดภาพ แสดงผลหน้าจอแรก และถอนการติดตั้งอย่างสมบูรณ์ในบัญชีผู้ใช้ทั่วไป (Standard User) บน Windows Server 2022 (x64) ผ่านระบบทดสอบอัตโนมัติ โดยในรุ่นนี้ยังไม่รองรับ Windows 32-บิต และ ARM64

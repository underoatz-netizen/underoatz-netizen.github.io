ดาวน์โหลด PikaSnip

เวอร์ชัน 0.1.0 สำหรับ Windows 10 และ Windows 11 (64 บิต) เลือกไฟล์ Portable ZIP เพื่อแตกไฟล์และใช้งานทันที หรือเลือก MSIX แบบลงนามเองหากต้องการทดสอบการติดตั้งแบบ sideload

แนะนำให้ใช้รุ่น Portable ZIP ในตอนนี้ ทั้งสองแพ็กเกจเผยแพร่จาก GitHub Release ทางการและรวมโมเดล OCR OpenThai 2.1, Microsoft ONNX Runtime v1.32.0 และ MSVC x64 CRT DLLs เฉพาะแอปจำนวน 4 ไฟล์ไว้ครบ จึงไม่ต้องลง VC++ Redistributable เพิ่มเติม ส่วนไฟล์ MSIX เป็นบิลด์ทดสอบแบบลงนามเอง (self-signed sideload) ที่ต้องให้สิทธิ์ผู้ดูแลระบบเชื่อถือใบรับรองก่อนติดตั้ง ระหว่างที่รุ่น Microsoft Store กำลังเตรียมเผยแพร่

PikaSnip_0.1.0.0_x64.msix (14,309,278 ไบต์)

ดาวน์โหลด MSIX ลงนามเอง
  • PikaSnip_0.1.0.0_x64.cer ใบรับรองทดสอบสาธารณะ (772 ไบต์, CN=OZ Lab) ใช้เฉพาะการติดตั้ง MSIX แบบ sideload 772 B
  • SHA256SUMS.txt ไฟล์รายการค่าแฮช SHA-256 ทางการของรุ่น v0.1.0 ไฟล์ค่าแฮช
  • ThirdPartyNotices.txt ประกาศสัญญาอนุญาตโอเพนซอร์สสำหรับ OpenThai 2.1 (Apache 2.0) และ Microsoft ONNX Runtime (MIT) 341,120 B
  • หน้าเผยแพร่ v0.1.0 บน GitHub ไฟล์และรายละเอียดการเผยแพร่ทั้งหมดบน GitHub Releases GitHub

เริ่มต้นใช้งานอย่างรวดเร็ว

3 ขั้นตอน
  1. ขั้นตอน 01

    ดาวน์โหลดและตรวจ SHA-256

    ดาวน์โหลด PikaSnip_0.1.0_Portable_x64.zip จาก GitHub Releases แล้วเทียบค่าแฮช SHA-256 กับตารางด้านล่างก่อนแตกไฟล์

  2. ขั้นตอน 02

    แตกไฟล์และเปิดใช้งาน

    แตกไฟล์ทั้งหมดใน ZIP ไว้ในโฟลเดอร์เดียวกัน (เก็บโมเดล OCR และ DLL ไว้ครบ) แล้วเปิด PikaSnip.exe หาก Windows SmartScreen เตือนไฟล์ที่ไม่ได้ลงนาม ให้ตรวจว่า SHA-256 ตรงกันก่อนแล้วเลือก More info > Run anyway

  3. ขั้นตอน 03

    จับภาพ ปักหมุด และ OCR

    PikaSnip จะรออยู่ในถาดระบบด้วยแรมต่ำกว่า 15 MB กด PrintScreen หรือ Alt+A เพื่อจับภาพ, Ctrl+P เพื่อปักหมุด หรือ Alt+T สำหรับ OCR ไทย/อังกฤษแบบออฟไลน์

ค่าแฮชและใบรับรองสำหรับ Sideload

หมายเหตุการติดตั้ง MSIX แบบลงนามเอง (Sideload)

แพ็กเกจ MSIX ลงนามด้วยใบรับรองทดสอบแบบลงนามเองสำหรับการทดสอบติดตั้งในเครื่อง ระหว่างที่รุ่น Microsoft Store กำลังเตรียมเผยแพร่:

  • ไฟล์ใบรับรอง: PikaSnip_0.1.0.0_x64.cer (772 ไบต์)
  • ผู้ลงนาม (Subject): CN=OZ Lab
  • ลายนิ้วมือ (SHA-1 Thumbprint): 9F536B494A2FC9724B848064E0E40873A0984408
  • เงื่อนไขการเชื่อถือ: การติดตั้ง PikaSnip_0.1.0.0_x64.msix แบบ sideload ต้องใช้สิทธิ์ผู้ดูแลระบบนำเข้า PikaSnip_0.1.0.0_x64.cer ลงในทั้ง LocalMachine\Root (Trusted Root Certification Authorities) และ LocalMachine\TrustedPeople (Trusted People) หากไม่ต้องการติดตั้งใบรับรองทดสอบในเครื่อง แนะนำให้ใช้รุ่น Portable ZIP แทน

บันทึกการเปลี่ยนแปลง

ประวัติการเผยแพร่ของ PikaSnip สำหรับ Windows 10 และ 11 (x64) เรียงจากใหม่ไปเก่า

PikaSnip 0.1.0 พร้อมใช้งานแล้ว รุ่นสาธารณะแรก เผยแพร่เมื่อวันที่ 26 พฤศจิกายน 2026 สำหรับ Windows 10 และ Windows 11 (64-bit x64)

ส่งเข้า Microsoft Store — 26 พฤศจิกายน 2026

อยู่ระหว่างการตรวจสอบ
  • ส่ง PikaSnip 0.1.0 เข้า Microsoft Store เพื่อตรวจสอบ และเผยแพร่ภาพหน้าจอทางการ 4 ภาพบนเว็บไซต์นี้

0.1.0 — 26 พฤศจิกายน 2026

รุ่นล่าสุด
  • เผยแพร่รุ่นสาธารณะแรกของ PikaSnip สำหรับ Windows 10 และ 11 (x64) พัฒนาด้วย C++20 เนทีฟบน Win32 และ Direct2D โดยไม่ใช้ Electron, WebView2, Qt หรือ .NET
  • ไฟล์ PikaSnip.exe ขนาดกะทัดรัด (754,688 ไบต์) คอมไพล์แบบ static CRT (/MT) ไม่มี dynamic CRT imports พร้อมแนบ MSVC x64 CRT DLLs เฉพาะแอปจำนวน 4 ไฟล์สำหรับ ONNX Runtime เพื่อให้เครื่อง Windows ที่สะอาดเปิดใช้งานได้โดยไม่ต้องลง VC++ Redistributable
  • จับภาพหน้าจอ (PrintScreen / Alt+A), วาดแก้ไขพร้อมเลิกทำ/ทำซ้ำ (Ctrl+Z / Ctrl+Y), ดูดรหัสสี HEX (C), คัดลอกลงคลิปบอร์ด (Ctrl+C / Enter) และบันทึกไฟล์ PNG (Ctrl+S) ลงใน %USERPROFILE%\Pictures\PikaSnip
  • ปักหมุดภาพลอยด้านบนสุดจากพื้นที่ที่เลือก (Ctrl+P) หรือจากคลิปบอร์ด (Alt+P) พร้อมซูม (25%–400%), ปรับความโปร่งใส (20%–100%), รีเซ็ต (0) และแถบเครื่องมือแก้ไขบนหมุด (E / Space)
  • OCR ภาษาไทยและอังกฤษแบบออฟไลน์ 100% (Alt+T สำหรับ Quick OCR และ Ctrl+T สำหรับพื้นที่ที่เลือก) ขับเคลื่อนด้วยโมเดล OpenThai 2.1 (Apache 2.0) และ Microsoft ONNX Runtime v1.32.0 (MIT)
  • โหลดเอนจิน OCR แบบหน่วงเวลาผ่าน LoadLibraryExW ทำให้แรมสแตนด์บายต่ำกว่า 15 MB (วัดได้ 10.79–11.33 MB บนเครื่อง Windows 11 build 26100 ที่สะอาด)
  • ทำงานออฟไลน์ 100% ไม่มี telemetry ไม่เชื่อมต่อเครือข่าย และปิดการเริ่มทำงานพร้อม Windows ไว้เป็นค่าเริ่มต้น (Enabled="false")
  • เผยแพร่บน GitHub Releases ทั้งไฟล์ Portable x64 ZIP ที่แนะนำ (13.30 MiB) และแพ็กเกจ MSIX ลงนามเองสำหรับ sideload (13.65 MiB) พร้อม PikaSnip_0.1.0.0_x64.cer, SHA256SUMS.txt และ ThirdPartyNotices.txt ส่งเข้าหน้า Microsoft Store แล้ว — อยู่ระหว่างการตรวจสอบ

ดูไฟล์และค่าแฮช SHA-256 ได้ที่หน้า ดาวน์โหลด หรือดูที่ v0.1.0 บน GitHub Releases

หน้าที่เกี่ยวข้อง

  • ดาวน์โหลด รับแพ็กเกจรุ่น 0.1.0 และค่าแฮช SHA-256 v0.1.0
  • ภาพรวม PikaSnip ผลิตภัณฑ์นี้ทำอะไรได้บ้าง ภาพรวม
  • คู่มือและคำถามที่พบบ่อย คีย์ลัด ที่เก็บไฟล์ และคำถามที่พบบ่อย คู่มือ

PikaSnip

โปรแกรมจับภาพหน้าจอ ปักหมุดภาพลอย วาดแก้ไข และอ่านข้อความ OCR ภาษาไทยและอังกฤษแบบออฟไลน์ 100% เขียนด้วย C++20 เนทีฟสำหรับ Windows โดย OZ Lab ใช้แรมสแตนด์บายต่ำกว่า 15 MB และไม่มีการส่งข้อมูลใด ๆ

ดาวน์โหลด v0.1.0 คู่มือและคำถามที่พบบ่อย
PikaSnip v0.1.0 Win32 · Direct2D
จับภาพ (Alt+A) ปักหมุด (Ctrl+P) OCR (Alt+T) สี HEX (C)
PikaSnip.exe · 754,688 ไบต์ สแตนด์บาย < 15 MB RAM · OCR OpenThai 2.1 ออฟไลน์

PikaSnip 0.1.0 สำหรับ Windows x64 พร้อมให้ดาวน์โหลดแล้วบน GitHub Releases แนะนำแพ็กเกจ Portable ZIP x64 (13.30 MiB) สำหรับแตกไฟล์และใช้งานทันทีโดยไม่ต้องติดตั้งใบรับรอง ส่วนแพ็กเกจ MSIX แบบลงนามเอง (self-signed sideload) เผยแพร่ไว้สำหรับการทดสอบ ส่งเข้าหน้า Microsoft Store แล้ว — อยู่ระหว่างการตรวจสอบ จะเพิ่มลิงก์เมื่อหน้าร้านเผยแพร่แล้ว ดูไฟล์ ค่าแฮช SHA-256 และประกาศสัญญาอนุญาตได้ที่หน้า ดาวน์โหลด

ทำอะไรได้บ้าง ภาพหน้าจอ สถาปัตยกรรมและขนาด สถานะโปรเจกต์ หน้าถัดไป

PikaSnip ทำอะไรได้บ้าง

จับภาพ · ปักหมุด · วาดแก้ไข · OCR ออฟไลน์

PikaSnip รอทำงานอย่างเงียบ ๆ ในถาดระบบของ Windows จนกว่าคุณจะกดคีย์ลัด โดยรวมการจับภาพหน้าจอ การปักหมุดภาพอ้างอิง การวาดแก้ไข การดูดสี และการอ่านข้อความ OCR ไทย/อังกฤษแบบออฟไลน์ไว้ในแอปเนทีฟตัวเดียว:

  • จับภาพบางส่วนของหน้าจอข้ามหลายจอภาพด้วย PrintScreen หรือ Alt+A แล้วคัดลอกลงคลิปบอร์ด (Ctrl+C / Enter) หรือบันทึกเป็นไฟล์ PNG (Ctrl+S) ลงโฟลเดอร์ Pictures\PikaSnip
  • ปักหมุดพื้นที่ที่เลือก (Ctrl+P) หรือปักหมุดภาพจากคลิปบอร์ด (Alt+P) เป็นหน้าต่างอ้างอิงลอยด้านบนสุด
  • ปรับดูภาพที่ปักหมุดได้ลื่นไหลด้วยการหมุนล้อเมาส์เพื่อซูม (25%–400%), กด Ctrl+Wheel ปรับความโปร่งใส (20%–100%), รีเซ็ตด้วยปุ่ม 0 และเปิดแถบเครื่องมือแก้ไขบนหมุดด้วย E หรือ Space
  • วาดแก้ไขลงบนภาพก่อนคัดลอก ปักหมุด หรือบันทึก พร้อมเลิกทำและทำซ้ำ (Ctrl+Z / Ctrl+Y)
  • ดูดสีพิกเซลขณะจับภาพและคัดลอกรหัสสี HEX ลงคลิปบอร์ดได้ทันทีด้วยปุ่ม C
  • สกัดข้อความภาษาไทยและอังกฤษแบบออฟไลน์ 100% ด้วย Quick OCR (Alt+T) หรือจากพื้นที่ที่กำลังเลือก (Ctrl+T) ขับเคลื่อนด้วยโมเดล OpenThai 2.1 (Apache 2.0) และ Microsoft ONNX Runtime (MIT) ที่รวมมาในแพ็กเกจ
  • รักษาแรมขณะรอทำงานให้ต่ำ: onnxruntime.dll (v1.32.0) ถูกโหลดแบบหน่วงเวลา (lazy load) ผ่าน LoadLibraryExW เฉพาะตอนที่คุณสั่งรัน OCR เท่านั้น
  • ทำงานออฟไลน์ 100% ไม่มี telemetry ไม่เชื่อมต่อเครือข่าย ไม่มีบัญชีผู้ใช้ และปิดการเริ่มทำงานพร้อม Windows ไว้เป็นค่าเริ่มต้น (Enabled="false")

สถาปัตยกรรมและขนาด

เนทีฟ Windows ไร้ความบวม

PikaSnip พัฒนาด้วย C++20 เนทีฟบน Win32 และ Direct2D โดยไม่พ่วง Electron, WebView2, Qt หรือ .NET:

  • ไฟล์โปรแกรมหลักขนาดเล็ก: PikaSnip.exe มีขนาด 754,688 ไบต์ คอมไพล์แบบ static CRT (/MT) ไม่มี dynamic CRT imports
  • แรมสแตนด์บายต่ำ: ขณะรอทำงานใช้แรมต่ำกว่า 15 MB (วัดได้จริง 10.79–11.33 MB บนเครื่อง Windows 11 build 26100 ที่สะอาด) เพราะเอนจิน OCR จะยังไม่ถูกโหลดจนกว่าจะเรียกใช้
  • ไม่ต้องลง VC++ Redistributable: รวมไฟล์ MSVC x64 CRT DLLs เฉพาะแอปจำนวน 4 ไฟล์ไว้คู่กับ onnxruntime.dll เพื่อให้เครื่อง Windows ที่สะอาดเปิดใช้งานได้ทันที
  • ที่เก็บข้อมูลในเครื่องที่โปร่งใส: รุ่น Portable เก็บ settings.json ข้างไฟล์ PikaSnip.exe ส่วนรุ่น MSIX เก็บที่ %LOCALAPPDATA%\OZLab\PikaSnip\settings.json และภาพ PNG ที่บันทึกจะเก็บใน %USERPROFILE%\Pictures\PikaSnip

ไปที่หน้าถัดไป

  • ดาวน์โหลด รับเวอร์ชัน 0.1.0 แบบ Portable ZIP หรือ MSIX ลงนามเอง พร้อมค่าแฮช SHA-256 v0.1.0
  • คู่มือและคำถามที่พบบ่อย คีย์ลัด ที่เก็บไฟล์ การทำงานของ OCR ออฟไลน์ และคำถามที่พบบ่อย คู่มือ
  • บันทึกการเปลี่ยนแปลง ประวัติการเผยแพร่ตั้งแต่ v0.1.0 ประวัติรุ่น
  • นโยบายความเป็นส่วนตัวของ PikaSnip หน้าเฉพาะสำหรับนโยบายความเป็นส่วนตัว (ภาษาอังกฤษและภาษาไทย) ออฟไลน์

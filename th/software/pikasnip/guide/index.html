คู่มือและคำถามที่พบบ่อย

วิธีจับภาพหน้าจอ ปักหมุดภาพลอย วาดแก้ไข ดูดสี และรัน OCR ภาษาไทยและอังกฤษแบบออฟไลน์ด้วย PikaSnip 0.1.0 สำหรับ Windows x64 ดาวน์โหลดได้ที่หน้า ดาวน์โหลด

พื้นฐาน คีย์ลัด ที่เก็บไฟล์และการตั้งค่า คำถามที่พบบ่อย

พื้นฐาน

  • รอทำงานในถาดระบบ (System Tray) เมื่อเปิด PikaSnip.exe แอปจะรออยู่ในพื้นที่แจ้งเตือนของ Windows โดยใช้แรมต่ำกว่า 15 MB คลิกขวาที่ไอคอนในถาดระบบเพื่อตั้งค่า เรียกคำสั่ง หรือสลับตัวเลือก Run at Startup (ปิดเป็นค่าเริ่มต้น)
  • จับภาพและวาดแก้ไข กด PrintScreen หรือ Alt+A เพื่อลากเลือกพื้นที่หน้าจอ วาดแก้ไขทับภาพได้ทันที เลิกทำหรือทำซ้ำด้วย Ctrl+Z / Ctrl+Y คัดลอกด้วย Ctrl+C หรือ Enter หรือบันทึกเป็น PNG ด้วย Ctrl+S
  • ดูดสีพิกเซล ขณะกำลังจับภาพ กดปุ่ม C เพื่อคัดลอกรหัสสี HEX ใต้เคอร์เซอร์ลงคลิปบอร์ดทันที
  • ปักหมุดภาพลอย กด Ctrl+P ระหว่างจับภาพเพื่อปักหมุดพื้นที่ที่เลือกลอยไว้เหนือหน้าต่างอื่นทั้งหมด หรือกด Alt+P เพื่อปักหมุดภาพที่อยู่ในคลิปบอร์ดทันที
  • ปรับแต่งและแก้ไขภาพที่ปักหมุด เลื่อนเมาส์เหนือหน้าต่างหมุดแล้วหมุน Mouse Wheel เพื่อซูม (25%–400%), กด Ctrl+Wheel เพื่อปรับความโปร่งใส (20%–100%), กด 0 เพื่อรีเซ็ต, กด E หรือ Space เพื่อเปิด/ปิดแถบเครื่องมือแก้ไขบนหมุด หรือกด Esc เพื่อปิดหมุด
  • OCR ภาษาไทยและอังกฤษแบบออฟไลน์ กด Alt+T สำหรับ Quick OCR หรือกด Ctrl+T บนพื้นที่ที่กำลังเลือกเพื่ออ่านข้อความไทยและอังกฤษแบบออฟไลน์ 100% ด้วยโมเดล OpenThai 2.1 และ Microsoft ONNX Runtime (v1.32.0) ที่โหลดเมื่อใช้งาน

คำถามที่พบบ่อย

ควรดาวน์โหลดไฟล์ Portable ZIP หรือแพ็กเกจ MSIX

สำหรับผู้ใช้ทั่วไปในตอนนี้ แนะนำให้ดาวน์โหลด Portable x64 ZIP จากหน้า ดาวน์โหลด เพราะแตกไฟล์แล้วเปิด PikaSnip.exe ใช้งานได้ทันทีโดยไม่ต้องติดตั้งใบรับรอง ส่วนไฟล์ MSIX เป็นบิลด์ทดสอบแบบลงนามเองสำหรับ sideload ที่ต้องให้สิทธิ์ผู้ดูแลระบบนำเข้า PikaSnip_0.1.0.0_x64.cer ลงใน LocalMachine\Root และ LocalMachine\TrustedPeople ส่งเข้าหน้า Microsoft Store แล้ว — อยู่ระหว่างการตรวจสอบ

ต้องติดตั้ง Microsoft Visual C++ Redistributable เพิ่มหรือไม่

ไม่ต้องครับ PikaSnip.exe คอมไพล์แบบ static CRT (/MT) ไม่มี dynamic CRT imports และในแพ็กเกจแนบ MSVC x64 CRT DLLs เฉพาะแอปจำนวน 4 ไฟล์สำหรับ onnxruntime.dll มาให้ครบ เครื่อง Windows 10 และ 11 ที่สะอาดจึงเปิดใช้งานได้ทันที

ทำไม PikaSnip ใช้แรมตอนสแตนด์บายต่ำกว่า 15 MB

ตัวโปรแกรมหลักพัฒนาด้วย C++20 เนทีฟ Win32/Direct2D โดยไม่มีเอนจินเบราว์เซอร์ และ onnxruntime.dll (v1.32.0) จะถูกโหลดแบบหน่วงเวลาผ่าน LoadLibraryExW เฉพาะเมื่อคุณสั่งรัน OCR เท่านั้น จากการทดสอบบนเครื่อง Windows 11 build 26100 ที่สะอาด พบการใช้แรมสแตนด์บายที่ 10.79–11.33 MB

PikaSnip ส่งภาพหน้าจอหรือข้อความ OCR ออกอินเทอร์เน็ตหรือไม่

ไม่เคยครับ PikaSnip ทำงานแบบออฟไลน์ 100% ไม่มี telemetry และไม่เชื่อมต่อเครือข่าย การจับภาพ การปักหมุด การวาดแก้ไข และการอ่านข้อความ OpenThai 2.1 OCR ทั้งหมดประมวลผลในเครื่องของคุณ อ่านรายละเอียดฉบับเต็มได้ที่ นโยบายความเป็นส่วนตัวของ PikaSnip หรือหน้า ความเป็นส่วนตัว

PikaSnip เปิดเองพร้อม Windows หรือไม่

ไม่ได้เปิดเป็นค่าเริ่มต้นครับ ตัวเลือกเริ่มพร้อม Windows ถูกปิดไว้ (Enabled="false") และจะเริ่มอัตโนมัติเฉพาะเมื่อคุณเปิดใช้งาน Run at Startup ด้วยตนเอง

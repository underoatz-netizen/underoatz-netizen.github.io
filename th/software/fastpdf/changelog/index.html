บันทึกการเปลี่ยนแปลง

ประวัติการเผยแพร่ของ FastPDF เรียงจากใหม่ไปเก่า

FastPDF 0.4.0 พร้อมใช้งานแล้ว เผยแพร่เมื่อวันที่ 24 ตุลาคม 2026 สำหรับ Windows x64

0.4.0 — 24 ตุลาคม 2026

  • เพิ่มกล่องโต้ตอบไปที่หน้า (Ctrl+G) พร้อมการตรวจสอบหมายเลขหน้าเป้าหมายเริ่มต้นที่ 1
  • ปรับปรุงความปลอดภัยเมื่อยกเลิกคำขอและความเสถียรของการเรนเดอร์ขณะเปลี่ยนหน้าอย่างรวดเร็ว
  • มีสองไฟล์ให้ดาวน์โหลด คือตัวติดตั้งสำหรับ Windows และไฟล์ ZIP แบบพกพา
  • ทั้งสองไฟล์ยังไม่ได้ลงนาม และเผยแพร่ค่าแฮช SHA-256 ไว้ในไฟล์ SHA256SUMS

ดูไฟล์และค่าแฮชได้ที่หน้า ดาวน์โหลด

0.3.2 — 14 ตุลาคม 2026

  • รุ่นแรกที่เผยแพร่สาธารณะของ FastPDF สำหรับ Windows x64
  • มีสองไฟล์ให้ดาวน์โหลด คือตัวติดตั้งสำหรับ Windows และไฟล์ ZIP แบบพกพา
  • ทั้งสองไฟล์ยังไม่ได้ลงนาม และเผยแพร่ค่าแฮช SHA-256 ไว้ในไฟล์ SHA256SUMS
  • การตรวจสอบอัปเดตในแอปทำแบบเรียกเอง และเปิดไปที่หน้า GitHub Releases
  • ไฟล์ที่เผยแพร่ไม่มีซอร์สโค้ดรวมอยู่

ดูที่ v0.3.2 บน GitHub Releases

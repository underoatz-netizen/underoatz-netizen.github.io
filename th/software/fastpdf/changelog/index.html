บันทึกการเปลี่ยนแปลง

ประวัติการเผยแพร่ของ PikaPDF (เดิมชื่อ FastPDF ถึงรุ่น 0.4.1) เรียงจากใหม่ไปเก่า

PikaPDF 0.5.1 พร้อมใช้งานแล้ว เผยแพร่เมื่อวันที่ 22 พฤศจิกายน 2026 สำหรับ Windows 10 และ Windows 11 (64-bit x64)

0.5.1 — 22 พฤศจิกายน 2026

รุ่นล่าสุด
  • เพิ่มธีมปรับตามระบบ (System-Aware Theme) ที่ปรับตามการตั้งค่า Light/Dark ของแอปบน Windows (AppsUseLightTheme) และความสว่างหน้าต่าง High Contrast อัตโนมัติตั้งแต่เปิดโปรแกรมและทันทีเมื่อเปลี่ยนธีมระบบ (WM_SETTINGCHANGE / WM_THEMECHANGED)
  • ปรับธีมแถบชื่อเรื่อง DWM, แถบเลื่อนและตัวควบคุม Explorer, แถบคำสั่งแถวเดียว, แถบด้านข้าง Thumbnails & Bookmarks, แผงค้นหา และแถบแจ้งเตือน โดยไม่ต้องเรนเดอร์หน้า PDF ที่แคชไว้ใหม่
  • คงการเรนเดอร์หน้า PDF พื้นหลังสีดำของโหมดนำเสนอ สีไฮไลต์การค้นหา และพู่กันวาดหมึกไว้ตามเดิมไม่เปลี่ยนแปลง
  • อัปเกรดในตำแหน่งเดิมทับ FastPDF 0.4.x และ PikaPDF 0.5.0 ได้ทันที โดยยังคงชื่อไฟล์ FastPDF.exe และรักษาการตั้งค่ากับไฟล์ล่าสุดใน %LOCALAPPDATA%\FastPDF
  • มีสองไฟล์ให้ดาวน์โหลด คือตัวติดตั้งสำหรับ Windows และไฟล์ ZIP แบบพกพา ทั้งสองไฟล์ยังไม่ได้ลงนาม และเผยแพร่ค่าแฮช SHA-256 ไว้ในไฟล์ SHA256SUMS

ดูไฟล์และค่าแฮชได้ที่หน้า ดาวน์โหลด หรือดูที่ v0.5.1 บน GitHub Releases

0.5.0 — 18 พฤศจิกายน 2026

PikaPDF
  • เปลี่ยนชื่อผลิตภัณฑ์จาก FastPDF เป็น PikaPDF โดยยังคงชื่อไฟล์โปรแกรม FastPDF.exe ภายในแพ็กเกจ เพื่อให้ชอร์ตคัตเดิมใช้งานได้ต่อเนื่อง
  • การติดตั้งใหม่จะใช้โฟลเดอร์ Program Files\PikaPDF เป็นค่าเริ่มต้น ส่วนการอัปเกรดทับ FastPDF 0.4.1 จะอัปเกรดในตำแหน่งเดิม ใช้โฟลเดอร์ติดตั้งเดิม และรักษาการตั้งค่ากับไฟล์ล่าสุดใน %LOCALAPPDATA%\FastPDF
  • เปลี่ยนแถบเมนูแบบแยก (File, View, Convert) เป็นแถบคำสั่งแถวเดียวที่ปรับขนาดตามหน้าต่าง พร้อมไอคอน Lucide และเมนู More commands (Open..., Recent Files, Save a Copy..., Save Rotated Copy..., Print..., PDF to PNG..., Image to PDF..., Check for Updates)
  • เพิ่มแถบด้านข้างภาพย่อ (Thumbnails) และบุ๊กมาร์ก (Bookmarks) เปิดปิดด้วย Ctrl+B โดยบุ๊กมาร์กภายนอกหรือระยะไกลที่ไม่รองรับจะถูกติดป้ายอย่างชัดเจนและไม่ถูกเรียกทำงาน
  • เพิ่มการวาดหมึกอิสระ (หลายสี 3 ความหนาเส้น) และการไฮไลต์ข้อความในเอกสารพร้อมเลิกทำและทำซ้ำ (Ctrl+Z / Ctrl+Y) บันทึกผ่าน Save a Copy โดยไม่เขียนทับไฟล์ที่มีอยู่หรือไฟล์ต้นฉบับ พร้อมหน้าต่างเตือนงานยังไม่บันทึกก่อนปิด เปลี่ยนไฟล์ พิมพ์ หรือส่งออก PNG
  • ปรับปรุงกล่องโต้ตอบการพิมพ์: 1–6 หน้าต่อแผ่น แสดงตัวอย่างแผ่นแรก สีหรือขาวดำ พิมพ์สองหน้า คุณภาพ Fast/Medium/Detailed ลำดับสำเนา By set/By page และความคืบหน้าพร้อมปุ่มยกเลิก
  • มีสองไฟล์ให้ดาวน์โหลด คือตัวติดตั้งสำหรับ Windows และไฟล์ ZIP แบบพกพา ทั้งสองไฟล์ยังไม่ได้ลงนาม และเผยแพร่ค่าแฮช SHA-256 ไว้ในไฟล์ SHA256SUMS

ดูไฟล์และค่าแฮชได้ที่หน้า ดาวน์โหลด หรือดูที่ v0.5.0 บน GitHub Releases

0.4.1 — 26 ตุลาคม 2026

FastPDF
  • เพิ่มการวัดและบันทึกเวลาเปิดเอกสาร PDF ลงในบันทึกวินิจฉัย การเปลี่ยนแปลงนี้เป็นการปรับปรุงการบันทึกเท่านั้น ไม่มีการกล่าวอ้างเรื่องความเร็ว
  • มีกล่องโต้ตอบไปที่หน้า (Ctrl+G) พร้อมการตรวจสอบหมายเลขหน้าเป้าหมายเริ่มต้นที่ 1
  • ตัวติดตั้ง Windows สามารถสร้างชอร์ตคัตบนเดสก์ท็อปได้แบบเลือกได้ (ปิดเป็นค่าเริ่มต้น)
  • มีสองไฟล์ให้ดาวน์โหลด คือตัวติดตั้งสำหรับ Windows และไฟล์ ZIP แบบพกพา
  • ทั้งสองไฟล์ยังไม่ได้ลงนาม และเผยแพร่ค่าแฮช SHA-256 ไว้ในไฟล์ SHA256SUMS

ดูไฟล์และค่าแฮชได้ที่หน้า ดาวน์โหลด หรือดูที่ v0.4.1 บน GitHub Releases

0.4.0 — 24 ตุลาคม 2026

FastPDF
  • เพิ่มกล่องโต้ตอบไปที่หน้า (Ctrl+G) พร้อมการตรวจสอบหมายเลขหน้าเป้าหมายเริ่มต้นที่ 1
  • ปรับปรุงความปลอดภัยเมื่อยกเลิกคำขอและความเสถียรของการเรนเดอร์ขณะเปลี่ยนหน้าอย่างรวดเร็ว
  • มีสองไฟล์ให้ดาวน์โหลด คือตัวติดตั้งสำหรับ Windows และไฟล์ ZIP แบบพกพา
  • ทั้งสองไฟล์ยังไม่ได้ลงนาม และเผยแพร่ค่าแฮช SHA-256 ไว้ในไฟล์ SHA256SUMS

FastPDF

  • มีสองไฟล์ให้ดาวน์โหลด คือตัวติดตั้งสำหรับ Windows และไฟล์ ZIP แบบพกพา

  • ไฟล์ที่เผยแพร่ไม่มีซอร์สโค้ดรวมอยู่

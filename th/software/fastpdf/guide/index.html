คู่มือและคำถามที่พบบ่อย

คู่มือนี้พาดูวิธีใช้ PikaPDF (เดิมชื่อ FastPDF) ครอบคลุมฟีเจอร์ในรุ่นปัจจุบัน เวอร์ชัน 0.5.1 สำหรับ Windows x64 ดาวน์โหลดได้ที่หน้า ดาวน์โหลด

พื้นฐาน คีย์ลัด ข้อจำกัดที่ทราบ คำถามที่พบบ่อย

พื้นฐาน

  • แถบคำสั่งและ More commands คำสั่งต่าง ๆ อยู่ในแถบคำสั่งแถวเดียวที่ปรับขนาดตามหน้าต่างพร้อมไอคอน Lucide คำสั่งที่ไม่พอวางบนแถวและคำสั่งจัดการเอกสารจะอยู่ในเมนู More commands (Open..., Recent Files, Save a Copy..., Save Rotated Copy..., Print..., PDF to PNG..., Image to PDF..., Check for Updates)
  • เปิดเอกสาร ใช้คำสั่ง Open... (Ctrl+O), Recent Files, ลากไฟล์ PDF หนึ่งไฟล์วางบนหน้าต่าง หรือเปิดโดยตรงจากบรรทัดคำสั่ง
  • แถบด้านข้าง (Ctrl+B) เปิด/ปิดแถบด้านข้างเพื่อสลับระหว่างภาพย่อ (Thumbnails) และบุ๊กมาร์ก (Bookmarks) บุ๊กมาร์กที่เป็นลิงก์ภายนอกหรือระยะไกลที่ไม่รองรับจะถูกติดป้ายอย่างชัดเจนและไม่ถูกเรียกทำงาน
  • อ่านและไปที่หน้า เอกสารแสดงแบบต่อเนื่องหนึ่งคอลัมน์ เลื่อนด้วยล้อเมาส์หรือแป้นพิมพ์ หรือกระโดดไปยังหน้าที่ต้องการได้ทันทีผ่านกล่องโต้ตอบไปที่หน้า (Ctrl+G)
  • ซูม ใช้คำสั่งซูม หรือกดปุ่ม Control ค้างแล้วหมุนล้อเมาส์ ระบบยึดตำแหน่งจะคงที่ให้เมื่อซูมหรือปรับขนาดหน้าต่าง
  • ค้นหา เปิดแผงค้นหา (Ctrl+F) แล้วพิมพ์ การค้นหาทำงานทันทีขณะพิมพ์และไฮไลต์ผลที่พบในเอกสาร
  • วาดและไฮไลต์ วาดหมึกอิสระได้หลายสีและ 3 ความหนาเส้น หรือไฮไลต์ข้อความในเอกสาร เลิกทำและทำซ้ำด้วย Ctrl+Z และ Ctrl+Y
  • Save a Copy บันทึกคำอธิบายประกอบผ่านคำสั่ง Save a Copy... ซึ่งสร้างไฟล์ใหม่เสมอโดยไม่เขียนทับไฟล์ที่มีอยู่หรือไฟล์ต้นฉบับ และมีหน้าต่างเตือนงานยังไม่บันทึกก่อนปิด เปิดไฟล์อื่น พิมพ์ หรือส่งออกเป็น PNG
  • นำเสนอ โหมดนำเสนอ (F11) จะเต็มหน้าจอและแสดงทีละหน้า ใช้ปุ่มลูกศร ปุ่มเว้นวรรค หรือปุ่มเลื่อนหน้าเพื่อเปลี่ยนหน้า
  • จับภาพหน้าจอ (Ctrl+S) ลากเลือกบริเวณบนหน้าเพื่อคัดลอกลงคลิปบอร์ด และบันทึกเป็นรูปภาพได้หากต้องการ หมายเหตุ: Ctrl+S ใช้สำหรับจับภาพหน้าจอ ไม่ใช่การบันทึกเอกสาร
  • แปลงไฟล์ ส่งออกหน้าเอกสารเป็นไฟล์ภาพ PNG หรือรวมไฟล์ภาพ PNG, JPEG และ BMP ให้เป็น PDF ไฟล์เดียว
  • พิมพ์ (Ctrl+P) ใช้กล่องโต้ตอบการพิมพ์ที่รองรับ 1–6 หน้าต่อแผ่น แสดงตัวอย่างแผ่นแรก พิมพ์สีหรือขาวดำ พิมพ์สองหน้า คุณภาพ Fast/Medium/Detailed ลำดับสำเนา By set/By page และความคืบหน้าพร้อมปุ่มยกเลิก
  • ธีมปรับตามระบบ (System-Aware Theme) PikaPDF ปรับส่วนติดต่อผู้ใช้ของหน้าต่าง (แถบชื่อเรื่อง DWM, แถบเลื่อน/ตัวควบคุม Explorer, แถบคำสั่ง, แถบด้านข้าง, แผงค้นหา และแถบแจ้งเตือน) ตามการตั้งค่า Light/Dark และโหมด High Contrast ของ Windows อัตโนมัติตั้งแต่เปิดโปรแกรมและทันทีเมื่อระบบเปลี่ยนธีม โดยไม่เรนเดอร์หน้า PDF ที่แคชไว้ใหม่และคงพื้นหลังสีดำของโหมดนำเสนอไว้ตามเดิม

ข้อจำกัดที่ทราบ

ต่อไปนี้คือข้อจำกัดในตอนนี้ เพื่อให้คุณรู้ว่าควรคาดหวังอะไร:

  • ยังเปิดไฟล์ PDF ที่ตั้งรหัสผ่านไม่ได้
  • การค้นหาและการไฮไลต์ข้อความครอบคลุมเฉพาะชั้นข้อความในเอกสาร ไม่มี OCR หน้าสแกนจึงค้นหาหรือไฮไลต์ข้อความไม่ได้
  • ยังไม่มีเครื่องมือเพิ่มข้อความ (Add Text)
  • ปิดการแก้ไขคำอธิบายประกอบในไฟล์ PDF ที่มีลายเซ็นดิจิทัล มีการป้องกัน หรือเข้ารหัส รวมถึงบนหน้าที่มีคำอธิบายประกอบอยู่แล้ว
  • Save a Copy จะไม่เขียนทับไฟล์ที่มีอยู่หรือไฟล์ต้นฉบับ
  • การหมุนหน้าใช้กับเซสชันที่เปิดอยู่เท่านั้น หากต้องการเก็บการหมุนไว้ ให้ใช้ Save Rotated Copy ไฟล์ต้นฉบับจะไม่ถูกแก้ไข
  • ไฟล์ที่เผยแพร่ยังไม่ได้ลงนาม Windows SmartScreen หรือเบราว์เซอร์อาจแสดงคำเตือนก่อนคุณเปิดใช้งาน

คำถามที่พบบ่อย

ดาวน์โหลด PikaPDF ได้ที่ไหน

เวอร์ชัน 0.5.1 สำหรับ Windows 10 และ Windows 11 (x64) ดาวน์โหลดได้ที่หน้า ดาวน์โหลด ไฟล์ที่เผยแพร่ยังไม่ได้ลงนาม Windows อาจแสดงคำเตือนเมื่อคุณเปิดใช้งาน

อัปเกรดจาก FastPDF 0.4.x หรือ PikaPDF 0.5.0 ได้อย่างไร

PikaPDF 0.5.1 อัปเกรดทับ FastPDF 0.4.x และ PikaPDF 0.5.0 ในตำแหน่งเดิมได้ทันที โดยใช้โฟลเดอร์ติดตั้งเดิม และรักษาการตั้งค่ากับไฟล์ล่าสุดไว้ใน %LOCALAPPDATA%\FastPDF ส่วนการติดตั้งใหม่จะใช้โฟลเดอร์ Program Files\PikaPDF เป็นค่าเริ่มต้น ทั้งในตัวติดตั้งและไฟล์ ZIP ยังคงใช้ชื่อไฟล์โปรแกรม FastPDF.exe (พร้อม pdfium.dll และ licenses/) เพื่อให้ชอร์ตคัตเดิมใช้งานได้ต่อเนื่อง

ต้องมีบัญชีเพื่อใช้ PikaPDF หรือไม่

ไม่ต้อง PikaPDF เป็นโปรแกรมบนเดสก์ท็อป ไม่มีการใช้บัญชีหรือการลงชื่อเข้าใช้

ซอร์สโค้ดอยู่ที่ไหน

ซอร์สโค้ดถูกเก็บเป็นส่วนตัว ไม่ได้เผยแพร่ และ PikaPDF ไม่ใช่โปรเจกต์โอเพนซอร์ส

PikaPDF ใช้กับคอมพิวเตอร์แบบไหน

PikaPDF ใช้บน Windows 10 และ Windows 11 รุ่น 64 บิต (x64)

PikaPDF ส่งเอกสารของฉันออกไปที่ใดหรือไม่

ไม่ส่งครับ PikaPDF ประมวลผลเอกสาร PDF ทั้งหมดในเครื่องของคุณและไม่อัปโหลดเอกสารออกไปภายนอก การเชื่อมต่อเครือข่ายเพียงอย่างเดียวคือคำสั่งตรวจสอบอัปเดต (Check for Updates) เมื่อคุณกดใช้งานเองเท่านั้น ดูรายละเอียดทั้งหมดได้ที่หน้า ความเป็นส่วนตัว

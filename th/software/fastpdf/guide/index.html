คู่มือและคำถามที่พบบ่อย

คู่มือนี้พาดูวิธีใช้ FastPDF ครอบคลุมฟีเจอร์ในรุ่นปัจจุบัน เวอร์ชัน 0.3.2 สำหรับ Windows x64 ดาวน์โหลดได้ที่หน้า ดาวน์โหลด

พื้นฐาน

  • เปิดเอกสาร ใช้คำสั่งเปิด ลากไฟล์ PDF หนึ่งไฟล์วางบน หน้าต่าง หรือเปิดโดยตรงจากบรรทัดคำสั่ง
  • อ่าน เอกสารแสดงแบบต่อเนื่องหนึ่งคอลัมน์ เลื่อนด้วย ล้อเมาส์หรือแป้นพิมพ์
  • ซูม ใช้คำสั่งซูม หรือกดปุ่ม Control ค้างแล้วหมุนล้อเมาส์ ระบบยึดตำแหน่งจะคงที่ให้เมื่อซูมหรือปรับขนาดหน้าต่าง
  • ค้นหา เปิดแผงค้นหาแล้วพิมพ์ การค้นหาทำงานทันทีขณะพิมพ์ และไฮไลต์ผลที่พบในเอกสาร
  • นำเสนอ โหมดนำเสนอจะเต็มหน้าจอและแสดงทีละหน้า ใช้ปุ่มลูกศร ปุ่มเว้นวรรค หรือปุ่มเลื่อนหน้าเพื่อเปลี่ยนหน้า
  • จับภาพ ลากเลือกบริเวณบนหน้าเพื่อคัดลอกลงคลิปบอร์ด และบันทึกเป็นรูปภาพได้หากต้องการ
  • แปลงไฟล์ ส่งออกหน้าเอกสารเป็นไฟล์ภาพ PNG หรือรวมไฟล์ ภาพ PNG, JPEG และ BMP ให้เป็น PDF ไฟล์เดียว
  • พิมพ์ พิมพ์เอกสารปัจจุบันผ่านระบบพิมพ์มาตรฐานของ Windows

ข้อจำกัดที่ทราบ

ต่อไปนี้คือข้อจำกัดในตอนนี้ เพื่อให้คุณรู้ว่าควรคาดหวังอะไร:

  • ยังเปิดไฟล์ PDF ที่ตั้งรหัสผ่านไม่ได้
  • การค้นหาครอบคลุมเฉพาะชั้นข้อความของเอกสาร ไม่มี OCR หน้าสแกนจึงไม่พบผลลัพธ์
  • การหมุนหน้าใช้กับเซสชันที่เปิดอยู่เท่านั้น หากต้องการเก็บการหมุนไว้ ให้บันทึกสำเนาที่หมุนแล้ว ไฟล์ต้นฉบับจะไม่ถูกแก้ไข

คำถามที่พบบ่อย

ดาวน์โหลด FastPDF ได้ที่ไหน

เวอร์ชัน 0.3.2 สำหรับ Windows x64 ดาวน์โหลดได้ที่หน้า ดาวน์โหลด ไฟล์ที่เผยแพร่ยังไม่ได้ ลงนาม Windows อาจแสดงคำเตือนเมื่อคุณเปิดใช้งาน

ต้องมีบัญชีเพื่อใช้ FastPDF หรือไม่

ไม่ต้อง FastPDF เป็นโปรแกรมบนเดสก์ท็อป ไม่มีการใช้บัญชีหรือการลงชื่อเข้าใช้

ซอร์สโค้ดอยู่ที่ไหน

ซอร์สโค้ดถูกเก็บเป็นส่วนตัว ไม่ได้เผยแพร่ และ FastPDF ไม่ใช่โปรเจกต์ โอเพนซอร์ส

FastPDF ใช้กับคอมพิวเตอร์แบบไหน

FastPDF ใช้บน Windows รุ่น 0.3.2 เป็นไฟล์สำหรับสถาปัตยกรรม 64 บิต (x64)

FastPDF ส่งเอกสารของฉันออกไปที่ใดหรือไม่

เรื่องการจัดการข้อมูล โปรดดูหน้า ความเป็นส่วนตัว นโยบายความเป็นส่วนตัวของแอปยังเป็นฉบับร่างและยังไม่มีผลบังคับใช้

PikaPDF

PikaPDF (เดิมชื่อ FastPDF) เป็นโปรแกรมบนเดสก์ท็อปสำหรับ Windows ใช้ทำงานกับเอกสาร PDF พัฒนาโดย OZ Lab ซอร์สโค้ดเป็นส่วนตัว และเวอร์ชัน 0.5.1 พร้อมให้ดาวน์โหลดแล้ว

ดาวน์โหลด v0.5.1 คู่มือและคำถามที่พบบ่อย

พร้อมใช้งานแล้ว: PikaPDF 0.5.1 สำหรับ Windows x64 สามารถอัปเกรดในตำแหน่งเดิมทับ FastPDF 0.4.1 และ PikaPDF 0.5.0 ได้ทันที โดยใช้โฟลเดอร์ติดตั้งเดิมและรักษาการตั้งค่ากับไฟล์ล่าสุดไว้ครบถ้วน ไฟล์ที่เผยแพร่ยังไม่ได้ลงนาม Windows อาจแสดงคำเตือนเมื่อคุณเปิดใช้งาน ดูไฟล์และค่าแฮช SHA-256 ได้ที่หน้า ดาวน์โหลด

ทำอะไรได้บ้าง ภาพหน้าจอ ฟีเจอร์ สถานะ หน้าถัดไป

ฟีเจอร์

17 ความสามารถใน 6 กลุ่ม

ธีมและหน้าตา

  • ปรับธีมตามระบบ Windows (Light, Dark และ High Contrast) อัตโนมัติตั้งแต่เปิดโปรแกรมและทันทีเมื่อเปลี่ยนธีมระบบ โดยอัปเดตแถบชื่อเรื่อง DWM, ตัวควบคุม Explorer, แถบคำสั่ง, แถบด้านข้าง, แผงค้นหา และแถบแจ้งเตือน โดยไม่เรนเดอร์หน้า PDF ที่แคชไว้ใหม่และไม่กระทบโหมดนำเสนอ
  • เข้าถึงคำสั่งจากแถบคำสั่งแถวเดียวที่ปรับขนาดตามหน้าต่างพร้อมไอคอน Lucide และเมนู More commands สำหรับคำสั่งที่ล้นหน้าจอและคำสั่งจัดการเอกสาร

อ่านและนำทาง

  • เปิดและอ่านเอกสาร PDF พร้อมการเลื่อนแบบต่อเนื่องหนึ่งคอลัมน์
  • แสดงหรือซ่อนแถบด้านข้างภาพย่อ (Thumbnails) และบุ๊กมาร์ก (Bookmarks) ด้วย Ctrl+B โดยบุ๊กมาร์กที่เป็นลิงก์ภายนอกหรือระยะไกลที่ไม่รองรับจะถูกติดป้ายอย่างปลอดภัยและไม่ถูกเรียกทำงาน
  • ไปยังหน้าที่ต้องการได้ทันทีด้วยกล่องโต้ตอบไปที่หน้า (Ctrl+G)
  • การซูม: พอดีความกว้าง พอดีหน้า 100% และซูมเอง พร้อมระบบยึดตำแหน่งที่คงที่ให้คุณ
  • โหมดนำเสนอ (F11) สำหรับดูทีละหน้าแบบเต็มจอ
  • เก็บรายการเอกสารที่เปิดล่าสุด
  • เปิดเอกสารได้โดยตรงจากบรรทัดคำสั่ง หรือลากไฟล์หนึ่งไฟล์วางบนหน้าต่าง

ค้นหาและจับภาพ

  • ค้นหาภายในเอกสารด้วยแผงค้นหาที่ค้นแบบทันทีขณะพิมพ์ (Ctrl+F)
  • จับภาพบางส่วนของหน้าไปยังคลิปบอร์ดด้วยคำสั่งจับภาพหน้าจอ (Ctrl+S) และบันทึกเป็นรูปภาพได้

เขียน ไฮไลต์ และบันทึก

  • วาดหมึกอิสระได้หลายสีและ 3 ความหนาเส้น หรือไฮไลต์ข้อความที่เลือกได้หลายสี พร้อมเลิกทำและทำซ้ำด้วย Ctrl+Z และ Ctrl+Y
  • บันทึกสำเนาผ่านคำสั่ง Save a Copy พร้อมระบบป้องกันงานที่ยังไม่บันทึก ซึ่งจะถามยืนยันก่อนปิด เปลี่ยนไฟล์ พิมพ์ หรือส่งออก PNG และไม่เขียนทับไฟล์ที่มีอยู่หรือไฟล์ต้นฉบับ

แปลงและจัดหน้า

  • ส่งออกหน้าเอกสารเป็นไฟล์ภาพ PNG และรวมไฟล์ภาพ PNG, JPEG และ BMP ให้เป็น PDF ไฟล์เดียว
  • หมุนหน้าและบันทึกสำเนาที่หมุนแล้ว โดยไม่แก้ไฟล์ต้นฉบับ

พิมพ์และอัปเดต

  • กล่องโต้ตอบการพิมพ์แบบใหม่: จัดวาง 1–6 หน้าต่อแผ่น แสดงตัวอย่างแผ่นแรก เลือกพิมพ์สีหรือขาวดำ พิมพ์สองหน้า คุณภาพ Fast/Medium/Detailed ลำดับชุดสำเนา By set/By page พร้อมแถบความคืบหน้าและปุ่มยกเลิก
  • ตัวเลือก "ตรวจสอบอัปเดต" แบบเรียกเอง และกล่อง About พร้อมแผงข้อมูลวินิจฉัย (Ctrl+D) สำหรับการแก้ปัญหา

FastPDF

FastPDF เป็นโปรแกรมบนเดสก์ท็อปสำหรับ Windows ใช้ทำงานกับเอกสาร PDF พัฒนาโดย OZ Lab ซอร์สโค้ดถูกเก็บเป็นส่วนตัว และยังไม่เปิดให้ดาวน์โหลด

ความพร้อมใช้งาน: ยังไม่มีรุ่นที่เผยแพร่หรือให้ดาวน์โหลด แผนคือการเผยแพร่ FastPDF ผ่าน GitHub Releases ในอนาคต รวมถึงไฟล์ที่ยังไม่ได้ ลงนาม แผนนี้ยังไม่พร้อมใช้งานในตอนนี้

FastPDF ทำอะไรได้บ้าง

FastPDF รวมความสามารถในการอ่านและเครื่องมือจัดการเอกสารไว้ในโปรแกรมเดียว ฟีเจอร์ด้านล่างคือสิ่งที่โปรเจกต์ได้พัฒนาจริงและมีเอกสารกำกับ:

  • เปิดและอ่านเอกสาร PDF พร้อมการเลื่อนแบบต่อเนื่องหนึ่งคอลัมน์
  • การซูม: พอดีความกว้าง พอดีหน้า 100% และซูมเอง พร้อมระบบยึดตำแหน่ง ที่คงที่ให้คุณ
  • โหมดนำเสนอสำหรับดูทีละหน้าแบบเต็มจอ
  • ค้นหาภายในเอกสารด้วยแผงค้นหาที่ค้นแบบทันทีขณะพิมพ์
  • จับภาพบางส่วนของหน้าไปยังคลิปบอร์ด และบันทึกเป็นรูปภาพได้
  • ส่งออกหน้าเอกสารเป็นไฟล์ภาพ PNG
  • รวมไฟล์ภาพ PNG, JPEG และ BMP ให้เป็น PDF ไฟล์เดียว
  • พิมพ์ผ่านระบบพิมพ์มาตรฐานของ Windows
  • หมุนหน้าและบันทึกสำเนาที่หมุนแล้ว โดยไม่แก้ไฟล์ต้นฉบับ
  • เก็บรายการเอกสารที่เปิดล่าสุด
  • เปิดเอกสารได้โดยตรงจากบรรทัดคำสั่ง หรือลากไฟล์หนึ่งไฟล์วางบนหน้าต่าง
  • ตัวเลือก "ตรวจสอบอัปเดต" แบบเรียกเอง และกล่อง About
  • แผงข้อมูลวินิจฉัยแบบเปิดปิดได้สำหรับการแก้ปัญหา

สถานะโปรเจกต์

สถานะของ FastPDF ตามที่เผยแพร่บนเว็บนี้
แพลตฟอร์ม โปรแกรมบนเดสก์ท็อปสำหรับ Windows
ซอร์สโค้ด ส่วนตัว (ไม่ได้เผยแพร่)
รุ่นที่เผยแพร่ ยังไม่มี
ดาวน์โหลด ยังไม่พร้อมใช้งาน
แผนการเผยแพร่ GitHub Releases รวมถึงไฟล์ที่ยังไม่ได้ลงนาม — เป็นแผน ยังไม่พร้อมใช้งาน
ช่องทางช่วยเหลือ ผ่านระบบแจ้งปัญหาสาธารณะของโปรเจกต์ (ดู ช่วยเหลือ)

ไปที่หน้าถัดไป

  • คู่มือและคำถามที่พบบ่อย — วิธีใช้ฟีเจอร์ต่างๆ และคำถามที่พบบ่อย
  • ดาวน์โหลด — ความพร้อมใช้งานในปัจจุบัน
  • บันทึกการเปลี่ยนแปลง — สถานะประวัติการเผยแพร่

ดาวน์โหลด PikaPDF

เวอร์ชัน 0.5.0 สำหรับ Windows x64 เลือกตัวติดตั้งหากอยากให้ PikaPDF ติดตั้งให้ หรือเลือกไฟล์ ZIP แบบพกพาหากอยากเก็บไว้ใช้งานเอง

PikaPDF 0.5.0 พร้อมให้ดาวน์โหลดแล้ว ทั้งสองไฟล์มาจาก GitHub Release ทางการ ชื่อไฟล์โปรแกรมภายในแพ็กเกจยังคงใช้ FastPDF.exe เพื่อให้ชอร์ตคัตเดิมใช้งานต่อได้ หากคุณมี FastPDF 0.4.1 อยู่แล้ว ตัวติดตั้งจะอัปเกรดทับในตำแหน่งเดิมโดยใช้โฟลเดอร์เดิม และรักษาการตั้งค่ากับไฟล์ล่าสุดไว้ครบถ้วน ไฟล์ยังไม่ได้ลงนาม Windows อาจแสดงคำเตือนก่อนคุณเปิดใช้งาน

ไฟล์ในรุ่นนี้

  • PikaPDF-0.5.0-win-x64-Setup.exe — ตัวติดตั้งสำหรับ Windows (ประมาณ 5.4 MB)
  • PikaPDF-0.5.0-win-x64.zip — ไฟล์ ZIP แบบพกพา (ประมาณ 4.1 MB)
  • SHA256SUMS — ไฟล์ค่าแฮชสำหรับทั้งสองไฟล์

ทั้งสามไฟล์รวมอยู่ที่ หน้าเผยแพร่ v0.5.0 บน GitHub

ค่าแฮชและการลงนาม

ไฟล์แต่ละไฟล์มีค่าแฮช SHA-256 หลังดาวน์โหลด ให้ใช้เครื่องมือตรวจค่าแฮช ของคุณแล้วเทียบกับค่าด้านล่าง หากไม่ตรงกัน โปรดอย่าเปิดไฟล์นั้น

ตัวติดตั้งและตัวแอปไม่ได้ลงนามด้วยใบรับรองความปลอดภัย Windows SmartScreen หรือเบราว์เซอร์อาจแสดงคำเตือนก่อนคุณเปิดไฟล์ ซึ่งเป็นเรื่องปกติของไฟล์ที่ยัง ไม่ได้ลงนาม และไม่จำเป็นต้องปิดการป้องกันใด ๆ ค่าแฮชด้านบนมีไว้เพื่อให้คุณ ยืนยันได้ว่าไฟล์นั้นเป็นไฟล์ที่เราเผยแพร่จริง

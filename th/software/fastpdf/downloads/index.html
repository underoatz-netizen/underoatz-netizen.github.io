ดาวน์โหลด PikaPDF

เวอร์ชัน 0.5.0 สำหรับ Windows x64 เลือกตัวติดตั้งหากอยากให้ PikaPDF ติดตั้งให้ หรือเลือกไฟล์ ZIP แบบพกพาหากอยากเก็บไว้ใช้งานเอง

PikaPDF 0.5.0 พร้อมให้ดาวน์โหลดแล้ว ทั้งสองไฟล์มาจาก GitHub Release ทางการ ชื่อไฟล์โปรแกรมภายในแพ็กเกจยังคงใช้ FastPDF.exe เพื่อให้ชอร์ตคัตเดิมใช้งานต่อได้ หากคุณมี FastPDF 0.4.1 อยู่แล้ว ตัวติดตั้งจะอัปเกรดทับในตำแหน่งเดิมโดยใช้โฟลเดอร์เดิม และรักษาการตั้งค่ากับไฟล์ล่าสุดไว้ครบถ้วน ไฟล์ยังไม่ได้ลงนาม Windows อาจแสดงคำเตือนก่อนคุณเปิดใช้งาน

แพ็กเกจพร้อมใช้งานภายในประกอบด้วย FastPDF.exe, pdfium.dll และ licenses/ แตกไฟล์ทั้งหมดลงโฟลเดอร์ที่ต้องการแล้วเปิดใช้งานได้ทันที

ดาวน์โหลดไฟล์ ZIP แบบพกพา
  • SHA256SUMS ไฟล์ค่าแฮชสำหรับทั้งสองไฟล์ ไฟล์ค่าแฮช
  • หน้าเผยแพร่ v0.5.0 บน GitHub ทั้งสามไฟล์รวมอยู่ที่หน้า Release ทางการบน GitHub GitHub

เริ่มต้นใช้งานอย่างรวดเร็ว

3 ขั้นตอน
  1. ขั้นตอน 01

    ดาวน์โหลดและตรวจ SHA-256

    เลือกดาวน์โหลดตัวติดตั้งหรือไฟล์ ZIP แบบพกพาจาก GitHub Releases แล้วเทียบค่าแฮช SHA-256 กับตารางด้านล่างก่อนเปิดใช้งาน

  2. ขั้นตอน 02

    ติดตั้งหรือแตกไฟล์

    เปิดตัวติดตั้ง (หรือแตกไฟล์ทั้งหมดใน ZIP) เนื่องจากไฟล์ยังไม่ได้ลงนาม Windows SmartScreen อาจแสดงคำเตือน — เมื่อตรวจค่า SHA-256 ตรงกันแล้ว ให้เลือก More info > Run anyway

  3. ขั้นตอน 03

    เปิดใช้งานและอัปเกรด

    เปิด PikaPDF (FastPDF.exe) หากอัปเกรดจาก FastPDF 0.4.1 ระบบจะใช้โฟลเดอร์เดิมและเก็บการตั้งค่าใน %LOCALAPPDATA%\FastPDF ไว้ครบถ้วน

ค่าแฮชและการลงนาม

ตรวจสอบความถูกต้อง SHA-256

ไฟล์แต่ละไฟล์มีค่าแฮช SHA-256 หลังดาวน์โหลด ให้ใช้เครื่องมือตรวจค่าแฮชของคุณแล้วเทียบกับค่าด้านล่าง หากไม่ตรงกัน โปรดอย่าเปิดไฟล์นั้น

ตัวติดตั้งและตัวแอปไม่ได้ลงนามด้วยใบรับรองความปลอดภัย Windows SmartScreen หรือเบราว์เซอร์อาจแสดงคำเตือนก่อนคุณเปิดไฟล์ ซึ่งเป็นเรื่องปกติของไฟล์ที่ยังไม่ได้ลงนาม และไม่จำเป็นต้องปิดการป้องกันใด ๆ ค่าแฮชด้านบนมีไว้เพื่อให้คุณยืนยันได้ว่าไฟล์นั้นเป็นไฟล์ที่เราเผยแพร่จริง

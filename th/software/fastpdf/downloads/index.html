ดาวน์โหลด

ยังไม่มีอะไรให้ดาวน์โหลดในตอนนี้

ยังไม่มีรุ่นสาธารณะหรือไฟล์ให้ดาวน์โหลด FastPDF ยังอยู่ ระหว่างการพัฒนา ซอร์สโค้ดถูกเก็บเป็นส่วนตัว และยังไม่มีการเผยแพร่ตัวติดตั้ง ไฟล์บีบอัด หรือไบนารีใด ๆ บนเว็บนี้

หมายความว่าอย่างไร

  • หน้านี้ไม่มีปุ่มหรือลิงก์ดาวน์โหลด เพราะยังไม่มีไฟล์ให้ดาวน์โหลด
  • หน้านี้ไม่ประกาศเลขเวอร์ชันสาธารณะ
  • หน้านี้ไม่ประกาศค่าแฮชตรวจสอบ (checksum)
  • หากพบไฟล์ที่อ้างว่าเป็น FastPDF จากที่อื่น ควรถือว่ายังไม่ได้รับการ ยืนยัน เราจะบันทึกเฉพาะไฟล์ที่เผยแพร่ผ่านช่องทางทางการของโปรเจกต์เอง เมื่อมีขึ้นจริงเท่านั้น

แผนการเผยแพร่

แผนคือการเผยแพร่ไฟล์ FastPDF ผ่าน GitHub Releases ในอนาคต ไฟล์เหล่านั้น คาดว่าจะเป็นไฟล์ที่ ยังไม่ได้ลงนาม ซึ่งหมายความว่า Windows อาจแสดงคำเตือนความปลอดภัยเมื่อเปิดใช้งาน แผนนี้ยังไม่พร้อมใช้งาน ในตอนนี้ และไม่มีข้อความใดบนหน้านี้เป็นการสัญญาวันที่หรือเวอร์ชัน

หน้าที่เกี่ยวข้อง

  • บันทึกการเปลี่ยนแปลง — สถานะประวัติการเผยแพร่
  • ช่วยเหลือ — ช่องทางขอความช่วยเหลือ
  • ภาพรวม FastPDF — ผลิตภัณฑ์นี้ทำอะไรได้บ้าง

OZ Lab

OZ Lab พัฒนาซอฟต์แวร์สำหรับ Windows ผลิตภัณฑ์ของเราคือ PikaPDF (เดิมชื่อ FastPDF) โปรแกรมบนเดสก์ท็อปสำหรับทำงานกับเอกสาร PDF และ PikaView (เดิมชื่อ OZ Image Viewer) โปรแกรมดูรูปภาพที่รวดเร็ว

ผลิตภัณฑ์ของเรา

  • PikaPDF (เดิมชื่อ FastPDF)

    โปรแกรมบนเดสก์ท็อปสำหรับ Windows ใช้เปิดและทำงานกับเอกสาร PDF: อ่าน ค้นหา ใส่คำอธิบายประกอบ นำเสนอ จับภาพ ส่งออกเป็นรูปภาพ รวมรูปภาพเป็น PDF และพิมพ์

    เวอร์ชัน 0.5.0 พร้อมให้ดาวน์โหลดสำหรับ Windows x64

  • PikaView (เดิมชื่อ OZ Image Viewer)

    โปรแกรมดูรูปภาพบนเดสก์ท็อปสำหรับ Windows รองรับไฟล์ภาพนิ่งทั่วไป แสดงภาพแรกอย่างรวดเร็ว ซูมและเลื่อนภาพได้ลื่นไหล เลื่อนดูภาพในโฟลเดอร์ แก้ไขแบบไม่ทำลายต้นฉบับ และพิมพ์

    เวอร์ชัน 0.1.1 พร้อมให้ดาวน์โหลดสำหรับ Windows x64

สถานะปัจจุบัน

PikaPDF 0.5.0 พร้อมใช้งานแล้ว เป็นรุ่นที่เดิมชื่อ FastPDF เผยแพร่บน GitHub Releases เป็นไฟล์ที่ยังไม่ได้ลงนาม Windows อาจแสดงคำเตือนด้านความปลอดภัยเมื่อคุณ เปิดใช้งาน ซอร์สโค้ดยังคงเป็นส่วนตัว ดูไฟล์และค่าแฮช SHA-256 ได้ที่หน้า ดาวน์โหลด

PikaView 0.1.1 พร้อมใช้งานแล้ว เป็นรุ่นที่เดิมชื่อ OZ Image Viewer เผยแพร่แพ็กเกจทางการสำหรับ Windows x64 ทั้งตัวติดตั้งและแบบพกพา พร้อมซอร์สโค้ดสำหรับส่วนประกอบ LGPL ซอร์สโค้ดส่วนแรกเปิดเผยสาธารณะบน GitHub ที่ underoatz-netizen/oz-image-viewer ดูไฟล์และค่าแฮช SHA-256 ได้ที่หน้า ดาวน์โหลด

เริ่มต้นดู

  • ซอฟต์แวร์ — ผลิตภัณฑ์ที่มีในเว็บนี้
  • PikaPDF — ผลิตภัณฑ์นี้ทำอะไรได้บ้าง
  • คู่มือและคำถามที่พบบ่อย — วิธีใช้งาน
  • PikaView (เดิมชื่อ OZ Image Viewer) — โปรแกรมดูรูปภาพสำหรับ Windows
  • ช่วยเหลือ — ช่องทางขอความช่วยเหลือ และสถานะการรับบริจาค
  • ความเป็นส่วนตัว — การจัดการข้อมูลของเว็บนี้ และของแอป

OZ Lab

OZ Lab พัฒนาซอฟต์แวร์สำหรับ Windows ผลิตภัณฑ์ปัจจุบันคือ FastPDF ซึ่งเป็นโปรแกรมบนเดสก์ท็อปสำหรับทำงานกับเอกสาร PDF

ผลิตภัณฑ์ปัจจุบันของเรา

  • FastPDF

    โปรแกรมบนเดสก์ท็อปสำหรับ Windows ใช้เปิดและทำงานกับเอกสาร PDF: อ่าน ค้นหา นำเสนอ จับภาพ ส่งออกเป็นรูปภาพ รวมรูปภาพเป็น PDF และพิมพ์

    ยังไม่เปิดให้ดาวน์โหลด

สถานะปัจจุบัน

FastPDF อยู่ระหว่างการพัฒนา ซอร์สโค้ดถูกเก็บเป็น ส่วนตัว และยังไม่มีรุ่นที่เผยแพร่หรือให้ดาวน์โหลด แผนการเผยแพร่ในอนาคต คือการปล่อยไฟล์ผ่าน GitHub รวมถึงไฟล์ที่ยังไม่ได้ลงนาม แต่แผนนี้ยังไม่พร้อมใช้งานในตอนนี้

เริ่มต้นดู

  • ซอฟต์แวร์ — ผลิตภัณฑ์ที่มีในเว็บนี้
  • FastPDF — ผลิตภัณฑ์นี้ทำอะไรได้บ้าง
  • คู่มือและคำถามที่พบบ่อย — วิธีใช้งาน
  • ช่วยเหลือ — ช่องทางขอความช่วยเหลือ และสถานะการรับบริจาค
  • ความเป็นส่วนตัว — การจัดการข้อมูลของเว็บนี้ และของแอป

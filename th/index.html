OZ Lab

OZ Lab พัฒนาซอฟต์แวร์สำหรับ Windows ผลิตภัณฑ์ของเราคือ PikaPDF (เดิมชื่อ FastPDF) โปรแกรมบนเดสก์ท็อปสำหรับทำงานกับเอกสาร PDF และ PikaView (เดิมชื่อ OZ Image Viewer) โปรแกรมดูรูปภาพที่รวดเร็ว

ดูซอฟต์แวร์ทั้งหมด ดาวน์โหลด PikaPDF v0.5.1

ผลิตภัณฑ์ของเรา

ซอฟต์แวร์สำหรับ Windows 3 รายการ

  • PikaPDF (เดิมชื่อ FastPDF)

    v0.5.1 · Windows x64

    โปรแกรมบนเดสก์ท็อปสำหรับ Windows ใช้เปิดและทำงานกับเอกสาร PDF: อ่าน ค้นหา ใส่คำอธิบายประกอบ นำเสนอ จับภาพ ส่งออกเป็นรูปภาพ รวมรูปภาพเป็น PDF และพิมพ์ พร้อมธีมที่ปรับตามระบบ Light/Dark

    เวอร์ชัน 0.5.1 พร้อมให้ดาวน์โหลดสำหรับ Windows x64

    ดาวน์โหลด ภาพรวม

  • PikaView (เดิมชื่อ OZ Image Viewer)

    v0.1.2 · Windows x64

    โปรแกรมดูรูปภาพบนเดสก์ท็อปสำหรับ Windows รองรับไฟล์ภาพนิ่งทั่วไป แสดงภาพแรกอย่างรวดเร็ว ซูมและเลื่อนภาพได้ลื่นไหล เลื่อนดูภาพในโฟลเดอร์ แก้ไขแบบไม่ทำลายต้นฉบับ และพิมพ์

    เวอร์ชัน 0.1.2 พร้อมให้ดาวน์โหลดสำหรับ Windows x64

    ดาวน์โหลด ภาพรวม

  • PikaSnip

    v0.1.0 · Windows x64

    โปรแกรมจับภาพหน้าจอ ปักหมุดภาพลอย วาดแก้ไข ดูดสี และอ่านข้อความ OCR ไทย/อังกฤษแบบออฟไลน์ 100% เขียนด้วย C++20 เนทีฟ ใช้แรมสแตนด์บายต่ำกว่า 15 MB และไม่มี telemetry

    เวอร์ชัน 0.1.0 พร้อมให้ดาวน์โหลดสำหรับ Windows 10 และ 11 (x64)

    ดาวน์โหลด ภาพรวม

สถานะปัจจุบัน

ช่องทางเผยแพร่

PikaPDF 0.5.1 พร้อมใช้งานแล้ว เดิมชื่อ FastPDF รุ่นนี้เพิ่มธีมปรับตามระบบสำหรับโหมด Light, Dark และ High Contrast ของ Windows เผยแพร่บน GitHub Releases เป็นไฟล์ที่ยังไม่ได้ลงนาม Windows อาจแสดงคำเตือนด้านความปลอดภัยเมื่อคุณเปิดใช้งาน ซอร์สโค้ดยังคงเป็นส่วนตัว ดูไฟล์และค่าแฮช SHA-256 ได้ที่หน้า ดาวน์โหลด

PikaView 0.1.2 พร้อมใช้งานแล้ว เป็นรุ่นที่เดิมชื่อ OZ Image Viewer เผยแพร่แพ็กเกจทางการสำหรับ Windows x64 ทั้งตัวติดตั้งและแบบพกพา พร้อมซอร์สโค้ดสำหรับส่วนประกอบ LGPL ซอร์สโค้ดส่วนแรกเปิดเผยสาธารณะบน GitHub ที่ underoatz-netizen/oz-image-viewer ดูไฟล์และค่าแฮช SHA-256 ได้ที่หน้า ดาวน์โหลด

PikaSnip 0.1.0 พร้อมใช้งานแล้ว เผยแพร่บน GitHub Releases (underoatz-netizen/pikasnip) ทั้งไฟล์ Portable x64 ZIP (แนะนำ) และแพ็กเกจ MSIX แบบลงนามเองสำหรับทดสอบ ส่งเข้าหน้า Microsoft Store แล้ว — อยู่ระหว่างการตรวจสอบ ดูไฟล์และค่าแฮช SHA-256 ได้ที่หน้า ดาวน์โหลด

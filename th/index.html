OZ Lab

OZ Lab พัฒนาซอฟต์แวร์สำหรับ Windows ผลิตภัณฑ์ของเราคือ FastPDF โปรแกรมบนเดสก์ท็อปสำหรับทำงานกับเอกสาร PDF และ OZ Image Viewer โปรแกรมดูรูปภาพที่รวดเร็วซึ่งอยู่ระหว่างการพัฒนา

ผลิตภัณฑ์ของเรา

  • FastPDF

    โปรแกรมบนเดสก์ท็อปสำหรับ Windows ใช้เปิดและทำงานกับเอกสาร PDF: อ่าน ค้นหา นำเสนอ จับภาพ ส่งออกเป็นรูปภาพ รวมรูปภาพเป็น PDF และพิมพ์

    เวอร์ชัน 0.3.2 พร้อมให้ดาวน์โหลดสำหรับ Windows x64

  • OZ Image Viewer

    โปรแกรมดูรูปภาพบนเดสก์ท็อปสำหรับ Windows รองรับไฟล์ภาพนิ่งทั่วไป แสดงภาพแรกอย่างรวดเร็ว ซูมและเลื่อนภาพได้ลื่นไหล เลื่อนดูภาพในโฟลเดอร์ และแก้ไขแบบไม่ทำลายต้นฉบับ

    อยู่ระหว่างการพัฒนา — ยังไม่มีรุ่นสาธารณะ

สถานะปัจจุบัน

FastPDF 0.3.2 พร้อมใช้งานแล้ว เผยแพร่บน GitHub Releases เป็นไฟล์ที่ยังไม่ได้ลงนาม Windows อาจแสดงคำเตือนด้านความปลอดภัยเมื่อคุณ เปิดใช้งาน ซอร์สโค้ดยังคงเป็นส่วนตัว ดูไฟล์และค่าแฮช SHA-256 ได้ที่หน้า ดาวน์โหลด

OZ Image Viewer อยู่ระหว่างการพัฒนา เวอร์ชัน 0.1.0 และยังไม่มีรุ่นสาธารณะ ซอร์สโค้ดเป็นส่วนตัว ดู หน้าโปรดักต์ สำหรับสถานะปัจจุบัน

เริ่มต้นดู

  • ซอฟต์แวร์ — ผลิตภัณฑ์ที่มีในเว็บนี้
  • FastPDF — ผลิตภัณฑ์นี้ทำอะไรได้บ้าง
  • คู่มือและคำถามที่พบบ่อย — วิธีใช้งาน
  • OZ Image Viewer — โปรแกรมดูรูปภาพที่อยู่ระหว่างการพัฒนา
  • ช่วยเหลือ — ช่องทางขอความช่วยเหลือ และสถานะการรับบริจาค
  • ความเป็นส่วนตัว — การจัดการข้อมูลของเว็บนี้ และของแอป

Privacy Policy — PikaSnip

Publisher: OZ Lab · Effective Date: November 25, 2026

Short version: PikaSnip runs 100% offline on your Windows device. It collects no personal data, uses no telemetry or analytics, displays no ads, and makes zero network connections.

1. Overview

PikaSnip is a native Windows desktop utility developed by OZ Lab for capturing screenshots, pinning floating reference images on screen, annotating captures, and performing offline Thai and English optical character recognition (OCR).

2. Data Collection

PikaSnip does not collect, transmit, sell, or share any personal or usage data:

  • Zero telemetry, usage analytics, or behavioral tracking.
  • Zero crash-report uploads or background network requests.
  • Zero accounts, sign-ins, advertising SDKs, or third-party trackers.

3. Screen Capture & Offline OCR Processing

All screen captures, annotations, pinned windows, and OCR text recognition (powered by bundled OpenThai 2.1 models and Microsoft ONNX Runtime, with optional local Windows Media OCR fallback) run entirely on your device. Captured pixels and recognized text never leave your computer.

4. Local Storage & Clipboard

  • Settings: Preferences (such as hotkeys, capture delay, and stroke style) are stored locally in settings.json at %LOCALAPPDATA%\OZLab\PikaSnip for Microsoft Store / MSIX installations, or beside PikaSnip.exe in writable Portable installations.
  • Saved Screenshots: Images are written to disk only when you explicitly choose Save (Ctrl+S), saved as PNG files in %USERPROFILE%\Pictures\PikaSnip.
  • Clipboard: PikaSnip reads from or writes to the Windows clipboard only when you explicitly trigger a Copy, Pin Clipboard (Alt+P), Color HEX copy (C), or OCR action.

5. App Capabilities & Permissions

  • Desktop Capture & Full Trust (runFullTrust): Used strictly to capture multi-monitor desktop content, register local hotkeys, host the system tray icon, display always-on-top pin windows, and lazily load the local OCR engine when requested.
  • Startup Task (PikaSnipStartupTask): Disabled by default. PikaSnip starts automatically with Windows only if you explicitly enable Run at Startup in the tray menu.

6. Children’s Privacy

PikaSnip does not collect personal information from anyone, including children under the age of 13.

7. Policy Updates & Contact

If future versions introduce any changes to data handling, this policy will be updated with a new effective date before release. For questions or support, visit OZ Lab at https://ozlab.pages.dev/.

  • การจับภาพและ OCR: ภาพหน้าจอที่จับ ภาพที่ปักหมุด การวาดแก้ไข และการอ่านข้อความไทย/อังกฤษ (ด้วยโมเดล OpenThai 2.1 และ ONNX Runtime ในเครื่อง) ประมวลผลบนอุปกรณ์ของคุณทั้งหมด ไม่มีการอัปโหลดภาพหรือข้อความออกจากเครื่อง
  • การจัดเก็บข้อมูลในเครื่อง: การตั้งค่าถูกบันทึกไว้เฉพาะใน %LOCALAPPDATA%\OZLab\PikaSnip\settings.json (สำหรับรุ่น Microsoft Store / MSIX) หรือข้างไฟล์โปรแกรมในรุ่น Portable และจะบันทึกภาพ PNG ลง %USERPROFILE%\Pictures\PikaSnip เฉพาะเมื่อคุณสั่งบันทึกเท่านั้น
  • คลิปบอร์ดและการเริ่มพร้อม Windows: แอปแก้ไขคลิปบอร์ดเฉพาะตอนคุณสั่งคัดลอก ปักหมุดจากคลิปบอร์ด หรือสกัดข้อความ OCR เท่านั้น ส่วนการเปิดพร้อม Windows ถูกปิดไว้เป็นค่าเริ่มต้น

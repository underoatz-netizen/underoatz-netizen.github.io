Support & donations

How to get help with PikaPDF (formerly FastPDF), and where things stand with donations.

Getting help

Public issue tracker

Support happens through the project's public issue tracker. You can read existing reports, or open a new one there:

PikaPDF (formerly FastPDF) issue tracker on GitHub

When you report a problem, please do not include confidential documents, personal data, passwords, license keys or other sensitive information. Describe the problem in text instead, with only the details needed to understand it.

We do not promise a response time, a fix date, or a feature. There is no email address, phone number or contact form for support at this time.

Donations & supporting OZ Lab

100% voluntary

PikaPDF (formerly FastPDF) is freeware provided at no cost. All features are fully accessible without payment, there are no locked features, and the application will never present donation prompts or reminders.

If you find PikaPDF or our projects helpful and would like to support independent development and hosting costs, voluntary contributions are warmly appreciated.

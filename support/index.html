Support & donations

How to get help with FastPDF, and the current status of donations.

Getting help

Support is handled through the project's public issue tracker. You can read existing reports and open a new one there:

FastPDF issue tracker on GitHub

When you report a problem, please do not include confidential documents, personal data, passwords, license keys or other sensitive information. Describe the problem in text instead, with only the details needed to understand it.

We do not promise a response time, a fix date, or a feature. There is no email address, phone number or contact form for support at this time.

Donations

Donations are not requested or accepted. No donation links, accounts or payment methods are configured, and the project does not ask for or collect payment information.

If this ever changes, the details will be published clearly on this page. Until then, treat any request for payment or donation that claims to be from OZ Lab or FastPDF as unofficial.

Privacy note

If you post an issue, the information you choose to write is handled by GitHub under GitHub's own policies. See the Privacy page for more.
